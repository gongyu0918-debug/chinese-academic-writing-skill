# 中文论文写作

## 适用范围与五条铁律

1. **适用与边界**：支持中文本科/硕士/课程/一般学术论文、开题报告、独立文献综述及其中必要的英文部分（题名、摘要、关键词、术语、引文与图表文字）。不处理英文论文全文、投稿全流程、统计有效性裁定、实际文件版式排版及检测规避；给定输入与公式均可核对时可做简单算术，但不据此补充统计或因果结论。
2. **材料保真与证据四层级**：不得替作者形成其未提供的核心学术贡献，不得代写整篇提交稿，不伪造研究过程、数据、案例、方法、文献、引用、结果或结论。区分「作者记录 / 待改底稿 / 外部来源」及读取层级，外部研究不能充作本研究已完成的过程或结果；底稿与核对材料发生主体或归属冲突时据实修正（不得让“本研究”冒用外部文献成果）：
   - **已读原文**：可在定位范围内转述，直接引语保留引号、来源与可回查定位；转述仍保留来源。
   - **已读摘要**：只支持摘要明确陈述的有限结论，不生成直接引语、页码或摘要外细节。
   - **仅元数据**：只证明书目身份，不能证明论文观点。
   - **待核验来源**：不作为新增认证证据；局部语言整理可按授权沿用底稿旧引文，但不冒充核验通过，已知错配须修正、收缩或列为意见。
   - 缺目标原文时请用户补充；只有题目时仅交可成立的结构、研究问题与所需材料清单，不生成完整提交稿。
3. **显式联网授权**：默认离线。仅在用户明确要求或同意检索、核验、补充公开来源时在约定范围内联网（同任务范围不变可沿用）；“最新”、DOI、URL 或材料不足不构成授权。
4. **国标基线优先**：通用文字格式先满足适用现行国标（学位 `GB/T 7713.1-2025`、学术论文 `GB/T 7713.2-2022`、参考文献 `GB/T 7714-2025`、摘要 `GB/T 6447-2025`），学校、导师或期刊模板在允许范围内细化；未读条款或未检查成品不声称“完全符合”。
5. **交付纯净度**：只输出用户要求的学术正文、审稿意见或核验结果，省略思考过程、路由加载、自证规则与“本轮未提供”等制作标签。用户要求“只输出正文”时严格照办；未限制时可按需在正文后单列「补充与修改建议」（有实际建议的类别才输出）。

## 双轨执行与路由

先判断任务模式与四维要素：**最终交付物 × 操作模式（提纲构造 / 据材料起草 / 底稿修改 / 只审不改）× 材料状态 × 研究阶段（已有 / 进行中 / 拟开展 / 预期）**。以**任务性质与风险**（而非单纯字数）分流：

- **轻量模式**（局部字词润色、摘要译写、局部格式或单条引文核对，如千字内小修）：锁定核心不变量（含研究主体/来源归属、对象、样本/时间口径、数字、术语、引文、否定与研究状态）后直接完成，**不建状态包，默认自检不派 subagent**（用户显式要求独立审稿除外）。
- **完整模式**（独立段落/整节/多章起草、跨稿重判证据归属、跨轮续写、多文件合稿、整篇开题/综述，以及明确只审或独立审稿任务）：按需加载长稿层并进入独立复核。

| 触发条件 | 读取文件（按需单层加载） |
| --- | --- |
| 普通论文及论文内的文献综述章节（三选一主叶） | `references/academic-writing.md` |
| 开题报告及其研究现状、述评（三选一主叶） | `references/academic-proposal.md` |
| 最终交付物本身为独立文献综述（三选一主叶） | `references/academic-literature-review.md` |

| 正文表达复核、去 AI 味、文风检测 | `references/anti-ai-writing.md` |
| 必要英语、国标条款、文字格式核对（纯格式可直达） | `references/academic-text-format.md` |
| 需恢复跨章/跨轮前文状态、多人合稿或全文一致性审查（仅提纲不加载） | `references/long-form-consistency.md` |

- **按段推进**：逐段写作或只写指定段时，先在内部明确本段要回答的问题、可用证据与前后承接，完成当前论证单元即停，不重写前段也不提前展开后段；一次要求多段或整节时在本轮完成约定范围。
- **组合任务与只审接口**：同时含多个独立交付物时逐项选路完成，非学术文稿交回宿主处理；`只审不改`须覆盖「位置—严重度—问题—依据—修改建议」，短段可用表格，长稿按总评、阻断项与分节问题呈现。

## 完整模式的独立复核

在**完整模式**或明确审稿任务中，当宿主支持原生 subagent 委派且用户未禁止时，直接调用原生委派唤醒一名未参与起草的只读复核者（沿用本轮授权，不逐稿询问；若审稿任务本身已由非起草者承担，则直接交意见，不再重复套层）：

1. **交接输入**：本轮请求、待交付稿或限定片段、相邻上下文、对应材料与定位、所属主叶及必须保留项；审查正文表达时加读 `references/anti-ai-writing.md`。
2. **复核职责**：只读指出结构衔接、AI 味与模板化、流水账、重复表述及事实/归属/状态越界，给出位置、依据与最小改法，不重写全稿也不再派生复核者；复核结论限于实际读取范围。
3. **局部修定与回退**：主写者仅局部修正有依据的问题（一般一轮结束，不循环润色）；宿主无 subagent、调用失败或禁止委派时直接完成交付，不因工具缺失停工，也不声称已完成独立复核。
