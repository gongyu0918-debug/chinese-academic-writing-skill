# 中文论文长稿稳定与全文一致性

仅在确需恢复跨章或跨轮前文状态、处理两份以上正文、多人合稿或全文一致性审查时读取；仅处理提纲且无需核对已给正文时不加载。长稿稳定指事实、论证、术语和作者声音可追溯，不要求各章句长、段长或句式一致。

## 工作状态包与时间口径

仅当用户明确要求跨轮保存或已授权写入项目时，才在 `.academic-writing/` 下维护工作文件（不属于正文，不随成稿输出）；未授权时只在当前上下文按同结构维护。**状态包只用于恢复上下文，不能替代回读最新版底稿或作为事实证据。**

### `.academic-writing/paper-state.md`

只记录从最新版底稿、材料或已核验来源确认的耐久项（未知项写“待作者确认”，不从旧轮补猜；与最新版底稿冲突时以回读定位为准，不静默覆盖）：

- **基础边界**：题目、研究问题、研究阶段、模板要求、最新版文件及实际覆盖范围；明确区分**材料截止日期 / 事实发生时间 / 修改写入时间**。
- **不变量与论证链**：对象、样本口径、时空范围、方法、变量、数字、公式；论点—证据—章节回应关系及允许强度上限；未决事项与材料冲突。
- **术语与缩写规范**：
  - `术语组：规范术语 | 混用待查变体1 | 混用待查变体2`（仅列待查混用组，供一致性脚本自动读取）
  - `允许变体：规范术语 -> 合法变体（适用章节）`（不纳入混用告警，命中时按章节语境人工判断）
  - `缩写：ABC, XYZ`
- **文体基线**：优先从作者认可的同稿既有章节提取人称、常用时态、限定强度、引证习惯与节奏倾向（不设句长或被动语态硬阈值）；无样本时采用克制自然的现代学术汉语。

### `.academic-writing/section-briefs/<章节标识>.md`

每份简报仅界定本节职责、必须回答的问题、可用证据 ID、允许强度、前后章衔接依赖及已完成内容摘要（不规定段数与句式）。

## 分批写作与多格式文件交接

1. **分批写作**：开始时核对最新版文件与覆盖范围；每轮仅传全文状态、本节简报、相关证据与相邻章摘要（判断跨章原文时直接回读原章）；一节完成后先独立复核再更新状态摘要，作者手工改稿后仅重审受影响章节。
2. **宿主多格式交接**：`scripts/*.py` 对 DOCX 仅提取主文档正文，不解析扫描 PDF、复杂表格、页眉页脚、批注、脚注/尾注及修订痕迹。处理含这些部件的稿件时，由宿主文件能力读取并注明已覆盖部件、定位以及**宿主未读取或不可读的部件**，不把仅扫正文宣称为整份文件审校完成。

## 合稿后六步全文复核顺序

由独立复核者执行；必须实读纳入范围的全部正文、图表与文献后才能声称完成对应范围复核（前层有阻断问题时不以语言润色掩盖）：

1. **硬边界**：题目、对象、样本、数字、时间、方法、研究状态、因果/否定范围、引语与引用映射前后一致。
2. **研究闭合**：摘要与引言承诺是否由正文兑现，方法—结果—讨论—结论—不足是否对应，结论是否越出证据。
3. **稿内一致**：概念定义、术语、缩写首次定义顺序、符号、图表公式编号、交叉引用与参考文献双向一致。
4. **章节关系**：有无跨章矛盾、同义重复、职责越界、前置概念未定义或旧版本残留。
5. **文体漂移**：人称、时态、语气强度与引证习惯是否无理由突变（合理章节功能差异不判不一致）。
6. **语言整理**：最后处理冗余、机械重复与语病，只改确认问题处；涉及论点取舍或概念合并的未决项先报告，不代作者拍板。**修复后须联查受影响章节、状态项与交叉引用**，不重生成无关章节。

## 只读机械扫描（可选）

支持传入 `--state-file` 自动读取 `paper-state.md` 中的 `术语组` 与 `缩写`，定位跨文件完全重复段落、术语混用、缩写定义顺序及 LaTeX 标签/引用缺失（命中仅为回读候选，不改写文件）：

```bash
python3 -B <skill_dir>/scripts/manuscript_audit.py ch1.md ch2.md --state-file .academic-writing/paper-state.md --json
```
