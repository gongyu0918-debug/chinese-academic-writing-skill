# 中文论文独立文献综述专项叶

仅在最终交付物本身为独立文献综述时读取（论文或开题内的综述章节走所属主叶）。通用铁律与四层级证据见 `SKILL.md`。

## 核心方法：五层文献拆解与主题综合

起草或重构综述时，先按五层拆解已给或已核验来源，**并严格按证据层级止步**（仅元数据止于书目身份，摘要未述推理链则留空，来源确有冲突再写分歧，不将五层写成必填填空表或固定段式）：

1. **元信息与语境**：作者、年份、研究对象、地域与时段边界。
2. **核心论点与推理链**：该文献主张什么、如何推导。
3. **证据基础与口径边界**：样本、方法、测量指标、短期/随访时点与限制。
4. **文献间关系定位**：相互间构成承接、补充、修正、情景限定还是直接冲突。
5. **按研究张力综合**：围绕主题、机制、方法或演进轴交叉比较（避免按篇逐个摘要罗列），明确区分“单一来源结论”与“作者基于多源的综合判断”。

## 来源覆盖、转引与系统综述边界

- **缺来源硬门禁**：无可用来源且用户未授权检索时，**提纲构造与据材料起草均退回范围界定、来源收集清单或提纲**，不写综述正文。
- **来源 ID 与覆盖表**：用户给出来源 ID 时必须在对应论断后就近保留该 ID；需要交付来源清单时，区分支撑观点的「实际使用来源」与仅说明状态/冲突的来源，只交单段时不附整表。
- **二手转引区分**：仅在二手文献 B 中读到原研究 A 的转述时，须标明“A，转引自 B”并定位实际读到的 B，不冒充已读原研究；对同一原结果的多次转述不增加独立研究数量；同方法但基于独立样本或材料的新研究分别计入。
- **防伪空白**：当前材料未覆盖某一问题，只能说明现有材料边界，不能断言整个领域存在空白或研究趋势。
- **系统综述门槛**：区分三类产物——① 协议草案建议（保持计划态）、② 据用户真实检索协议、数据库与检索式、筛选标准和完整筛选记录转写 PRISMA 流程及纳入/排除数量、③ 方法学质量评价（须基于原研究材料与明确评价依据）；缺少真实检索筛选记录时，不生成系统综述结论或检索/排除数量。

## 四种模式

- **提纲构造**：据综述问题与已读来源确定可成立的组织轴；尚无可用来源时交范围界定、候选结构与收集清单，待支持判断保留为问题。
- **据材料起草**：以多来源比较为基本单位，将每项观点准确归回原来源，不把不同作者的对象、方法、数据或结论相互移接。
- **底稿修改**：保留综述问题、来源归因与引用对应，删除或降级无法回溯来源的共识、争议、因果与空白表述；调整分类轴时同步核查同一文献跨节归组是否冲突。
- **只审不改**：重点检查错配归因、摘要过度外推、伪共识/伪争议/伪空白及参考文献失配，按统一审稿接口输出，不重写全文。

## 专项复核要点

1. 每项归因与转引层级是否准确对应来源，是否误用仅有元数据或二手转述。
2. 小节是否围绕同一分组张力形成综合比较，是否退化为逐篇罗列。
3. 综述问题、分类轴、覆盖范围、综合结论与参考文献是否双向一致，是否存在未覆盖误作空白或相关升级为因果。
