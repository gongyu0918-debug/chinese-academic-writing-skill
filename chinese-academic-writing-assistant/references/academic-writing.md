# 普通中文论文专项叶

仅在最终交付物为普通本科/硕士/课程/一般学术论文或修改论文内部章节时读取。本叶专注论证建构与写作方法，通用铁律与四层级证据见 `SKILL.md`。

## 核心区分：材料支持的作者分析 vs 新增经验事实

- **允许有限作者分析**：材料事实可支持作者自己的归纳、比较、解释、候选原因或条件性意义；明确归属作者分析并保持“提示、可能、可理解为、与……相容”等有限强度时，不因来源未逐字写出同一句而视为新增事实。
- **守住主体与强度边界**：推断绑定原主体、对象、样本、情境、时间、所测变量与研究状态；行为记录、相关关系、意向或感受保持其原有解释层级，多种解释并存时保留备选可能。
- **只审不改口径**：有材料与常识直接支持且已标明作者推测的解释，不因构念未被直接测量而判为事实错误或强索次级材料；重点审查其是否确定化、偷换对象或越出范围。

## 章节写作决策卡（按研究设计选用的功能线索，非必填八股）

按学科、材料与研究设计选用（章节可合并，各要素仅作功能线索，非每篇必填清单；段落以完成最小论证单元为准，不设固定句数、句序或等长要求）：

| 章节 / 模块 | 常见论证动作（按设计选用） | 实写避坑与校准 |
| --- | --- | --- |
| **引言** | 现实或理论锚点 → 既有共识与具体缺口/张力 → 本文研究问题与切入点 → 若设计明确，可交代边际贡献 | 缺口落到具体对象与机制问题，不从常识或未读文献虚构空白 |
| **文内综述** | 按理论脉络、核心分歧或方法演进分组对话 → 收束到本文待解问题 | 避免逐篇报菜名，保留改变判断的反证与限定 |
| **方法与数据** | 研究对象与样本来源 → 适用的变量或分析框架 → 处理或识别步骤 → 口径边界 | 明确统计口径、测量工具与控制条件；仅记录材料已确认且影响解释的未完成或待定项，不把材料缺口写进正文 |
| **结果呈现（Findings-First）** | 先陈述核心发现与方向/量级，再按设计展开机理、异质性或分项指标细节 | 不显著项与多指标权衡如实报告，描述统计与控制后估计分开，不把图表逐格报成流水账 |
| **讨论与局限** | 回连前人文献（印证 / 修正 / 解释分歧）→ 区分**方法固有边界（Constraint）**与**可修复缺陷（Defect）** | 讨论有新解释增量，不复读结果数字，不写空泛自我否定或材料外对策 |
| **摘要与结论** | 摘要凝练“问题—方法—发现—结论”；结论直接回应研究问题与条件性启示 | 只概括正文已兑现内容，不新增数据、方法、结果或绝对化意义 |

## 跨学科论证焦点

- **实证经管/社科**：区分相关性、稳健性边界与因果识别条件；样本或业务口径差异（如集团合并口径与单项业务口径）须显式交代，表文显著性与数值保持一致。
- **人文历史/文学**：多源史料或文本对照并注明记录者立场与语境；结合自称/他称与记录者立场逐层区分“未见其名”“文献缺载”与“事件存否”，可讨论缺载原因但不能由单源沉默反推事件未发生。
- **法学规范研究**：先约定行为人称谓与讨论域，再展开条文释义、学说分歧与判例比较，保留合理异议。
- **理工/医学实验**：实验链服务具体研究问题（按实际设计选用主比较、泛化、消融、效率、误差或随访等环节）；区分不同测定口径与短期/随访时点，不以初步指标替代临床或工程定论。

有作者认可的既有稿或同类范文时，仅校准术语、引证方式、限制语与节奏，不复制措辞、观点或来源；篇幅不足只展开已有证据，偏长先删重复与无贡献铺垫。

## 四种模式与导师/审稿意见对照

- **提纲构造**：从研究问题、材料与学校模板提取章节任务；材料稀疏时收缩结构，不用近义标题跨章重复，逐章标明可用材料与缺口。
- **据材料起草**：围绕本节问题、证据与论点关系组织正文，按材料对研究问题的作用分配详略，不按材料条数平均铺排。
- **底稿修改**：只在授权范围内调整，保留模板、层级、核心术语、数据、引用、图表编号与公式；导师意见与旧稿仅作依据，不把旧数据/旧结论自动带回最新版。
  - **意见对照台账（Rebuttal Ledger）**：用户提供导师批注或审稿意见且未限制只输出正文时，按需附紧凑对照表：`意见编号 | 原文位置 | 处理状态（已改 / 部分采纳 / 保留并说明 / 待补证）| 改动与依据`（“改动与依据”直接写明修改或保留理由，不重复状态词）；普通润色仍只交正文。
- **只审不改**：先查“问题—任务—论点—证据—方法—结果—结论”是否闭合及表文数据一致，再查术语、语言与格式；无原始依据不断言统计有效或可通过。

## 专项复核要点

1. 段落是否推进当前论证单元，证据是否得到必要解释，是否存在同义反复或无依据强评价。
2. 研究问题、章节任务、摘要与结论是否逐级闭合，摘要与结论是否仅概括正文。
3. 术语、研究对象、人称、方法、结果、图表、公式与引用序号是否稿内一致。
