# 中文论文开题报告专项叶

仅在最终交付物为中文论文开题报告（含其中的国内外研究现状、文献述评）时读取。通用铁律与四层级证据见 `SKILL.md`。

## 四类研究状态隔离与任务链

1. **严格区分四类状态**：`已有基础`（已完成且有材料支持）、`正在开展`（已启动但未完结的调研/整理/实验）、`拟开展工作`（作者提出的后续安排）、`预期产出`（计划目标）。同一研究工作可分项写入已完成部分、进行中进度与后续计划，拟开展工作与预期产出以计划态表述，与已完成发现清楚分开。
2. **七环任务对应链**：围绕「中心问题 → 研究目标 → 子问题 → 研究内容 → 方法与材料来源 → 进度与已有条件 → 预期产出」建立逐级对应；栏目顺序服从学校或导师模板，不把学位论文成稿的结果、结论或致谢强套进开题。
3. **方案协作边界**：开题正文只写入作者已选定的方案与条件；当用户明确请求探索或比较研究设计、备选框架或方法时，可在正文后建议区以“候选 / 待选 / 待验证”身份对比方案与取舍条件，不写入作者已定正文，也不代拟未提供的招募、访谈提纲、样本量或时间表。

## 四种模式

- **提纲构造**：按题目、研究问题、已有材料与学校模板组织栏目，明确已有基础与拟开展项归位；资料不足时交可成立框架与关键材料缺口。
- **据材料起草**：先将材料分入四类状态再映射模板栏目；选题依据、政策背景与研究现状同样受材料门禁约束（仅知“已收集某批文件”而未读内容时只记基础存在，不概括文件主张；输入未提及不等于项目尚未确定）。
- **底稿修改**：保留原稿计划状态与已确认栏目，不把导师待定建议或旧方案自动写成最终安排；发现前后版本冲突时标出请求确认，不擅自择优。
- **只审不改**：重点核查四类状态是否混淆、研究问题是否导向目标/内容/方法、进度与现有条件是否匹配、研究现状是否与开题问题脱节；按统一审稿接口输出，不重写开题。

## 专项复核要点

1. 题目、对象、范围、中心问题、目标、内容、方法、进度、条件与预期产出是否逐级闭合。
2. 已有基础、正在开展、拟开展与预期产出是否边界清晰，有无生成拟真研究设计或把预计成果写成既成结论。
3. 国内外研究现状是否紧扣开题问题，有无无来源发现或伪研究空白。
