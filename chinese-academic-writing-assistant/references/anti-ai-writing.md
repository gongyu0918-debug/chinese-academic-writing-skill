# 论文 ANTI-AI 语义复核

本文件供独立复核或用户明确要求去 AI 味/文风检查时读取。目标是在**严守学术事实与论证逻辑**的前提下消除模板化套话、无论证功能的机械限定与制作残留；不以故意口语、情绪化或机械换同义词制造风格，不预测检测分数。

## 口径保护五锚点与噪声预算

改写前先锁定五项不变量，再以最小局部改动消除确认问题（单次转折、一次排比、真实比较或专业术语自然重复不触发改写）：

1. **研究对象与主体归属**：保持原主体、对照组、案例与人称；核对底稿所述发现的归属，将外部文献的过程与结果准确归回原文献，与本研究工作清楚区分。
2. **样本、时间、测量口径与研究状态**：保留样本量、时间窗、指标定义、统计口径及已完成/进行中/拟开展/预期状态。
3. **核心术语、数字与公式**：专业术语允许自然重复，不为降频换成不等义近义词。
4. **否定范围与论断强度**：保持原有的推断强度（如相关、提示、可能）与结论适用范围，原句的限定对象和否定范围维持不变。
5. **保护区与引用映射**：直接引语、用户要求逐字保留的文字、参考文献表、脚注/尾注中的书目信息、`[1]`、`[2-4]`、作者—年份标注、DOI、URL、公式、LaTeX 与代码不参与普通句式改写。

## 聚焦四类高频真问题

1. **偏题外围免责与连续否定叠甲**：先收窄越出材料的强判断，再只保留会改变当前判断理解的限制语；**同一边界**只表达一次，分别影响因果、时间或适用范围的不同必要限定各自保留；删除与当前论证无关的“未测事项罗列”或重复兜底尾句。
2. **机械对比与虚设否定**：材料没有真实对照或被否定对象时，不用“不是……而是……”“一方面……另一方面……”硬凑平衡。
3. **空壳拔高与意义尾句成簇**：多段末尾反复用“为……提供了重要理论支撑/实践依据”凑收束，或用“毋庸置疑/不言而喻”替代论据。
4. **连接替代论证与清单式流水账**：相邻段只换说法重复同一观察（数据本身列举不属流水账），或用大量“此外/同时/综上所述”掩盖推理断层。

## 实战改写示范（Before / After，严格保真原意）

- **示例 1（去空壳拔高尾句，保留原反馈主体与相关限定）**
  - *原稿*：检索所得反馈显示，32 名中学教师中，多数认为统一检索节省了寻找素材的时间。不过，本研究未考察教师的长期使用意愿，因此尚不能彻底证明课堂教学质量提高，但这进一步为教育数字化提供了重要理论支撑。
  - *改后*：检索所得反馈显示，32 名中学教师中，多数认为统一检索节省了寻找素材的时间；由于该反馈仅涉及素材获取且未考察长期使用意愿，尚不足以据此推断课堂教学质量变化。
- **示例 2（去模板对仗与空壳意义尾句，不增原稿外事实）**
  - *原稿*：数字治理不是简单的技术叠加，而是制度重构与流程再造的深度协同。这一发现充分说明了平台化改革的重要意义，为后续县域治理现代化提供了重要理论支撑与实践借鉴。
  - *改后*：数字治理不仅涉及技术应用，还包含制度调整与流程协同；这一判断概括了平台化改革的结构特征，其具体成效仍须结合实际案例进一步论证。

## 复核顺序、模式区分与回指原则

1. **复核顺序**：锁定五锚点 → 通读本轮范围核对段落职责与推进（结果段报数据与比较、讨论段推进解释）→ 定位上述四类真问题及制作残留 → 交最小改法。
2. **回指只改真歧义**：能由上下文辨明的代词与整段回指保持原文，不要求先行语紧邻，也不逐个展开代词；仅在混淆论断对象、指标或材料归属时据已给文本补明，不确定则保留原句并在允许的意见中提示。
3. **操作模式区分**：
   - **一般润色**：可作保持原意、不增事实与因果的最小删改和衔接修复；
   - **只删不改**：仅删除完整句或可分离尾部，需重写才能完整处保留；
   - **纯检测模式**：不改写正文，按用户指定字段或「位置—严重度—问题—依据—修改建议」输出；真实研究限制与必要否定不计为问题。

## 只读辅助脚本（可选）

本地草稿可运行跨平台只读扫描辅助定位候选（`prose_lint.py` 命中和次数不判定语义质量；不可执行时人工完成语义复核，不加 `--fix`）：

```bash
python3 -B <skill_dir>/scripts/prose_lint.py draft.md --format --structure --delivery-mode body-only --json
```

允许正文后建议时改为 `--delivery-mode body-with-suggestions`，检查审稿表自身时改为 `--delivery-mode review-only`；`<skill_dir>` 为本 Skill 安装目录。
