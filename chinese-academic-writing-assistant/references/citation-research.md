# 学术来源检索与引用覆盖

本文件处理来源检索、引文核验与引用覆盖审查。联网授权与证据四层级总则见 `SKILL.md`；离线任务直接使用已给材料建立账本并跳过外部检索。

## 检索与核验流程

1. **锁定任务与最小外发**：明确研究问题、时段、语种、来源类型与排除条件；联网只发送检索词与主题，不上传未公开全文、个人信息或敏感研究材料。
2. **交叉检索与回读验证**：拆解可检索论断，选用适配学科数据库及 OpenAlex、Crossref、Semantic Scholar 等交叉核对；搜索片段只作线索，必须打开落地页或原文按 DOI/PMID/arXiv ID/规范题名去重并核对题名、第一作者、年份、载体与版本。DOI 可解析仍须匹配内容，指向他文即阻断。
3. **出版与撤稿状态**：记录核验渠道与日期；`更正` 须读通知与现行版；`撤稿/撤回` 文献移出正文经验论据（仅当研究对象本身为该撤稿事件或文本分析时，可在标明撤稿状态后客观分析）。仅当预定渠道均成功返回可识别记录且均无通知时，才记“本次未检出更新”；任一渠道无记录、请求失败或只返回空关系时记“未确认”（OpenAlex 等聚合状态仅作辅助）。
4. **交付衔接**：纯核验到来源清单、可用范围与未决项即止；需返回写作时只向所属主叶交接本轮所需证据与未决项，来源错配或范围错误须先于文字润色处理。

## 原子论断与证据映射

- **适配优先于名气**：优先评估是否直接回答当前论断、文献类型与研究设计是否匹配及能否定位原文；期刊名、被引量仅作辅助信号。
- **高风险论断从严**：具体数字、因果、比较、特定作者归属、规范要求与研究空白必须有有效支持，否则删除、降调或列为待补。
- **拆解原子关系**：以「主体—关系—对象—方向/否定—范围」绑定来源。按原文实际检验层级区分描述、相关、预测、中介、因果与机制；仅有 A→B 与 B→C 而未检验整体路径时，分述局部关系或列为考察维度，不合并为完整因果链。
- **复合句拆分与二手转引**：同一句含多个方向或强度不同的分句时拆句并分别就近标引，不让句末单标号替整条链背书；作者综合须标明归属。仅读到二手文献 B 对原研究 A 的转述时，标为“A，转引自 B”并定位实际读到的 B。段首句、过渡句与段末综合同样受检。

## 引用覆盖、GB/T 7714 样式与只读审计

- **覆盖指标**：以「获得有效支持的应引用论断数 / 应引用论断总数（N/M）」为主指标并单列高风险项；可辅报每千字独立来源数、连续无引文区段、双向对应与单一来源集中度。不自设统一合格比例，不按字数硬凑引用。
- **双制式规则（`GB/T 7714-2025`）**：局部续写沿用本稿既有体系与来源 ID；英文条目与文字格式细节同步参照 `references/academic-text-format.md`。用户未指定且本稿无既有样式时默认顺序编码：
  - **顺序编码制**：富文本设上角标 `[1]`，纯文本/Markdown 用 `[1]`，紧随所支持论断（多源写 `[1-3]` 且每项须支持对应内容）；文后按正文首次出现顺序列出实际使用来源。
  - **著者—出版年制**：文内用 `作者（年份）` 或 `（作者，年份）`；文后条目将出版年移至责任者之后（逗号分隔），原出版项或卷期前不再重复该年份，条目不加序号，按文种集中后再按责任者字顺与出版年排列。
  - 两种体系均须保证**正文引文与文后清单双向对应**；仅交付指定段落时不附整稿清单，直接引语留页码或定位。

需要本地结构统计时，可运行只读审计脚本（支持顺序编码与著者—出版年制映射统计；标记覆盖仅表示存在标号，不替代原文语义核验）：

```bash
python3 -B <skill_dir>/scripts/citation_audit.py draft.md --mode general --json
```
