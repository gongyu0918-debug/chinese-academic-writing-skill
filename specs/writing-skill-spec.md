# 论文写作行为 Spec

审计对象：`chinese-academic-writing-assistant` 0.1.9；仓库基线 `63a77bd9c4703b9a480387173761224278594ee6`。本表覆盖入口与全部七份 reference。它是维护者检查行为和设计验证的规格表，**不随 Skill 加载，不作为新增运行提示**。标为“待消歧”或“待验证”的预期仍是候选规格，不能宣称产品已经实现。

本表不含 Git、提交、发布、安装、打包、模型调用或回归测试命令。稿件只读扫描是可选产品功能，与维护流程分别管理。审校位置、原句和改写候选见[审计报告](rule-audit-20261030.md)；判断改动收益的方法见[评估规格](evaluation-spec.md)。

定位均相对于 `chinese-academic-writing-assistant/`，行号绑定上述基线。简称：S=`SKILL.md`；W=`references/academic-writing.md`；P=`references/academic-proposal.md`；L=`references/academic-literature-review.md`；A=`references/anti-ai-writing.md`；C=`references/citation-research.md`；G=`references/long-form-consistency.md`；F=`references/academic-text-format.md`。

“已覆盖”只表示已有明确条款；“观察到问题”只表示已有稿件证据；二者均不是稳定性通过结论。优先级表示下一步核查价值，不表示故障发生率。

2026-11-02更新：依据本表F01—F03方向试写三个局部候选，完成两模型112次写稿（109次满足执行条件）。新题和重复题的表现不一致，三个候选暂不替换运行版；这既不证明现版更优，也不否定这些方向。下面更新的是证据状态与待解决边界，详见[微调实写结果](../tests/evidence/rule-tuning-20261102/README.md)。
