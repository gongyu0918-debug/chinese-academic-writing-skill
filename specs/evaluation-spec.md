# 规则评估 Spec：差异、波动与归因

适用于本仓库写作规则的审计与候选实验。依据用户本轮要求：少数几次改善不足以认定优于基线，少数几次变差也不足以否定现版或候选；波动可能来自规则本身，需要核实。此文是维护评估资料，不加载进写稿上下文，不包含维护命令。

## 三种结论分别写

| 层次 | 足以支持的证据 | 不能替代它的材料 |
| --- | --- | --- |
| 文本问题 | 可定位的规则歧义、条件遗漏、作用域交叉或重复 | 否定词数量、规则篇幅、个人语感 |
| 行为问题 | 实际请求、原始材料、可见终稿及经回读材料核实的偏差 | 调用成功、脚本零告警、审稿者一票通过 |
| 改动效果/因果 | 同条件对照、重复与跨任务复测、材料核验、规则路径/作用机制，以及对替代解释的检查 | 单次胜负、两个昵称、不同候选混算胜率、只挑有利样例 |

保留“已观察、待复现、归因未定、局部支持、证据支持无明显差异”等分析状态。工程上的合并/不合并决定另列；因证据不足暂不采用，不能写成该规则已被证明无效。现版继续使用也不等于现版已获稳定性认证。历史发布和取消记录保留当时事实，补充其证据范围，不改写旧稿或旧判词。

## 试验前冻结

1. 明确本次要解决的用户行为，例如“保留必要限定，同时减少无论证作用的句尾免责”。规定正例、反例、可接受变化和实质损害，先写后看输出。
2. 冻结完整基线与候选、实际加载文件、任务原文、材料、输出范围、上下文历史、工具/联网条件、宿主、provider、精确模型版本、reasoning及可配置的采样参数。不可见参数记未知，不能假称完全控制。时间窗口和调用顺序同样记录。
3. 区分规则文本注入测试与自主加载测试。前者比较文本作用，后者比较工具路由与执行；未读取目标 reference 的稿件不能用于证明该 reference 的因果效果。
4. 每个比较先改一个可解释的规则原子。需要同时改多处时，记录完整候选及相互作用，后续拆分/消融；不要把不同轮候选合成一个“新版”。

## 对称比较与复现

| 要检验的解释 | 设计与观察 | 判读边界 |
| --- | --- | --- |
| 模型在相同条件下自然波动 | 同一基线、同一任务独立重复，同时重复候选；使用新上下文，平衡调用顺序 | 单版本自重复只能观察波动，不能定位规则原因；没有 seed 配对时不声称共享随机流 |
| 某一条规则引发问题 | 基线/单原子候选配对；必要时消融或恢复该条，再测新同类任务 | 去掉规则可能同时改变上下文长度与显著性；消融不是单独的因果证明 |
| 多条规则相互抵消 | 分别比较原子A、原子B及组合，保持材料、模型与任务一致 | A有效不代表A+B有效；只在组合出问题时不归咎任一单条 |
| 加载/目标识别失误 | 保存实际请求与已加载文件；区分目标正文、示例、来源和状态包 | 有工具返回不等于所有内容被模型有效使用；未取得上游请求体就保留传输疑点 |
| 评审偏差 | 盲化版本标签与左右顺序，独立审读后逐条回到材料；记录审阅分歧和不采纳理由 | 多数票不覆盖事实错误，作者自查不算独立审，评审也会添加不存在的要求 |
| 特定题目或模型适配 | 同一任务家族换新材料；跨学科、长短稿、不同研究阶段及模型家族分层 | 两个provider使用同一模型不等于两个模型家族；局部收益不外推到所有任务 |

重复次数和任务数量按目标差异、初步波动、成本与所需结论精度预先约定，不设置一个适用于所有规则的“跑够N次即稳定”。一次硬错误足以记录并修正该稿，或暂停当前候选上线以调查；它通常不足以认定某条规则普遍有害。重复不足时继续把“能否归因”列为未决，不以“模型波动”自动豁免，也不以“发生在候选”自动定罪。

## 局部准入与非目标波动

局部改动按其实际diff验收。范围消歧、模式分流或指令减负可以有明确的文本维护价值；在目标行为可用、关键边界得到验证、没有证据充分的相关实质回退时，可按该局部范围采用。无需先证明整套技能跨模型、跨任务全面提升，也不要求每个对照题都有净收益。“未证明全局稳定收益”限制的是对外效果声明，不单独构成否决理由。

| 观察 | 与本次diff的关系如何核实 | 准入处理 |
| --- | --- | --- |
| 同题基线和候选均有的既有问题 | 比较是否有同向加重、范围扩张或新的失败路径；不能仅因两臂共有便断言完全无关 | 未证加重时移出本次否决依据，作为共有质量问题留档 |
| 只在一次候选稿出现的问题 | 回到改动条款、原题、材料和实际加载，检查可能的作用路径及同版重复 | 登记实例；严重问题可触发局部核查，不自动扩大为整个候选失败 |
| 其他候选或不同设置的失败 | 核对规则字节、主叶、任务、宿主、模型及时间窗口是否相同 | 不把另一版的错误直接计入当前候选回归；相同机制仍需单独说明 |
| 直接目标上的负向差异 | 看是否增加实际修改负担、破坏必要信息或违背任务；在相同任务及必要的新同类题复查 | 有重复、具体影响和合理作用路径时，可据该项暂缓；不用全局一致性代替这项调查 |
| 非目标行为的候选专属实质损害 | 虽然条款未直接改该行为，也须检查上下文显著性、共同约束等交互 | 不因“未改那条规则”直接豁免；按影响与关联证据决定局部回滚、继续诊断或采用 |
| 格式微差、可接受措辞、评审者偏好或误读 | 核对是否真的违反用户要求、改变语义或明显增加修改工作 | 纠正对应稿件/评审，不自动升级为规则回退 |

归因表至少写明：具体差异、基线同类表现、候选条款可能怎样影响它、证据强弱、是否影响本次采用。优先使用“已有共有问题”“未证候选加重”“相关性待核查”“相关回退有支持”等表述；只有证据足够时才称“与diff无关”。不确定性本身不是永久禁止合入的条件，也不因放宽门槛而忽略真实损害。

重复出现的局部质量差异也须按影响取舍：能用局部删改消除、关键材料和论证仍完整的残留，可在记录代价和适用范围后接受；不能因此把该稿写成无问题。涉及事实、来源、研究状态或任务范围的实质损害，按其影响另行处理。准入不是要求每份稿零修改，也不是取消准确性要求。

## 评审与汇总

- 逐稿记录：事实/来源/状态保真、论证与分析是否保留、必要限定、正文可用性、无关免责负担、完成范围、作者修改负担。允许不同维度结果不同，不用一句“更稳”覆盖代价。
- 技术失败、语义失败和质量差异分别统计；按任务家族、模型与研究阶段报告分子分母。相同题目的多次生成不是多个独立题目，调用数也不是样本任务数。
- 所有预定任务和失败均保留。缺失配对不悄悄删除；说明缺失原因以及是否可能偏向某臂。
- 比较任务内重复分布与两臂差异。资料足够时报告差值及不确定性区间，按任务聚合或处理重复样本相关性；不具备条件时给原稿和分层描述，不制造显著性或稳定胜率。
- 多轮调词后，用未用于调整的新任务确认；同一批材料反复优化得到的收益仅属探索。停止条件在看结果前约定，预算用尽本身不是“通过”或“取消”的证据。
- 判断正负效果使用相同的事实标准、复现要求和归因范围。净收益须说明改善什么、牺牲什么、在哪些条件成立；不要求每篇稿都更好，也不只看平均偏好掩盖严重错误。
