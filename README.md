# 中文论文助手

面向中文本科论文、硕士学位论文、课程论文、开题报告和独立叙述性文献综述的协作写作 Skill。

调用名：`$chinese-academic-writing-assistant`

## 能做什么

- 根据作者提供的材料起草提纲、段落或章节；
- 修改现有文本，保留事实、引用、术语和研究状态；
- 按“位置—严重度—问题—依据—修改建议”只审不改；
- 区分普通论文、开题报告和独立文献综述；
- 在正文后按需提示可补充的论点、论据、论述和其他修改建议；
- 复核机械重复、虚设否定和无依据对比，只对确认有问题的局部做语义重写。

## 写作边界

只有题目或证据不足时，输出可成立的结构、研究问题和材料清单，不生成可直接提交的完整论文。没有目标文本不能改稿；没有来源且未获准检索时，不起草独立综述正文；不补造数据、研究过程、文献或引用。该 Skill 不提供 AIGC 检测规避和通过率承诺。

## 运行文件

Skill 运行目录严格保留 5 个文件：总入口、OpenAI 元数据和普通论文、开题报告、独立文献综述三份专项 reference。测试与发布证据位于 `tests/`，不进入运行包。

## 验证

0.0.1 使用 12 个核心任务、两个独立 writer 上下文和两名匿名 verifier 检查真实写稿的指令遵循、任务编排、事实边界和交付风格。模型 ID 无法取得，因此结果只作为当前环境的 sanity，不作为跨模型统计结论。
