# 中文论文写作

面向中文本科论文、硕士学位论文、课程论文、开题报告和独立叙述性文献综述的协作写作 Skill。

调用名：`$chinese-academic-writing-assistant`

## 能做什么

- 根据作者提供的材料起草提纲、段落或章节；
- 修改现有文本，保留事实、引用、术语和研究状态；
- 按“位置—严重度—问题—依据—修改建议”只审不改；
- 区分普通论文、开题报告和独立文献综述；
- 在正文后按需提示可补充的论点、论据、论述和其他修改建议；
- 渐进加载论文 ANTI-AI 复核层，定位机械重复、虚设否定和无依据对比，只对确认有问题的局部做语义重写；
- 使用只读脚本提示高频句式、重复段落、标点和制作过程残留，不自动替换或判定文本来源。
- 经用户明确授权后联网检索或核验同领域学术来源，建立论断—证据映射并检查引用覆盖；默认不联网，也不按固定比例凑引用。
- 使用只读引用审计脚本提示候选论断、编号引文与参考文献对应、重复 DOI、未使用条目和引用集中度，不自动补引或换引。
- 多章节、跨轮次续写或全文审查时，按需维护全文状态包与分节简报；合稿后分层检查硬边界、研究闭合、术语与符号、章节关系和文体漂移。
- 使用只读长稿扫描脚本提示跨文件重复段落、显式术语组混用、指定缩写定义顺序和 LaTeX 交叉引用问题，不自动改稿。
- 学校、导师或期刊样式优先；无模板时默认在正文就近使用顺序编码上角标，并在文末列出编号对应的参考文献。

## 写作边界

只有题目或证据不足时，输出可成立的结构、研究问题和材料清单，不生成可直接提交的完整论文。没有目标文本不能改稿；没有来源且未获准检索时，不起草独立综述正文；不补造数据、研究过程、文献或引用。该 Skill 不提供 AIGC 检测规避和通过率承诺。

## 运行文件

Skill 运行目录保留 11 个文件：总入口、OpenAI 元数据、三份任务 reference、来源检索、ANTI-AI 与长稿一致性三份渐进 reference，以及三项只读检查脚本。测试与发布证据位于 `tests/`，不进入运行包。

## 验证

0.0.1 使用 12 个核心任务、两个独立 writer 上下文和两名匿名 verifier 检查真实写稿的指令遵循、任务编排、事实边界和交付风格。0.0.2 增加候选扫描、保护区、只读性、交付残留和渐进加载回归。0.0.3 增加显式授权检索、DOI 身份回读、原子论断和写后引用语义门禁；旧四份引用回归仍有 2 份硬失败，当前规则已改为经复核单例即阻断，但未重跑前不得声称引用语义稳定。0.0.4 候选取消段落句序、句数、句位和等长控制，将 ANTI-AI 改为按需加载，增加样本身份锁定与引用扫描误报修复；三任务对照中旧 baseline 仍占优。0.0.5 新增长稿状态、分节简报、阶段化全文复核和只读机械扫描，确定性测试 122 项通过；一组四章前向任务通过硬边界，但旧基线在同一材料上也能识别核心问题，因此不声称一次性审查质量优于旧版，跨会话稳定性仍待配对消融。
