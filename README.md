# 中文论文写作 Skill

[![Version](https://img.shields.io/badge/version-0.0.9-blue)](https://github.com/gongyu0918-debug/chinese-academic-writing-skill/releases/tag/v0.0.9)
[![SkillHub](https://img.shields.io/badge/SkillHub-chinese--academic--writing--assistant-e8590c)](https://skillhub.cn/skills/chinese-academic-writing-assistant)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

中文论文写作 Skill 用于协助完成中文本科论文、硕士学位论文、课程论文、开题报告和独立文献综述。它根据作者已经提供或明确授权核验的材料工作，可以构造提纲、起草章节、修改底稿或只审不改，并在长稿和多轮续写中辅助维护和检查事实、术语、引用与研究状态的一致性。

这个 Skill 不替作者补造研究。材料不足时，它会收缩交付范围，先给出可成立的结构、研究问题或材料清单，不把常识、惯例和推测写成已经取得的证据。

## 项目来源与设计

这个项目最初是[中文公文写作 Skill](https://github.com/gongyu0918-debug/chinese-official-writing-skill) 中面向论文写作的特殊文种 reference。随着论文规则、引用检查和测试材料逐渐增多，为了便于维护，后来拆分成独立 Skill。

它保留了公文写作入口中的以下做法：先守住材料和事实边界，再按任务加载规则；优先使用中文 Markdown 编写，让不懂代码的人也能直接阅读和修改；去 AI 味只处理已经确认的局部问题，不依靠固定词表大面积改写。

拆分后，项目围绕论文写作作了专门调整，包括区分研究阶段，建立论点与证据的对应关系，处理学术来源和引用，以及在多章节、跨轮次写作中维护全文一致性。这些规则只服务于当前列明的中文论文场景，不向其他写作任务外扩。

## 适合哪些任务

| 任务 | 可以提供的帮助 |
| --- | --- |
| 普通论文 | 梳理研究问题、章节任务和论证关系；依据现有材料起草或修改章节 |
| 开题报告 | 区分拟开展与已完成内容，整理选题依据、研究现状、研究内容和计划 |
| 独立文献综述 | 在来源可用时组织主题、比较观点、说明分歧并形成述评 |
| 修改底稿 | 保留原有事实、数字、术语、引用和研究状态，修正已确认的问题 |
| 只审不改 | 按“位置—严重度—问题—依据—修改建议”给出审稿意见 |
| 长稿与多轮续写 | 维护全文状态和分节简报，合稿后检查跨章节矛盾、重复与文体漂移 |

## 它怎么工作

开始写作前，Skill 会先确认最终交付物、操作方式、研究阶段、学校或导师模板，以及本轮实际提供的材料。普通论文、开题报告和独立文献综述分别使用自己的写作规则，不会因为都出现“文献综述”几个字就混用结构。

写作过程中，它把研究问题、章节任务、论点、证据和结论回应连在一起。每段围绕一个主导任务展开，但不规定固定句数、句序、句位或等长结构。事实、数字、题目、术语和引用不得静默改变；缺少依据的内容会从正文中收回，或放在正文后的补充建议中。

只有在用户明确授权后，Skill 才会联网检索或核验学术来源。检索得到的材料按已读原文、已读摘要、仅有元数据和待核验来源区分使用，DOI 存在不等于某个论点已经获得支持。

完成内容和证据复核后，Skill 再按需检查机械重复、无依据对比、模板化过渡和制作过程残留。三项本地脚本只报告候选问题，不自动改稿，也不判断文本是否由 AI 生成。终稿扫描会额外提示未决状态句尾、无依据否定推断和否定边界句尾等候选，以及成簇的意义支撑句尾和正文外的制作性注记标题；用户只要求检测时，按位置、严重度和修改建议输出检测结果，不改写正文。

## 长稿如何保持一致

多章节、跨轮次续写或全文审查时，可以维护一份简短的全文状态包，记录题目、研究问题、材料边界、关键术语、固定数字、研究阶段和未决事项。每个章节另有分节简报，说明本节要完成什么、使用哪些证据、需要承接和交给下一节什么内容。

合稿后按顺序检查事实与研究状态、问题与结论是否闭合、术语和符号是否统一、章节之间是否重复或冲突，以及文体是否在长稿中逐渐漂移。`manuscript_audit.py` 可以提示跨文件重复段落、显式术语混用、指定缩写的定义顺序和 LaTeX 交叉引用问题，最终判断仍由作者或审稿者完成。

## 使用边界

- 只有题目时，不生成可直接提交的完整论文或完整研究设计。
- 没有目标文本时不能执行改稿；没有可用来源且未授权检索时，不起草独立综述正文。
- 不编造研究过程、数据、案例、方法、文献、引用、结果或结论。
- 不处理统计有效性判定、投稿全流程、答辩材料、论文排版、查重率预测或 AIGC 检测规避。
- 学校、导师或期刊模板优先；没有模板时只提供通用写作协助，不声称完全符合某一机构的全部规范。

## 安装与调用

当前公开版本：`chinese-academic-writing-assistant@0.0.9`

发布渠道：[GitHub Releases](https://github.com/gongyu0918-debug/chinese-academic-writing-skill/releases) · [skillhub.cn](https://skillhub.cn/skills/chinese-academic-writing-assistant)。自后续版本起不再向 ClawHub 发布或更新；既有 ClawHub 版本只作为历史记录保留。

通用 Agent Skills 安装器：

```powershell
npx skills add https://github.com/gongyu0918-debug/chinese-academic-writing-skill --skill chinese-academic-writing-assistant
```

在支持技能调用的环境中使用：

```text
$chinese-academic-writing-assistant 请根据我提供的材料续写第三章，并检查与前两章的术语和数据是否一致。
```

## 运行文件

| 路径 | 作用 |
| --- | --- |
| `chinese-academic-writing-assistant/SKILL.md` | 判断任务是否适用，并控制材料、检索、写作和交付流程 |
| `references/academic-*.md` | 普通论文、开题报告和独立文献综述的专项规则 |
| `references/citation-research.md` | 授权后的来源检索、核验和引用覆盖 |
| `references/anti-ai-writing.md` | 成稿后的自然表达复核 |
| `references/long-form-consistency.md` | 长稿状态、分节简报和全文一致性检查 |
| `scripts/*.py` | 引用、表达和长稿的只读候选扫描 |

skillhub.cn 包固定为上述 11 个必要运行文件和 1 份 Markdown MIT 许可证 `LICENSE.md`，共 12 个文件。发布用 `SKILL.md` 只派生 `name`、精简 `description`、`slug`、`version`、`displayName`、`tags` 和 `license: MIT`；不重复写 `summary`，不附 `homepage`。README、HANDOFF、测试、工具、评测证据和脱敏发布回执保存在 GitHub 仓库，不进入 skillhub.cn 包；本地临时包和原始回执保存在 `.release/`，不提交。

SkillHub 封面源文件为 `assets/skillhub-icon.png`，仅在 GitHub 维护，并在平台支持的页面入口单独上传或关联；图片不进入运行包。
