# 匿名语言复核样本 S010

## 用户任务

只审不改下列论文段落，不给替换稿：‘研究[6]指出变量A与变量B相关。本研究不是重复前人工作，而是实现理论突破；不仅解释了机制，还证明了普遍规律。’材料[6]只支持相关关系，没有机制检验或外部效度材料。请按统一字段报告无依据否定、虚假对比、递进越界和机械句式风险；候选词命中本身不能作为结论。

## 匿名输出

1. 位置：第二句“不是重复前人工作”
   严重度：高
   问题：无依据否定。现有材料不能证明本研究与前人工作不存在重复，否定前人工作也不是由相关关系证据自然推出的判断。
   依据：材料[6]仅支持变量A与变量B相关，未提供研究问题、理论命题、方法或结果层面的比较材料。
   修改建议：删除该否定；如需说明研究的新意，应补充本研究与前人研究的具体比较依据，并把新意限定在证据能够支持的范围内。

2. 位置：第二句“不是重复前人工作，而是实现理论突破”
   严重度：高
   问题：虚假对比。“重复前人工作”与“实现理论突破”被写成二选一关系，但两者并非由现有材料确立的对立项；“理论突破”本身也缺少依据。
   依据：材料[6]只能支持相关关系，不能据此判断本研究相对于前人成果的差异，更不能证明其形成了理论突破。
   修改建议：取消该对比。若要保留“理论突破”的判断，需提供明确的理论增量、与既有研究的对照及相应研究结果；证据不足时不作此评价。

3. 位置：第二句“不仅解释了机制，还证明了普遍规律”
   严重度：高
   问题：递进越界。句子从相关关系连续推进到机制解释和普遍规律，论断强度超出材料能够支持的范围。
   依据：材料[6]没有机制检验，因而不能支持“解释了机制”；也没有外部效度材料，不能从一次相关关系推至“普遍规律”。
   修改建议：删除机制和普遍性结论。只有在补充机制检验及足以支持外部效度的材料后，才能按实际结果分别表述，且不得把相关关系改写为因果证明。

4. 位置：第二句整体
   严重度：中
   问题：存在机械句式风险。相邻使用“不是……而是……”和“不仅……还……”形成连续的对比、递进骨架，且各分句都把结论逐级拔高，使表达呈现口号化特征。该判断来自句式与论证内容不匹配，并非因为候选词本身出现。
   依据：前文只有变量相关关系，未提出需要反驳的“重复”判断，也没有支撑理论突破、机制解释和普遍规律的证据；两个关联结构因此没有承担真实的比较或递进任务。
   修改建议：先按证据删除越界判断，再围绕“相关关系”直接陈述可成立的结论。以后只有在前文提出真实争议、且各层论断均有证据时，才保留相应的对比或递进结构。
