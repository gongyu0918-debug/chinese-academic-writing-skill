## 先验机械门禁

由 `specs/v008.json` 驱动，盲评前运行：汉字数区间、必需标题与部分数、正文-only、禁止列表（如适用）、必需事实字面量、过程泄漏词。机械门禁只识别可确定的格式与字面硬错误；语义质量由盲评判断。

## 独立盲评

- 每任务单独成包，judge 只看任务、匿名左右稿和评分说明。
- Judge 1 与 Judge 2 使用不同种子映射；两票同向才形成决定，否则 Judge 3；三票仍分裂记未决。
- 每侧先给 PASS/WARN/FAIL；事实、来源、研究状态、输出模式、禁止项错误为硬错误，质量偏好不得覆盖。T2 中把检测任务做成全文改写按输出模式硬错误处理；T1 中删除真实研究限制含义按硬错误处理。

## 合并门槛（用户门槛的预注册表述）

1. 不得出现可复现的 candidate-only 硬 FAIL（机械或盲评）。
2. 已决定任务中 Candidate 胜数不少于 Baseline 胜数；任何 Baseline 胜出若被裁判归因于候选 DIFF，则撤回对应原子或允许一次最小修复并改用全新未见任务确认。
3. 与 DIFF 无关的波动（措辞、篇幅抽样、同等质量下的选题偏好）记录为噪声，不计胜负。
4. 确定性门禁：全量 unittest、quick_validate、git diff --check 通过；新检测器具备正例、反例、模式隔离和只读测试。

任一条件不满足即整体拒绝，0.0.8 不合并运行包改动；不靠改题、换 prompt 或反复微调救援。
