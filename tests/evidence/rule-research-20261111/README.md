- 三组匿名审阅均未发现实质保真回退，主审回读了原始材料。A1首轮候选仍列出复访、消费和满意度的未测清单，有局部删改空间；同题重复没有保持这一方向，新题两臂均去掉外围事项。没有把“相当”写成每份稿零问题。
- B的引言、文学文本分析和讨论都能完成任务，未从片段补生平、后续情节或新研究设计。该样本不证明新职责说明提高了成稿水平。
- C两次语言整理均沿用[12]且不声称认证；已知错配按已给核验记录纠正，仅元数据的[9]未被用作观点证据；混合进度任务保住已完成、核对中和未定方案。基线也能完成这些行为，C的采用依据是消除规则身份交叉。
- 自主作者只记录读取入口和主叶，Z2两臂初稿仍有外围说明。随后读取对应ANTI-AI规则的独立复核者，两版都指出应删除整句。最终两臂按意见完成删除。这支持这两个局部任务的分阶段交付可以运行，不能据初稿把未加载的ANTI-AI层判为已经执行后失败，也不能称新规则独有收益。
