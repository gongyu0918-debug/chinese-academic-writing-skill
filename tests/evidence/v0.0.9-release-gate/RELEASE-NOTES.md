# 中文论文写作 v0.0.9

## 本次更新

- 直接适配中文公文写作 Skill 1.6.0 已验证的连续否定减载规则：复核句中或相邻句的重复否定，同时保留材料明确、与当前论证直接相关的必要否定、真实研究限制和未决状态。
- 最终交付改用正向成品边界，只交付用户要求的学术文本或审稿结果；隐藏推理、加载、规则复述和模板旁白仍不进入成品。
- SkillHub 元数据改为简短用途说明，省去重复 `summary` 和 `homepage`。
- 项目与发布包统一采用 MIT。GitHub release 资产与 SkillHub 使用同一份 12 文件包：11 个运行文件加独立 `LICENSE.md`。
- 0.0.9 只发布至 GitHub 与 skillhub.cn，不更新 ClawHub；封面图不塞入运行包。

## 验证边界

- 确定性测试、标准 Skill 结构校验、SkillHub 目录包与 zip 包 dry-run 均通过。
- GitHub 公开评测 stderr 中的内部请求标识已替换为固定占位符；原始日志仅保留在本地忽略目录，写稿正文、trace、判决和计分未改。
- 两行“来源可比性与综合边界”实验候选未获得受控收益，已经撤回，不在 0.0.9 运行规则中。
- 本版本不声称真实写稿已经证明论文质量或去 AI 味效果获得提升。
