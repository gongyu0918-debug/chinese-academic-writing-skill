## 组一：第三章第二段

**W01 → B（轻微）**。A 尾附「（本段约221字，未重述上一段数据，未涉及预约柜。）」，自述与正文不符——「过半请求出现在午休的分布方向一致」已复述上一段结论，实测约202字；「午休恰好落在课程结束与到馆之间」把时段与行为顺序搅在一起，需重写。B 无附加说明，直接可用；单侧问题是「所述时间正落在午休区间内」把推断写成事实（摘录只说课后顺路取），以及「上下午课程之间的空档」预设下午有课，各改一词即可。

**W05 → A**。两稿正文质量相当，B 的「其取资料的时间安排是否同样出自行程衔接不得而知」是很好的限度句；但 B 尾附「（186 字，含数字计。若需调整…告诉我即可。）」，同时违反"只回复这一段"与"写完等我给下一段材料"，且186与实测约190不符。A 无附加文字，「该解释以受访者所述情形为限」保持原意。

**W07 → A（两稿都需改）**。B 的问题更实质：「作者对其中10位读者进行了访谈」凭空设定抽样关系（材料只说"另有10人的访谈摘录"），属研究状态层面的补写；「表明…可能是促成…的一个原因」以"表明"引出判断，强度上抬；「解释覆盖程度偏低」对 6/10 下了材料不支持的评价。A 的问题是表层：标签误作「第三段」、自报188而实测约207、「10位访谈者」应为"受访者"（角色用词错）、「6位明确提到」的"明确"是加强。A 的「材料中也未对其他开放时段偏少的原因给出对应说明」有据。

**W09 → A（接近 TIE）**。B 优点是原样引用作者判断，保真度最高；但「一个有针对性的解释线索」是空泛自评，「短暂空档」补写程度词，「也不足以把午休集中归因于单一机制」否定的是无人主张过的东西（原判断本就是"一个原因"），属多余否定。A 的「记录本身能够说明请求集中，尚不能证明这一衔接必然导致借阅行为」把描述与因果分开，最佳；单侧问题是「也显示…存在关联」的"显示"偏强、「往返教室」补写地点。

## 组二：润色两段

**W02 → B（轻微）**。A 开头「改后正文（两段）：」违反"只交改后正文"；A 把看法写成既成事实——「8人提到能看到进度就减少了反复咨询」（原始记录为"提到进度可见能减少反复咨询"），属状态上移；A 还整条删去窗口数量、部门间资源整合两项限度。这三项否认指向不同层面，不属重复。B 把三项压成一句「但不表示办理手续已缩减，也不表示窗口数量或部门间资源配置有相应变化」，删重复而不丢限度；单侧问题是第二段「多数受访者以进度信息替代反复询问，部分受访者仍保留电话确认」把第一段的 8/4 又说了一遍。

**W06 → B（轻微）**。本组最接近的一对：两稿都删净了底稿第二段的重复、都保留三项否认、都无附加说明。差别在保真——B 保留「但部分人仍需要进一步确认」与「也不足以说明改革成效」，A 两层都省了。B 的单侧瑕疵是「这一分歧提示」：8人与4人是体验差异而非"分歧"，用词偏重。

**W10 → A**。B 正文可用（保留首句论点，把4人那层写成「进度展示提供的信息还不能完全满足部分受访者的需要」），但前挂约110字工作流自述：「补丁工具在该环境持续中止，扫描脚本需要文件输入才能运行，本轮跳过脚本、按 ANTI-AI 规则人工终检完成：不可变项…不声称脚本已运行。以下为改后正文：」——与"只交改后正文"直接冲突，含读者无法理解的内部术语，是全部10组中最重的可用性问题；正文另删去窗口/资源两项否认。A 三项维度准确，单侧问题是第二段首句「就信息需求而言，多数受访者关注是否还需要再次询问，少数受访者仍保留电话确认」仍为第一段复述。
