# 候选路由二次独立复核

对象：`.release/trial/candidate-skill/` 冻结副本中的入口、全部 6 份 reference 与 agents 元数据。只读走查；未运行 Python 语义断言、LLM 写稿或子 writer。候选的正文质量须由主任务保留的原始写稿与独立意见验证，本报告只判断连接含义与退出条件。

## 判断

基线主要断点已补齐：三叶四模式都能选到；来源核验与联网许可已分离；纯引文服务无需虚构文种；阶段切换不再依赖物理卸载；段落职责、成段即停、下一任务接续已建立；独立复核有交接、只读意见、主写修订与终止，评审不能再派评审；无宿主子代理也有不冒称独立的交付出口。没有发现整份不可达叶、悬挂文件目标或必须依赖不存在工具才能结束的主路径。

还保留两处条件措辞不一致，建议先做最小澄清，再绑定新候选做前向任务；另有一处单段任务参考文献尾部的格式风险值得实际写稿检查。均不是已发生的无限循环证据。

## 尚需处理的连接

### C1 / P2：单段跨轮恢复前文，仍同时命中“跳过长稿”和“进入长稿”

- 原句 A：`SKILL.md:53`：`单段或单节且不需要恢复其他章节状态时不读取；跨轮单节确需核对前文状态时读取`。
- 原句 B：`SKILL.md:66`：`跨轮确需恢复前文状态时使用长稿层`。
- 原句 C：`references/long-form-consistency.md:3`：`提纲和无需恢复其他章节状态的单段、单节不加载`。
- 可执行请求：`这是上轮同一小节已经交付的前两段和 .academic-writing 中保存的状态，请恢复前文状态，只写第三段；当前不涉及其他章节。`
- 问题：范围是单段、只恢复同节前文而非其他章节，A/C 字面要求跳过，B 要求进入；入口第一句虽然提到跨轮，但未给出后续条件的优先级。正文仍可写，因此不是死锁；问题是状态恢复路径不唯一，可能遗漏用户要求恢复的状态，或无故读长稿层。
- 最小修正：把条件统一为“需要恢复跨章或跨轮状态时读取；不需要恢复状态的单段/单节跳过”；是否开状态文件继续单独受现有授权约束。无需把所有逐段任务都升为长稿。
- 前向判据：需要状态的跨轮单段正确恢复；同轮仅写单段不加载长稿；无需补写已经完成的前段。

### C2 / P2：离线来源核验与写作的组合任务有一个过早结束句

- 原句 A：`references/citation-research.md:7`：`离线任务从已有材料建立账本，完成核验后直接交结果。`
- 原句 B：同文件 `:11`：`先完成论断—证据映射，再返回所属主叶写作；纯检索或核验到来源结果、可用范围与未解决项即结束。`
- 上游：`SKILL.md:70` 已正确限定 `纯核验任务到问题清单或来源结果即结束`。
- 可执行请求：`仅用所给两篇全文，不联网；先核对比较论点是否成立，再写一个讨论段，最终只交该段。`
- 问题：A 对全部“离线任务”给直接结果出口，而 B 与入口只让纯核验结束。合理执行可以按 B 返回写作，但较字面的执行者可能核验后只交问题清单，遗漏本轮已授权正文。
- 最小修正：A 改为“离线任务从已有材料建立账本；纯核验完成后直接交结果，包含写作则回主叶”；或删掉 A 的结束子句，让第 5 步统一负责完成出口。
- 前向判据：纯核验停在意见；核验加写段任务进入正确主叶并只交正文；两种都不联网。

### C3 / P3（需写稿验证）：来源层的全稿参考文献规则仍可能外溢到单段

- 原句：`references/citation-research.md:35`：`文末设置“参考文献”，按正文首次出现次序列出来源`；同文件 `:37`：`用户要求正文时，只保留已核验来源的就近引用与参考文献`。
- 已有保护：`SKILL.md:64` 当前段完成即停，`:86` 用户输出范围优先；独立综述 `:11` 已明确“只要一段”账本留内部不附表。因此这不是规则优先级上的硬覆盖，只是来源层仍使用全稿口径。
- 可执行请求：`核对给定全文后只写综述第二段，保留原稿来源序号 [4]、[7]；不要另交参考文献或说明。`
- 风险：返回写作时可能额外附“参考文献”，或按当前段重编号 [1]/[2]。后者本应被用户锁定项制止，但对段落增补任务需要实际观察。
- 最小澄清（仅在样本出现问题或直接作为口径修正时）：单段/章节增补沿用本稿现有引文与文后对应；完整稿或用户要求时输出参考文献表。不要建立每段重排参考文献的独立流程。
- 前向判据：恰好一段、原有编号不变、无额外附表；独立完整交稿仍有正确文后对应。

## 不应误判为新问题的地方

- C `:20` 仍禁止用“可能”给未检验整体路径补证，这是来源边界，不与 C `:25` 对合理有限分析的保留自动矛盾。需要用材料与真实稿判断是哪一种。
- 三叶“专项复核交入口独立者”不会导致评审自己再派评审，入口和 A 已明确禁止，且用户只审角色已有短路出口。
- 入口“允许附说明时”才说明未完成独立复核，不强迫只正文任务加免责声明；不能把状态说明塞进每段尾部。
- 阶段顺序允许同一上下文继续，不等于可以把三种文种的栏目和研究状态混在一起；组合任务独立材料约束仍保留。
