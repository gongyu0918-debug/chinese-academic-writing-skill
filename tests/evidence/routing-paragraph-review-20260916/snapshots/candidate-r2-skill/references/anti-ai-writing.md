# 论文 ANTI-AI 语义复核

本文件供入口安排的独立复核者检查正文表达，是三类任务共用的质量层，不是第四种任务叶。目标是使论述贴合研究问题与证据，减少模板化、机械重复和制作残留。以实际表达作用判断质量，不预测生成来源或检测分数，也不用故意口语、情绪和残缺句制造风格。

## 复核顺序

1. 锁定题目、事实、数字、公式、专名、术语、引用及位置、研究状态、否定范围和论断强度。
2. 通读本轮范围，先看结构是否完成研究任务、段落如何推进、前后推理是否连贯，再定位重复表述、流水账和局部句式问题。
3. 回读问题句、前后段和材料依据，给出具体位置、实际影响与最小改法。可选 `scripts/prose_lint.py` 只辅助定位，命中和次数不判定语义质量。
4. 复核者交意见，主写者只改确认有问题的局部及必要衔接；只审任务到意见即结束。
5. 修改守住锁定项和引用映射。通常一轮完成，只在修改产生新的实质问题时复查受影响处；不派生下一层复核者。

本地草稿可运行：

```powershell
python -B scripts\prose_lint.py draft.md --format --structure --delivery-mode body-only --json
```

允许正文后建议时将模式改为 `body-with-suggestions`；检查审稿表自身时使用 `review-only`。无法执行脚本时按本文件人工复核，不得声称脚本已经运行。不得增加 `--fix` 或依据 finding 批量替换。

## 保护区与不变量

- 直接引语、用户要求逐字保留的文字、参考文献表、脚注和尾注中的书目信息只核对位置与格式，不改其内容。
- `[1]`、`[2-4]`、作者—年份标注、DOI、URL、公式、LaTeX、代码、文件路径和英文题名中的符号不参与普通句式或标点改写。
- 必要否定、真实比较、概念辨析、反证、研究限制和材料明确记载的争议可以保留。专业术语允许自然重复，不为降低词频而换成含义不等的同义词。
- `本文将`、`本研究`、`本节讨论` 等学术元话语具有真实导读、方法交代或篇章衔接功能时可以保留；只有集中重复且删去不损害结构时才调整。
- 作者既有论文或认可章节可作为术语、句法、第一人称和节奏的相对基线；无样本时不虚构“个人风格”，也不强行注入观点、情绪或口语。
- 改写不得新增事实、文献、因果、评价或研究过程，不得把“可能、提示、相关”提升为“必然、证明、导致”，也不得移动否定对象或扩大结论适用范围。

## 保护性外扩删除式复核

用户提供完整底稿并明确要求压缩机械兜底、重复限制或材料外收束时，在内容与证据复核后做一次删除式语义观察。这不是否定词检测，也不重写整段：先判断句子或可分离尾部在当前章节和上下文中是否独立承担事实、方法、结果、当前研究状态、程序边界、必要的结论限制、证据冲突或来源归因；承担任一作用即保留。

只处理没有独立论证作用的连续自证、未测事项链、泛化免责声明、材料外未来研究或治理安排、负面范围扩大。材料或来源卡写明某项未测、未收集或未提及，只说明该边界可用，不等于正文必须逐项复述；只有删去后会使正在作出的具体结论因果化、长期化、范围扩大或强度升级时才保留。多个事项承担同一边界时保留最直接的一处，不把其余外围否定当作需要逐项保存的事实。

删除只覆盖完整句或可与有依据前缀分离的最宽尾部，不改事实句，不补责任主体、替代解释、过渡句、篇幅、未来安排或新结论。若删除会损害语法、段落衔接、引用对应或必要边界，需要改写才能完整，看不到权威材料，或判断有疑问，则保留原稿。删减后不为满足篇幅恢复已删内容；用户另有字数要求时，只用已有事实、来源比较和论证关系承担。完成一次即停止，不再为追求“更像人写”继续换词。

## 高频句式与词组

先看句式在上下文中承担什么作用，再看分布。真实比较、递进与并列按其关系表达；句式制造了材料未支持的对立、先后或强弱时，恢复实际关系。同一词组或段落功能集中复现而信息没有推进时，合并重复部分。专业术语和必要主体可以自然复现。

句尾以完成当前论证为准。限制语只有在影响该论断的事实、研究状态或适用范围时才就近保留；用具体对象和条件表达即可。同一边界反复附在各段末尾，或延伸成一串与当前判断无关的排除事项时，保留有独立作用的部分，删去外围自证。必要否定、阴性结果和真实未决事项保持原意；数量和词形本身不决定删改。这些是审已有文本的线索，不是要求起草者为每段补限制、免责声明或收束句。

## 论文场景的成簇风险

- **连接替代论证**：连接词没有对应的并列、因果或递进关系。
- **同构段落**：多个段落以相同短语、长度和收束方式重复；不得为追求变化改成另一套固定骨架。
- **清单替代展开**：只列态度或概念，未说明论点、依据与推理关系。
- **空泛或模糊归因**：抽象词互相解释，或“有研究表明”等没有可回查来源。
- **评价升级与角色混淆**：强词超出证据，或摘要、综述、结论、开题承担了错误功能。

这些风险须结合研究对象和证据账本判断。段落动作是可选集合，不得反向要求每段包含主张、证据、解释、限制或过渡。单个词、一次排比、一次转折或真实比较不足以触发改写。没有能指出具体位置、上下文依据和语义问题的候选时，保持原文。

## 纯检测模式

用户只要求检测（只查找 AI 味、模板化或文风问题，不要求改写）时，严格服从用户指定的字段、顺序和格式；未指定时按位置、严重度、问题、依据和修改建议输出。可按需引用原句和问题依据，不代写全文，也不把候选写进正文。真实研究限制和必要否定不计为表达问题。

## 格式候选

标点脚本只提示重复或冲突标点、中文句内异常半角标点、未闭合引号或括号、意外 Emoji 等候选。引用规范、公式标点、英文摘要和学校模板优先，不能据静态命中直接修改。
