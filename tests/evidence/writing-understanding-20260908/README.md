## 哪些具体写法值得借鉴

### 比较：解释条件差异怎样影响判断

城市降温题中，树荫研究在北方街道，透水铺装研究在南方广场；报告的地表温差分别为 12.8℃、3.6℃。Ollama 的隔离比较候选写道：

> 甲报告的地表温差数值大于乙，这既可能反映树荫遮阳的降温潜力，也可能与街道和广场的下垫面构成、观测时段及城市气候背景差异有关，不能据此直接判定树荫优于透水铺装。

这句把“不能直接比较”落实到地点、表面条件、时段和气候对温差的可能影响，读者能理解为什么数值不能直接排优劣。基线主要分别介绍三个研究，再在结尾补一句需要本地验证。候选的条件说明更有解释力，仍保留“可能”的强度。

原稿：[基线](calls/baseline/ollama/fresh_urban_cooling_compare_01/final.md) / [隔离比较候选](calls/isolated-comparison/ollama/fresh_urban_cooling_compare_01/final.md)。

不过，现有独立综述叶已经要求按来源真实关系选择组织轴、比较共识与差异。C2 基线已经发现“意见数量较多、理由比例较低”的跨研究关系；C3 基线已经区分行为观察、主观意义与制度材料。新增“同一标准”没有解决稳定存在的逐篇罗列问题。

最终未见题 C4 暴露了适用边界：S1 是成年首次到访者的路线完成实验，S2 是到访史未知的中学生访谈，S3 是官网介绍页分析。三者只能为不同问题提供不同层级的证据。

- Alibaba 隔离候选把 S3 放在“使用体验方面”，尽管随后承认没有使用资料；末句又称“现有证据初步支持语音、纸质和AR导览对初访者完成路线或理解展品各有潜在作用”，将 S2 归入了初访者证据。
- MiniMax 隔离候选先写“样本是否属于初访者并不明确”，后又写“提示交互成本是AR导览在初访群体中的潜在摩擦点”，对象限定前后不一致。
- Ollama 隔离候选更紧凑，未出现这项对象转移。末轮盲审解盲结果为基线 2、候选 1，主审复核保留这一方向。

原稿：[Alibaba 基线](calls/baseline/alibaba2/C4/final.md) / [候选](calls/isolated-comparison/alibaba2/C4/final.md)；[MiniMax 基线](calls/baseline/minimax/C4/final.md) / [候选](calls/isolated-comparison/minimax/C4/final.md)；[Ollama 基线](calls/baseline/ollama/C4/final.md) / [候选](calls/isolated-comparison/ollama/C4/final.md)。

这些现象提示，按维度组织时仍可能强行对齐不同人群和来源。单次配对不能证明某个新增句子必然引发错误；取消依据是基线已有目标能力、候选局部收益与额外修订负担并存、最后新题未复现稳定净收益。保留“解释差异如何影响判断”的优句作为证据，不继续叠加默认规则。

### 结论：让相互不完全一致的结果产生认识

混凝土题的 Alibaba 隔离结论候选注意到，S45 孔隙率低于 S0，但早期和 28 天强度仍最低，继而写道：

> 提示掺量过高时胶凝材料反应不充分的不利影响可能部分抵消了孔结构改善对强度的贡献。

其价值在于解释“孔结构改善与强度变化为何不完全同步”，使结论超出试验项目清单。材料已有未充分反应颗粒的显微观察，该句作为有限解释可以成立，不能仅因没有直接测量机制就判错。

原稿：[基线](calls/baseline/alibaba2/fresh_recycled_concrete_conclusion_02/final.md) / [隔离结论候选](calls/isolated-conclusion/alibaba2/fresh_recycled_concrete_conclusion_02/final.md)。

收益未稳定复现。文学结论的基线本来已把工作、文本发现和返乡解释连接起来；MiniMax 隔离候选仍从工作清单起笔，并增加“公共时间的感知并不一致地指向归途的推进”等更费解的表述。混凝土候选也更长。联合候选在两条 DeepSeek 0731 渠道的 E1 中还新增了材料未给的“单平台”，但该叶同时含比较与结论提示，这一错误不能直接归咎于结论句。

原稿：[文学基线](calls/baseline/minimax/E2/final.md) / [隔离结论候选](calls/isolated-conclusion/minimax/E2/final.md)；[E1 Alibaba 基线](calls/baseline/alibaba2/E1/final.md) / [联合候选](calls/candidate/alibaba2/E1/final.md)。

取消结论补丁的依据是未稳定减少工作罗列或修改负担。观察到的有限解释能力已由 v0.1.3 普通论文叶明确允许，当前证据不足以支持再加一层通用结论要求。

## 评审与证据边界

匿名包隐藏模型和基线/候选身份，映射单独保存。初轮及新题另发出 13 次廉价模型评审请求：7 次完整非空、6 次技术无效；完整评审中有 2 份 JSON 格式不合法。Luna 隔离补审覆盖初轮 11 对、新题 15 对、隔离 10 对、末轮 3 对，仅用于评审，没有用它代替上述三个渠道写稿。

主审逐项回查材料与原句，纠正错引、估字错误、将合理推断判错，以及把双方共有问题归为候选独有回退等情况。原始评审保持原样，见 [reviews](reviews)；复核理由见 [adjudication-notes.md](adjudication-notes.md)。不汇总一个误导性的总胜率。

主要限制：每个题目/渠道/写稿组只有一次首稿；只有两个名义模型家族；来源为匿名合成材料；技术失败减少部分可比样本。测试只验证明确加载这些规则后的写稿行为，不覆盖自动选叶、安装、Hook、真实检索或长稿跨轮一致性。

当前基线也有过长、无据推断或表达不准的稿件。本轮取消候选不代表基线全部通过，更不能把“接口完成且非空”当成写作质量合格。篇幅按保存正文去空白后的混合字符数单列诊断，包含标点和拉丁字符；事实安全与篇幅合规分别判断。

## 文件与校验

- `calls/<arm>/<provider>/<task>/`：精确请求、原始正文及接口记录。记录中的 `valid` 仅表示完成且非空。
- `review-*.json` / `mapping-*.json`：匿名包及独立映射，正文逐字回绑首稿。
- `frozen-inputs/`：基线、候选、单条隔离副本及评审输入。
- `run_trial.py`：本次一次性调用脚本的存档；不属于产品运行代码。历史调用在 `.release/writing-trial/` 执行，完整原始响应 JSON 保留在那里；本档案保存正文和响应元数据/哈希，不收录接口返回的加密推理块。
- `manifest.json`：本目录除清单自身以外所有文件的 SHA-256；`verify_evidence.py` 只离线核对输入、正文、配对、模型标识和档案完整性，不自动判文风优劣。

Windows 写入会将模型文本的 LF 转成 CRLF，故调用脚本中的 `final_sha256` 绑定规范化读回的模型文本；最初的 Alibaba C1 基线试跑记录绑定保存字节。该试跑记录由保存响应和当时耗时补齐，未重生成，也没有后续脚本的逐文件哈希字段；仍可由精确请求逐字核对冻结入口和单叶。校验器明确处理这些历史差别，所有实际文件字节仍由 manifest 绑定。

本目录在 `.gitattributes` 中设为 `-text`，防止 Git 的自动换行转换改变已冻结文件的字节，并将 CRLF 中的 CR 识别为换行组成部分。初轮 Luna 评审存档自带一个行末空格，对该原始文件关闭空白格式告警以保留原字节；其哈希和 JSON 仍校验。设置仅限本次档案，不影响产品文件。
