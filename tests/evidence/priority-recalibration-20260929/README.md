# 主次规则重新校准与竞品小改

**合并P主次规则与Q2独立证据区分；取消Q第一版及Elicit摘要硬筛流程。** 全部试验复用托管`academic-release-016`独立工作树，未在main上边写边试，也没有建立worksheet或新的语义测试系统。

用户明确主次是规则要求：主要内容应展开，次要内容应压缩；不要求每个样本均胜过基线。上一轮原裁定不改写，本轮针对偏严或不对称登记另作纠偏。准入不等于承诺每篇稿件都提升，仍保留稿件错误和可归因回退的区别。

## 产品实际改动

- `SKILL.md`执行第2步：按研究问题与材料作用安排详略，关键证据及其与判断的关系重点展开；背景、重复与旁支按需要收束，不按材料条数平均铺排。关键反证、分歧、必要限定和用户必列内容保留。
- `references/academic-literature-review.md`据材料起草：准确转述仍可按来源使用，但多次转述同一结果不增加独立证据；同方法的新材料或新样本仍分别判断。

只有两处Markdown规则变化，三个检查脚本和其他运行文件不变。没有复制外部代码、引入自动检索、固定篇幅配额、代理状态机或证据打分。

## 取舍与风险

详见[P逐稿裁定](P-adjudication.md)、[Q/Q2取舍](Q-adjudication.md)、[竞品来源与静态筛选](competitor-review.md)和[预登记](agent.md)。独立意见保留在reviews，不把评审票数当答案。

已纠正的评审偏差包括：因无关台账数字更多而偏好基线；把正常学术标题视为正文外交付；把带明确限定的材料内分析判成因果；把同批样本的有限互证视为独立验证；跨配对误引用稿句。正文前后加载、计数等制作说明仍属交付问题，但不直接归因于主次DIFF。

稿件仍暴露“未控制”与“不能排除”的范围差异、把不同类型研究共同概括为缺陷、漏限定“唯一观察”的对象、段首概括过宽等问题。部分为两臂共有，部分候选需收窄；未确认最终规则导致可重复的新硬回退。只证明本轮有限场景的规格可用与局部收益，不证明跨学科长稿、所有宿主或所有成稿稳定提升。
