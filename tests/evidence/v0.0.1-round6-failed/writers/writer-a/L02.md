# 生成式人工智能对大学写作的影响：综述范围与资料准备方案

现有信息仅能确定综述主题，尚无可用于归纳、比较和评价的文献、摘要或检索记录。在不补充来源且不开展检索的条件下，无法形成有证据支持的独立文献综述正文，也不能判断已有研究的主要结论、共识、争议、发展趋势或不足。为避免虚构作者观点、研究发现和引用，现将本任务收缩为综述范围界定、研究问题设计、资料收集清单和成文提纲。待取得可核验来源后，可据此完成约3000字的综述正文。

## 一、综述范围

综述可将“大学写作”暂定为高等教育情境中的课程写作、专业写作、学术写作及相关教学与评价活动，将“生成式人工智能”暂定为能够根据用户输入生成或改写文本的人工智能工具。上述界定只用于确定后续检索边界，不代表已有文献采用统一概念。正式写作时，应根据实际来源核对不同研究对工具类型、使用方式、写作任务和研究对象的定义，并在概念不一致时分别说明。

为使约3000字的篇幅能够形成集中讨论，建议优先考察大学生在课程写作中的生成式人工智能使用及其影响。教师备课、自动评分、学校治理和工具技术性能可作为必要的情境信息，但不宜在缺少材料的情况下与学生写作效果并列展开。若后续来源主要涉及研究生、第二语言学习者或某一专业学生，则应相应调整研究对象，不能将特定群体的结论直接推广到全部大学生。

时间、地域、语言和学科范围目前均不能据题目自行确定。资料收集时应记录这些信息，再根据来源分布决定是采用跨情境综述，还是限定为某一国家、语言、学段或课程类型。任何范围调整都应在引言中说明理由，并与正文使用的文献保持一致。

## 二、拟回答的研究问题

1. 相关研究如何界定生成式人工智能、大学写作及工具使用行为？不同定义之间是否可以直接比较？
2. 现有研究考察了哪些写作任务、使用环节和教学情境？研究对象覆盖了哪些学生群体？
3. 研究使用哪些材料和方法判断影响，例如文本作品、写作过程记录、学习者反馈、教师评价或课程结果？不同证据能够支持何种强度的结论？
4. 文献报告的影响分别指向哪些写作表现、学习过程或教学评价问题？这些影响是在何种使用方式和情境条件下出现的？
5. 不同研究的结论是否一致？如有差异，能否从研究对象、任务要求、工具版本、使用规则、评价指标或研究设计中得到解释？
6. 当前来源能够支持哪些审慎结论，仍有哪些问题因证据不足而不能回答？

这些问题是后续阅读和归类的工作框架，不是对既有研究内容的预断。若实际文献无法覆盖某一问题，应缩减问题，而不能以常识补足。

## 三、需要收集的资料

### （一）可直接支持观点的来源

优先收集能够核对全文的实证研究。每项研究至少应记录作者、题名、年份、发表载体、研究对象、写作情境、工具及使用方式、研究方法、评价指标、主要结论、限制和原文定位。正文中的具体判断应回到相应来源，不以二手转述替代原始证据。

可同时收集与主题直接相关的综述研究，用于了解概念划分、研究范围和可追溯的参考文献线索。引用综述所概括的单项研究时，仍应尽量取得原始研究；无法取得时，应明确该信息来自二手来源，不将其写成已经核验的原始结论。

大学、教育主管机构或学术组织发布的正式政策、指导文件和调查报告，可用于说明具体制度背景、使用要求或调查结果。此类材料不能自动证明生成式人工智能对写作能力产生了何种效果。工具开发机构发布的产品说明可用于核对功能和版本信息，也不宜用作学习效果的主要证据。

### （二）不能单独支持研究结论的材料

只有题名、作者、年份或数字对象标识符的书目信息，只能证明文献线索，不能证明文献观点。只读到摘要时，只能使用摘要明确陈述的内容，不能补写研究细节、直接引语或页码。新闻报道、经验文章和社交媒体讨论可用于发现问题线索，但如无相应研究支持，不应据此概括学术共识或因果关系。

### （三）检索与筛选记录

如后续开展资料检索，应保留数据库或资料平台、检索日期、检索式、时间范围、语言范围、纳入与排除条件以及每一步筛选结果。若没有完整、可复查的检索和筛选记录，最终成文应定位为叙述性综述，不使用“系统综述”“穷尽相关研究”或“全面证明”等表述，也不生成检索数量和筛选流程。

资料不必为了凑数而纳入。选择标准应围绕研究问题，兼顾与主题的直接相关性、来源可核验程度和研究情境的可比性。若来源集中于单一群体或单一课程，应如实限定结论适用范围。

## 四、来源阅读与证据记录表

后续可按下列字段建立来源表，并为每项来源设置唯一编号：

| 字段 | 记录内容 |
| --- | --- |
| 来源信息 | 作者、题名、年份、载体、链接或馆藏位置 |
| 阅读层级 | 全文、摘要或仅元数据 |
| 研究对象 | 学段、专业、语言背景、样本与地域 |
| 写作情境 | 课程、任务类型、完成条件与评价要求 |
| 工具使用 | 工具名称及版本、允许用途、实际使用方式 |
| 研究设计 | 数据来源、比较方式、观察时段与分析方法 |
| 评价内容 | 作品表现、写作过程、学习体验或教学评价 |
| 主要结论 | 来源明确支持的结论及其适用条件 |
| 原文定位 | 页码、章节、表格或段落位置 |
| 局限 | 作者说明的限制及阅读中可核对的边界 |
| 正文位置 | 计划支持的小节、论点及引用编号 |

记录时应把来源结论与综述作者的综合判断分开。某项来源发现特定现象，不等于整个领域已经形成共识；多项研究结论不同，也不必然构成理论争议，还需判断研究对象、任务、指标和方法是否具有可比性。

## 五、约3000字综述的成文提纲

### （一）引言

说明综述对象、核心问题和范围，交代生成式人工智能、大学写作及“影响”的操作性含义。研究意义、发展态势和问题严重程度均应由实际来源支持，不用概括性套话代替证据。引言结尾说明正文采用的组织轴及来源边界。

### （二）概念与研究情境

比较来源中的核心概念、研究对象和写作任务，说明哪些研究可以放在同一分析框架下，哪些研究因工具、群体或任务差异需要分别处理。若工具版本或课程规则会改变使用条件，应在此交代，但只写来源明确记录的信息。

### （三）研究证据的类型与可比性

归纳文献采用的研究材料、方法和评价指标，讨论不同证据分别能回答什么问题。文本成品、过程数据、主观反馈和教学评价不应被视为同一种证据；横截面关联、前后比较与具有适当对照的研究也不支持同等强度的结论。本节的任务是为后续综合划定推论边界，而不是简单罗列方法名称。

### （四）主要主题的综合比较

依据实际来源形成主题，而不预先写定正面或负面结论。每一主题先概括可比研究共同考察的问题，再比较结论、证据基础和适用情境；出现差异时，核对研究对象、任务要求、工具使用方式和评价标准。正文应以多项来源之间的关系为单位，避免按作者逐篇介绍。若某一主题只有单项来源，应明确其证据范围，不扩写为普遍规律。

### （五）结论差异及其可能来源

在来源允许的范围内解释研究结论为何不同。只有文献提供相应分析或比较证据时，才能讨论影响条件和作用机制；若只是综述作者根据材料提出的解释，应使用审慎表述，并与原研究结论区分。对尚不能解释的差异，可说明现有材料不足，但不能据此断言整个领域存在空白。

### （六）证据限制与后续研究方向

综合实际来源在对象覆盖、任务设置、工具版本、观察时段、评价指标和研究设计方面的限制。后续研究方向应由这些可核对的限制推导，不以通用模板生成。当前材料没有覆盖的问题，只能表述为本次综述的来源限制，不能直接写成学界从未研究。

### （七）结语

逐项回应综述问题，概括哪些判断获得较充分支持、哪些判断只在特定情境下成立、哪些问题仍无法回答。结语不新增来源之外的事实，不把相关性升级为因果性，也不提出超过证据范围的教学或制度建议。

## 六、形成完整综述前的最低条件

至少需要提供一组与题目直接相关、能够核验正文或摘要的真实来源，以及每项来源的基本书目信息。若希望比较研究结论，还需保证来源之间在研究对象、写作任务或评价内容上存在可说明的联系。若要求采用系统综述方法，则必须另行提供真实的检索协议、数据库与检索式、筛选标准和完整筛选记录。

取得资料后，应先完成来源表和引用映射，再确定主题分组并起草正文。成文中的每项研究发现、共识、分歧和不足都应有就近引用，参考文献表与正文引用逐项对应。未核验来源不得进入观点综合。只有满足这些条件，约3000字的独立文献综述才具备基本的学术证据基础。
