# 生成式人工智能对大学写作的影响：综述范围与写作方案

现有材料不足以形成一篇可核验的3000字独立文献综述。独立文献综述需要依据真实来源比较研究对象、研究方法、主要结论及其局限；在没有文献、摘要或检索记录且不能联网的情况下，无法可靠判断已有研究形成了哪些共识、存在何种争议、呈现何种趋势，也不能给出可追溯的引用和参考文献。为避免把一般判断写成研究结论，以下先界定综述范围，并提供后续可直接使用的结构和材料清单。

## 一、综述范围

综述可围绕“生成式人工智能介入大学写作后，写作过程、写作成果、学习发展与学术规范受到何种影响，这些影响在什么条件下出现”这一核心问题展开。

研究对象可暂定为普通高校本科生和研究生参与的课程写作、学术写作及学位论文写作。是否纳入教师写作、创意写作、外语写作和非学历教育，应在取得文献后根据来源覆盖情况决定。生成式人工智能的范围可包括用于选题构思、资料梳理、提纲生成、文本起草、语言修改、反馈和协作的文本生成工具，但不能在没有材料支持的情况下预设某类用途更常见或影响更显著。

影响维度可作为待检验的分析框架，而不能预先写成结论：一是写作过程，如构思、起草、修改及反馈方式是否发生变化；二是写作成果，如文本质量、论证、语言表达和原创性如何被研究与评价；三是学习发展，如写作能力、批判性思维、自我效能和学习投入是否受到影响；四是规范治理，如作者责任、引用披露、评价公平和课程管理面临哪些问题。时间、地域、学科和语言边界应在来源收集后再明确。

## 二、拟回答的问题

1. 现有研究考察了生成式人工智能介入大学写作的哪些环节？
2. 不同研究使用了什么对象、方法和评价指标，其证据能够支持多强的结论？
3. 相关影响是否因学习阶段、学科、写作任务、工具使用方式或教学安排而有所不同？
4. 研究如何界定潜在收益、风险及其适用条件？
5. 教学指导、使用披露、评价方式和学校政策在研究中承担何种作用？
6. 现有证据在哪些方面相互印证，在哪些方面存在差异，哪些问题仍缺少充分材料？

## 三、3000字综述结构

### 1. 引言（约300字）

依据来源说明选题背景，提出综述问题，交代研究对象、生成式人工智能的操作性范围以及文献覆盖边界。引言不宜先行断言技术已经改善或削弱大学写作。

### 2. 概念与分析框架（约350字）

梳理来源对生成式人工智能、大学写作、写作质量和写作能力等概念的界定，说明不同研究的概念是否一致。在此基础上确定全文采用的分类轴，并解释纳入和排除的写作场景。

### 3. 对写作过程与写作成果的影响（约750字）

按构思、起草、修改、反馈等环节综合多项研究，再比较文本质量、论证、语言和原创性等评价结果。每项判断都应说明研究对象、使用方式和评价方法，区分工具使用后的短期表现与稳定写作能力，避免把个别研究结果扩展为普遍结论。

### 4. 对学习发展与教学关系的影响（约650字）

比较研究如何考察写作知识、批判性思维、自我调节、学习投入及师生互动。重点分析结论是否来自实验、问卷、访谈、文本评价或其他证据，并讨论任务设计、教师指导和学生经验等条件是否影响研究结果。

### 5. 学术规范、评价与治理（约450字）

依据研究和正式政策材料讨论作者责任、使用披露、引用、学术诚信、数据与隐私以及评价公平。政策文件只能用于说明规范要求，不能代替实证研究证明实际影响。

### 6. 研究差异与证据局限（约300字）

比较样本、学科、任务、工具版本、研究周期和测量方法的差异，判断不同结论能否直接对照。只有来源覆盖充分时，才能归纳研究不足或提出领域空白；材料没有涉及某一问题，并不等于该领域不存在相关研究。

### 7. 结语（约200字）

回应综述问题，概括证据支持的共识、差异和适用条件，并提出与证据强度相称的教学或研究启示。结语不得引入前文没有来源支持的新结论。

## 四、需要补充的材料

为完成正式综述，至少需要提供一组可追溯的来源材料，并说明其获取范围。可优先收集以下内容：

- 与主题直接相关的同行评议实证研究，尽量提供全文；无法提供全文时，至少提供完整摘要和书目信息。
- 已有综述、理论研究或方法研究；如存在系统综述，应同时保留其检索范围和纳入标准。
- 能够反映不同研究设计的材料，如实验、调查、访谈、课堂观察和文本评价研究，以便比较证据类型。
- 高校、学术组织或教育主管机构发布的正式规范，用于讨论使用披露、学术诚信和评价要求。
- 每项来源的作者、题名、年份、载体、DOI或稳定链接，以及可回查的页码或段落位置。
- 实际使用的数据库、检索日期、检索式、时间范围、语言范围及纳入排除标准。若未进行系统检索，应如实说明，不使用“系统综述”表述。

整理材料时，可为每项来源记录“研究对象—写作场景—工具用途—研究方法—主要结论—局限—可支持的论点”。取得这些材料后，才能按上述结构比较来源、就近标注引用，并形成一篇有证据基础的3000字独立文献综述。
