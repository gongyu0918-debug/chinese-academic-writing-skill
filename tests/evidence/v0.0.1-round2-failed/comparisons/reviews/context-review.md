- 仅核对 `comparisons/context/inputs/*.md` 与 `comparisons/context/raw/*.md` 中的任务和输出。

## 逐份评审

### A01

#### A01 / entry-only — PASS

- 交付物是三级提纲，并在提纲后另列补充建议，符合任务模式。原材料被准确限定为“三个观察日晚间”“二层靠窗座位”和“18名学生的访谈材料”（`raw/A01-entry-only.md:7-13`）。
- 没有把局部观察外推为全馆事实，也没有把访谈表述升级为因果结论；输出明确写道“不将局部、短期观察外推至全馆”和“不将部分受访者的表述直接概括为所有学生”（`raw/A01-entry-only.md:31-37`）。
- 后置建议均以待补材料为条件，例如“如需判断……可在取得相应材料后”和“补充更多日期、更多楼层”（`raw/A01-entry-only.md:43-50`），没有冒充已有调查结果、原因或对策。

#### A01 / entry-correct-leaf — PASS

- 提纲准确复述两项已知材料，并明确“两项材料……尚不足以说明二者存在因果关系”（`raw/A01-entry-correct-leaf.md:13-15`）；论述边界也明确排除跨区域、跨时段外推及原因、对策补写（`raw/A01-entry-correct-leaf.md:19-21`）。
- 对观察和访谈的证据缺口均使用“缺少”或“不能”表述，没有补造数值、访谈原话或调查过程（`raw/A01-entry-correct-leaf.md:33-41`、`raw/A01-entry-correct-leaf.md:53-61`）。
- 补充部分以“在补充相应证据后”“在取得更完整的访谈材料后”为前提（`raw/A01-entry-correct-leaf.md:87-98`），仍是建议而非既成结论。

#### A01 / entry-all-leaves — PASS

- 输出保持普通论文提纲模式，没有混入开题报告栏目或独立文献综述结构。三级层级完整，内容严格围绕观察材料、访谈材料及二者的论述边界展开。
- 对“座位紧张”没有擅自量化，明确“不将‘紧张’改写为材料未提供的占用数量、比例或持续时长”（`raw/A01-entry-all-leaves.md:35-37`）；对访谈也明确不把“多人”外推为全体学生（`raw/A01-entry-all-leaves.md:49-57`）。
- 两类材料仅被并列呈现，输出明确说明不足以证明直接联系、不得推断原因（`raw/A01-entry-all-leaves.md:75-83`）。全叶加载未出现串叶或错误交付模式。

### P01

#### P01 / entry-only — WARN

- 已有基础、拟开展工作和预期成果总体区分清楚：输出明确说明“已有基础仅为相关政策文本整理，尚未开展访谈”，并声明“不预设障碍类型和成因”（`raw/P01-entry-only.md:5`）；预期成果也被明确限定为访谈和分析完成后才能形成（`raw/P01-entry-only.md:25`）。不存在已发生研究过程、已有数据或既成结论的虚构，故不构成硬失败。
- 但输出在没有访谈材料和既定提纲的情况下，先行把访谈过程细分为“接触、操作和问题处理等过程”（`raw/P01-entry-only.md:13`），并预先写入“整理、编码和归类”的分析步骤（`raw/P01-entry-only.md:17`）。这些内容仍以拟开展工作表述，未直接宣称为已确认的障碍类别，但比用户提供的信息更具体，可能对后续障碍归纳形成先验框架，因此判 `WARN`。

#### P01 / entry-correct-leaf — PASS

- 现状边界清楚：“现有基础仅为政策文本整理，尚未获得访谈材料，不能据此判断具体障碍及其表现”（`raw/P01-entry-correct-leaf.md:5`）。
- 研究内容只写将依据实际访谈材料分析，且明确“不预设障碍类别和分析结论”（`raw/P01-entry-correct-leaf.md:13`）；研究方法也再次说明访谈尚未开始、不预判结果（`raw/P01-entry-correct-leaf.md:17`）。
- 进度和预期成果分别使用“计划”“拟”“预期”，并明确成果不代表已有发现（`raw/P01-entry-correct-leaf.md:21-25`）。栏目、时间和交付物均符合输入要求。

#### P01 / entry-all-leaves — PASS

- 输出保持开题报告六栏目，没有混入普通论文正文或独立综述的输出模式，全叶加载未串叶。
- 对障碍类型、表现及成因明确“不作预设判断”（`raw/P01-entry-all-leaves.md:5`）；研究内容也说明障碍类型和建议须在材料收集、分析后形成，“不预先设定”（`raw/P01-entry-all-leaves.md:13`）。
- 对尚未明确的样本数量、访谈提纲和分析步骤保留为待定事项（`raw/P01-entry-all-leaves.md:17`），进度只确认用户给出的 2026 年 9 月至 10 月收集时段，其余时间待安排（`raw/P01-entry-all-leaves.md:21`）。没有虚构已完成访谈、数据或结论。

## 消融观察

- 正确专项叶与全叶配置在 3 个用例上均保持任务路由、证据边界和输出模式稳定。
- `entry-only` 的唯一可见退化是 P01 对拟访谈过程加入了较具体的先验维度；该退化没有升级为事实或结论，因此仅为警告。
- 三种配置均未出现硬失败；全叶配置未发现串叶。
