# 社区老年人数字政务使用障碍研究开题报告

## 一、选题依据

本研究拟围绕社区老年人使用数字政务服务时可能遇到的障碍展开调查，重点了解障碍出现的具体环节、表现及相关影响因素，为后续提出改进建议提供依据。目前已有基础仅为相关政策文本整理，尚未开展访谈，也未形成实证材料和研究结论。因此，本研究不预设障碍类型和成因，具体判断将以拟收集的访谈材料为依据。

## 二、研究目标

一是结合已整理的政策文本，明确社区老年人数字政务使用障碍的调查范围；二是通过半结构式访谈，了解受访者在实际使用过程中的经历和困难；三是在材料分析的基础上归纳障碍类型，并提出有针对性的改进建议。

## 三、研究内容

研究拟开展三方面工作：第一，梳理已有政策文本中与老年人数字政务服务相关的内容，为访谈问题设计提供背景；第二，围绕数字政务服务的接触、操作和问题处理等过程开展访谈，收集社区老年人的实际使用材料；第三，对访谈材料进行整理和归类，分析主要障碍及其表现，并据此研究改进方向。上述内容均为拟开展工作，目前尚无访谈结果。

## 四、研究方法

研究拟以半结构式访谈为主要方法。访谈开始前，将根据研究目标和已有政策文本拟定访谈提纲；访谈过程中，在保持核心问题一致的基础上，根据受访者回答作必要追问；访谈结束后，对材料进行整理、编码和归类。受访对象范围及访谈数量将结合实际联系条件进一步确定。访谈尚未开始，现阶段不对研究结果作预判。

## 五、进度安排

前期在已有政策文本整理的基础上明确研究范围，完善访谈提纲并做好访谈准备。2026年9月至10月开展材料收集和半结构式访谈，同步整理访谈记录。材料收集完成后，开展分类分析，归纳障碍类型，形成改进建议，并完成研究文本的撰写和修改。

## 六、预期成果

本研究预期形成两项成果：一是基于实际访谈材料形成社区老年人数字政务使用障碍的类型分析；二是结合障碍表现提出相应的改进建议。以上均为预期成果，需在访谈和材料分析完成后才能形成，不能视为现有结论。
