# 社区老年人数字政务使用障碍研究开题报告

## 一、选题依据

本研究以社区老年人为研究对象，拟围绕其使用数字政务过程中遇到的障碍开展研究。现有基础仅为政策文本整理，尚未获得访谈材料，不能据此判断具体障碍及其表现。后续研究将在已有材料基础上，通过半结构式访谈补充研究材料，为障碍类型分析和改进建议提供依据。

## 二、研究目标

本研究拟了解社区老年人使用数字政务时遇到的具体困难，在访谈材料基础上归纳障碍类型，并据此提出改进建议。上述目标均属于拟开展工作，现阶段尚未形成研究结论。

## 三、研究内容

已有基础为政策文本整理。拟开展的工作包括：开展半结构式访谈，整理访谈材料，分析社区老年人数字政务使用障碍的具体表现及类型，并在分析基础上提出改进建议。研究内容将以实际收集的材料为限，不预设障碍类别和分析结论。

## 四、研究方法

本研究拟采用半结构式访谈收集材料。访谈尚未开始，后续将根据实际访谈情况整理相关材料，并据此开展障碍类型分析。现阶段不对访谈结果作预先判断。

## 五、进度安排

前期已完成政策文本整理。2026年9月至10月计划收集研究材料，并开展半结构式访谈。材料收集完成后，拟依次进行访谈材料整理、障碍类型分析和改进建议撰写。

## 六、预期成果

预期形成社区老年人数字政务使用障碍的类型分析，并提出相应的改进建议。以上内容为预期成果，不代表已经取得的研究发现或结论。
