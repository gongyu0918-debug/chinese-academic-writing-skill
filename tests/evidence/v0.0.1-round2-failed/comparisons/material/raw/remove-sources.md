# “生成式人工智能对大学写作的影响”叙述性综述前期框架

## 一、当前材料状态与交付边界

本轮仅提供综述主题，未提供文献、摘要、全文或检索记录，且不允许联网检索。现阶段无法形成综述正文，也无法判断相关研究的主要发现、共识、分歧、作用机制、发展趋势或研究空白。以下内容仅用于界定后续工作范围、明确待回答问题、搭建结构并收集材料。

## 二、待确认的综述范围

1. “生成式人工智能”的具体范围及需要纳入的工具或技术类型。
2. “大学写作”的适用对象、写作任务和教学场景。
3. “影响”的考察口径，以及是否限定为特定层面的影响。
4. 研究对象所在国家或地区、学科、教育阶段及语言环境。
5. 文献的时间范围、语种范围和来源类型。
6. 综述篇幅、用途、提交格式及参考文献著录要求。

## 三、待材料支持的综述问题

1. 所提供来源如何界定生成式人工智能、大学写作及二者之间的关系？
2. 各来源考察了哪些研究对象、写作情境和具体问题？
3. 各来源采用了什么研究材料和方法，其结论能够支持到何种程度？
4. 不同来源的明确结论之间是否存在一致、差异或冲突？
5. 各项结论受到哪些研究范围、方法或材料条件的限制？
6. 在现有来源覆盖范围内，可以形成哪些审慎结论，哪些问题仍不能回答？

## 四、拟定结构

### （一）引言

说明综述主题、问题意识、范围边界、材料来源及组织方式。材料到位前不预写研究背景、研究趋势或研究意义。

### （二）核心概念与综述边界

依据实际来源说明核心概念的具体用法，明确研究对象、写作场景、时间、地域、学科和语种范围；不同来源定义不一致时，分别保留其原意。

### （三）来源覆盖与证据基础

梳理各来源的研究对象、材料、方法、结论及限制。只使用元数据的来源不用于支持研究发现；只有摘要的来源仅采用摘要明确陈述的信息。

### （四）研究发现的综合比较

根据实际来源之间的关系确定分组方式，比较能够相互对应的观点、证据与限制。具体主题和分类轴在阅读材料后确定，不预设共识、争议、趋势或作用机制。

### （五）综合评议

区分来源原有结论与综述者的综合判断，评估结论的证据基础、适用范围和相互关系。仅在来源覆盖充分时讨论研究不足，不把当前材料未覆盖的问题写成领域空白。

### （六）结语

概括现有材料能够支持的结论及其边界，并列出尚待补充证据的问题；不将相关性表述提升为因果结论。

## 五、最小材料清单

1. 可供阅读的文献全文；无法提供全文时，可先提供完整摘要。
2. 每项来源的作者、题名、年份、载体、卷期、页码及 DOI 或稳定链接等书目信息。
3. 已有检索记录，包括数据库、关键词、检索时间及初步筛选情况；叙述性综述不要求补造系统综述流程。
4. 课程或学校对篇幅、结构、文献数量、文献年限和引用格式的明确要求。
5. 已确定的研究对象、地域、学科、写作类型、时间和语种范围。
6. 如已有底稿，提供需要处理的原文及希望保留的标题、观点和引用序号。

材料补齐后，应先逐项核对来源层级和可支持观点，再确定正文分类轴并开展多来源综合。
