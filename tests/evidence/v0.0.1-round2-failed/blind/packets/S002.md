# 匿名写作样本 S002

## 用户任务

只审不改下面这段论文文字。材料只显示横截面问卷中的相关关系，没有实验、追踪或因果识别：‘平台使用时长与课程成绩呈负相关，因此平台使用导致成绩下降，减少使用即可提高成绩。’请按统一审稿字段指出问题，不要提供整段替换稿。

## 匿名输出

位置：句中“因此平台使用导致成绩下降”

严重度：高

问题：将横截面问卷呈现的负相关直接解释为因果关系，论断强度超出现有材料。该结果也可能受到反向关系或其他共同影响因素的作用。

依据：横截面相关关系只能说明两个变量在同一时间点存在统计关联，不能确定时间先后，也不能排除学习投入、课程难度等其他因素的影响，因而不足以证明平台使用导致成绩下降。

修改建议：将结论限定为“平台使用时长与课程成绩呈负相关”，并说明不能据此作出因果解释。如需保留因果判断，应补充能够识别时间顺序并控制混杂因素的追踪、实验或准实验材料。

位置：句中“减少使用即可提高成绩”

严重度：高

问题：由观察到的相关关系直接推出具体干预措施及其确定效果，缺少干预证据，“即可”还把未经验证的效果表述为必然结果。

依据：现有材料没有比较减少使用前后的成绩变化，也没有证明减少使用是成绩提高的原因，因此不能支持该措施的有效性和确定性。

修改建议：删除确定性的干预结论，或将其作为有待检验的研究假设；若要提出实践建议，应补充干预研究、纵向证据或其他能够支持措施效果的材料。
