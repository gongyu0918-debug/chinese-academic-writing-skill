# “生成式人工智能对大学写作的影响”独立文献综述写作方案

目前只有综述题目，没有提供文献全文、摘要、书目信息或检索记录，同时又不允许联网检索。在这种材料条件下，无法可靠写成一篇3000字的独立文献综述。文献综述中的研究结论、学者观点、共识与争议都必须能够回到具体来源；如果直接补写正文，就会产生无法核验的文献、观点或归因。现阶段可先确定综述范围、研究问题和材料收集要求，待提供可用来源后再形成完整正文。

## 一、建议界定的综述范围

题目中的“生成式人工智能”“大学写作”和“影响”都需要进一步限定。可暂时将综述对象界定为：生成式人工智能工具进入高等教育场景后，对大学生课程写作、学术写作及其教学与评价所产生的影响。正式写作前，建议确认以下边界：

1. **研究对象**：仅讨论本科生，还是同时纳入研究生、教师和写作中心人员。
2. **写作类型**：聚焦课程论文与学术写作，还是也包括反思日志、实验报告、毕业论文、外语写作等任务。
3. **使用环节**：是否覆盖选题、资料整理、提纲设计、初稿生成、语言修改、反馈和评价等环节。
4. **结果范围**：关注文本表现、写作过程、学习成效、作者责任、学术诚信、评价公平，还是其中若干方面。
5. **语言与地域**：讨论中文大学写作、英语或外语写作，还是进行跨语言、跨地区比较。
6. **时间范围**：以生成式人工智能广泛进入大学教学后的研究为主，起止年份应根据实际检索结果确定，不宜预先虚构。

如果没有学校或任课教师给定的范围，可先以“大学生课程与学术写作中的生成式人工智能使用”为中心，教师教学与课程评价作为相关情境纳入，但不把所有高等教育人工智能研究都列入综述。

## 二、可采用的核心问题

完整综述可围绕以下问题组织，但每个问题是否保留，应以收集到的文献能否提供证据为准：

1. 现有研究如何界定大学写作中的生成式人工智能使用，其研究对象和写作任务有何差异？
2. 不同研究考察了写作过程中的哪些环节，又采用了哪些指标判断影响？
3. 关于文本表现、写作能力与学习过程，现有研究分别得出了哪些结论，结论成立的条件是什么？
4. 研究如何讨论作者责任、来源使用、学术诚信和评价有效性等问题？
5. 工具使用方式、学生基础、课程要求、教师指导和任务设计是否会造成不同结果？
6. 现有研究使用了哪些研究设计和材料，其结论受到哪些样本、情境、测量或研究周期限制？
7. 已有证据能够支持哪些教学与评价建议，哪些建议仍只是研究者主张而非经验证实的结论？

这些问题是后续阅读与分类的工作框架，并不表示现有研究已经形成相应共识，也不能据此预设生成式人工智能必然带来促进或损害。

## 三、需要补充的来源材料

为写成可核验的独立综述，建议提供与题目直接相关的文献材料，并尽量覆盖不同研究类型：

- 以大学生实际写作任务为对象的实证研究；
- 比较使用与未使用生成式人工智能写作过程或结果的研究；
- 记录学生、教师或写作指导人员使用经验的访谈、观察或调查研究；
- 讨论课程设计、反馈方式和写作评价调整的教学研究；
- 聚焦作者责任、引用规范、学术诚信或公平问题的研究；
- 能够梳理已有研究范围和证据质量的综述性文献；
- 与所在学校、课程或专业直接相关的规范文件，如本次作业要求确需讨论制度背景。

每篇来源至少应提供作者、题名、年份、载体等完整书目信息，以及摘要或与本题相关的正文片段。只有题名或书目信息时，只能确认文献身份，不能据此概括研究观点；只有摘要时，只能采用摘要明确陈述的内容，不能补写方法细节、数据、页码或作者未说明的结论。若希望比较研究设计、样本和局限，最好提供全文。

## 四、建议建立的文献记录表

提供材料时，可按下表逐篇登记，以便后续核对引用与综合结论：

| 项目 | 需要记录的内容 |
| --- | --- |
| 文献编号 | 自定义编号，便于正文引用与参考文献对应 |
| 书目信息 | 作者、题名、年份、期刊或出版机构、卷期页码、DOI或稳定链接 |
| 材料层级 | 全文、摘要或仅有元数据 |
| 研究对象 | 学生层次、专业、课程、语言与地区 |
| 写作任务 | 课程论文、学术论文、外语写作或其他任务 |
| 工具与用法 | 使用了何种工具，介入写作的哪些环节 |
| 研究方法 | 实验、问卷、访谈、文本分析、课堂观察或其他方法 |
| 主要结论 | 仅记录来源明确支持的结论 |
| 限制条件 | 样本、情境、测量方式、研究周期及作者说明的局限 |
| 可用位置 | 拟用于概念界定、主题比较、方法讨论或总结 |

## 五、3000字综述的暂定结构

以下结构仅用于安排篇幅和后续材料，不代表已经获得任何研究结论。收集文献后，应根据来源之间的真实关系调整分类，不宜为了保持结构而强行归组。

### 1. 引言（约300字）

交代综述所关注的大学写作场景，说明核心概念、综述问题及范围。研究背景和问题重要性需要有可核验来源支持，不能只用笼统判断铺陈。

### 2. 研究对象、任务与方法概况（约400字）

比较现有研究关注的学生群体、课程类型、写作任务、工具使用方式和研究方法，说明不同证据适合回答什么问题。只有在来源覆盖充分时，才能归纳研究分布或方法倾向。

### 3. 对写作过程与文本表现的影响（约650字）

依据实际材料比较生成式人工智能介入不同写作环节时的观察结果。应区分文本变化、学生感受和能力变化，避免把短期文本表现直接等同于长期写作能力，也避免把相关关系写成因果关系。

### 4. 对学习过程、作者责任与学术规范的影响（约650字）

围绕学习投入、判断与修改过程、作者身份、来源使用和学术诚信等问题进行综合。正文既要呈现研究结论，也要说明结论来自何种对象、任务与方法；若来源只表达规范立场，应与实证结果分开讨论。

### 5. 影响差异及其情境条件（约450字）

比较不同学生基础、课程目标、任务设计、教师指导和工具用法下的结果。只有当多项来源确实提供相关证据时，才能归纳影响条件；材料未涉及的因素只能列为待考察问题。

### 6. 教学与评价回应（约350字）

梳理文献提出或验证过的教学与评价做法，区分经过课堂研究支持的措施与作者提出的建议，并说明其适用场景和证据限制。

### 7. 总结与研究不足（约200字）

回答开头提出的综述问题，概括当前材料能够支持的结论及其边界。所谓“研究不足”或“研究空白”必须建立在足够广泛的来源覆盖之上；若材料有限，只能表述为“本次所纳入材料尚未覆盖”。

## 六、形成正文前的最低材料要求

下一步可直接提供文献全文、摘要汇编或逐篇阅读笔记，并同时说明学校要求的引用格式、综述对象、语言地域和时间范围。材料到位后，正文将以多来源比较为基本单位，归纳一致之处、差异、争议、证据基础和限制，避免按作者逐篇罗列。所有观点会保留与具体来源的对应关系，文末参考文献也与正文实际使用情况一致。
