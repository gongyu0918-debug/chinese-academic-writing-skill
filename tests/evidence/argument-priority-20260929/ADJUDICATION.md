# 主审逐项裁定

以下按完整原材料核对，不把评审票数当准入判定。两版标识由盲审包独立映射还原。

## r1 与控制题

- A / DeepSeek：两版都省去了无关课堂管理记录，主次收益未复现。基线多出“本节正文（约450字）”前言；候选交付较干净，但不能归因于本轮详略原子。基线“来源层面的处理相对较少”没有保留“优先”不排除后续补来源的余地；候选将“分别标出”改为“同时标出”也宜收窄，不能把评审的“可推出共现”当记录事实。未把这些单篇风险称为规则因果。
- B / DeepSeek：候选明确L1/L2是行为证据，基线仍较完整介绍无关界面资料，候选有局部证据分层表达；两版都保留了旁支解释，不能说已消除平均介绍。两版均保留相反的L2、非行为L3及来源ID。主审补记评审漏看：候选“两个侧面未在同一项研究中同时检验”断言超出摘录可见范围；基线“回查行为与判断结果的联系尚未被检验”同样需限定为当前材料未给出。审稿者称候选“精确”不采纳为此句的质量证明。
- E / Qwen（r1）：两版均完整保留用户要求的S1-S5、人数与主要结果，未发生删掉必列来源。候选综合句称仅S1直接支持问题，错误排除了报告定位正确人数的S2；独立审阅确认。基线多了路由过程前言。主审不采纳审稿者以“交付更干净”优先候选的取舍：可直接删除的前言不能掩盖实质性证据分类错误。保留原稿，r1该题不判通过；仅一对尚不证明由新增规则导致。
- F / Qwen（r1）：两版保留两处原文、页码及期待/迟疑的张力，均未断言最终是否出发。两版把“仍”解作动作不止一次，原文也容许“仍然”之义；属需商榷的文学解释，不直接等同于伪造过程。候选“兴奋依托的恰是未经检验”较抽象；基线“并无外在障碍”超出抽屉未上锁本身，宜限定。两版都有可改处，不把词风偏好当硬回退。
- C / GLM（r1，主审补查）：双方保留18/12/6、维度已确认及编写说明尚未取得。基线研究内容列清补标记、比较、解释的顺序；候选也排除了装帧/发行旁支，但两版都做到，候选开头两次重述研究问题。基线有过程前言，候选没有；这一差异仍不证明主次原子收益。DeepSeek两臂都超时，没有配对结论。
- D / GLM（r1，主审补查）：双方都保住60/90、5/3天、登记口径差异、紧急工单10/25与不能断言效率改善，删去公告栏月份；必要反证未被压掉。候选保留了“原始材料与本段一致”的制作说明，基线也附“R1为作者记录汇编”这一来源性质说明；候选没有额外的内容主次优势。DeepSeek两臂均超时，不能以GLM替代其结果。
- A / GLM（r1）：候选省去课堂管理旁支，基线在结尾逐项排除，有局部主次改善。候选却将每位学生的初稿都同时有两类标记写作既定事实，题面没有给出逐人的标记分布，不采纳评审将此称为“设计事实”的表述。基线的“若只有容易程度在起作用”把4人的自述外推至全组选择，宜弱化；“调整要改动论证”本身是与当前任务相容的普通解释，不单独判编造机制。未逐项再说另10名未访谈者不构成必列信息遗漏。
- B / GLM（r1）：基线和候选都介绍全部弱关联来源，候选额外枚举各类材料和测量，未显示聚焦改善。评审认为“L3提供主观层面的支持”有风险；主审按其已经限定为主观且未测点击判断，不将其直接判硬错误。基线与候选的“判断联系”“提示有效”收束都应回到题目给出的回查对象，而不抬高成理解或判断正确性研究。与A的局部选材收益方向不一致。

## 修订依据

r1 未证明稳定净收益，也暴露中心判断措辞可能被读为选择支持证据的歧义。r2保留主次规格，但改为研究问题与证据作用，避免以“充分展开”催促篇幅；补明用户必列例外。该调整基于具体错误与静态风险共同作窄修，不宣称已经证明了r1错误的因果来源。

r2另用全新G/H/I题对稳定基线测试；E题原样用新会话重新配对，作为旧错误的同题复验，单独计数，不冒称全新题。

## 决策

取消r1和r2新增运行提示，恢复本轮稳定基线。理由是多场景、两家最终写手的目标收益方向不一致，主次改善尚不足以抵消额外提示负担；不是把每个模型错误都认定为本次DIFF造成，也不是要求一个原子消除全部历史问题。首次必列题的实质错误与r2局部改善均保留，不用格式胜负包装规则提升。

主次思路保留为维护侧审稿标准：按研究问题及材料作用判断，关键反证与限定不天然次要，用户必列要求不因压缩消失。产品不新增同义禁令、固定篇幅比例、句式模板或机械语义测试。下一次只有遇到可复现的具体写作职责缺口，才试限定到相应主叶的原子；本轮不以继续堆提示代替取舍。
