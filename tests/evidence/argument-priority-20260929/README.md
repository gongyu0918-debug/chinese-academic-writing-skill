## 结论与实际变化

- 内容详略、证据强度、任务与版本优先级是三个不同问题。本库已有后两者和渐进加载，不再叠加证据账本、代理状态机或重复路由。
- 学术主次应由研究问题和材料作用决定。能改变判断的反证、争议和限定是重点，不能默认排在支持性材料之后；用户必列内容须单独核对。该思路写入 `HANDOFF.md` 的维护审稿流程。
- r1 在入口第2步加入“支撑中心判断、充分展开”；r2改为“写清证据与判断的关系”，并明确必列例外。r1一篇必列综述错误排除定位正确人数证据，r2同题不再出现；但其他题的旁支取舍随模型反向变化，重复限制仍多，未证明稳定净收益。因此两版运行文字均取消。
- 某些单稿仍有结论范围或正文外说明问题。两臂共有问题、孤立差异与可归因回退分别记录；本轮不宣称证明某词导致错误，也不把所有无前言稿算候选改善。
