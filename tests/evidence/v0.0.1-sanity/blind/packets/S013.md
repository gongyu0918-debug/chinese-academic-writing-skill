# 匿名写作样本 S013

## 用户任务

依据以下三项材料写一段独立叙述性综述，并在正文后列出实际使用的来源标识。材料[1]：张明（2022）原文第15页称，在其样本中A与B呈正相关，并明确说明研究未识别因果关系。材料[2]：李华（2023）摘要称C与B存在统计关联，未提供页码。材料[3]：王强（2021）只有题名和DOI 10.1234/example.2021.001，没有摘要或全文。不得从[3]推断研究发现。

## 匿名输出

现有材料分别从 A 与 C 两个方面考察其与 B 的关系，但证据所能支持的论断强度有所不同。张明（2022）在其样本中发现 A 与 B 呈正相关，同时明确指出该研究未识别因果关系，因此这一结果只能说明样本内的相关性[1]。李华（2023）的摘要则表明 C 与 B 存在统计关联，但摘要未说明关联方向、强度及其形成机制，据此尚不能作进一步推断[2]。综合来看，当前材料支持 A、C 分别与 B 存在相关或关联关系，但不足以据此建立因果解释，也不能将两项研究的结论合并为方向一致的关系判断。
