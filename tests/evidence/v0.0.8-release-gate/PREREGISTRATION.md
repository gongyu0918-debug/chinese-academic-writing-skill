日期：2026-08-09。目的：发布 GitHub/ClawHub/skillhub.cn 前，用全新未见任务和全新会话验证 0.0.8 运行包相对 0.0.7 无回退。用户门槛：写稿没有回退风险、至少不劣于基线；与 DIFF 无关的波动不在判定范围内。

## 固定版本

- Baseline：tag `v0.0.7`（提交 `4d36a40`，运行包与 v0.0.6 相同），writer 在 detached worktree `ab-v008-baseline`。
- Candidate：tag `v0.0.8`（提交 `09b89a6`），writer 在 worktree `release-v0.0.8`（分支 codex/release-v0.0.8）。
- 环境：codex-cli 0.144.6，默认模型与只读沙箱，剔除 `[agents]` 表的独立 CODEX_HOME（与开发轮相同）；每个“任务 × arm”全新会话。

## 机械门禁

由 `specs/release.json` 驱动，盲评前运行；口径与开发轮一致（含盲评前修正后的门禁脚本）。R3 的 M1/M2/M3/[S1] 标签保留为显式必需字面量。

## 盲评与门槛

- 每任务双盲评审，judge-1/judge-2 独立映射；分裂时 judge-3。
- 硬错误口径与开发轮一致（含“只检测不修改”与“保留真实研究限制含义”两条任务相关硬错误）。
- 发布门槛：1) 不得出现可复现的 candidate-only 硬 FAIL；2) 已决定任务 Candidate 胜数不少于 Baseline；3) 与 DIFF 无关的波动记噪声。任一不满足即停止发布。
- 若出现候选独有硬 FAIL，先按开发轮确认轮方法用全新任务复验归因；复现即停止发布，不复现记噪声后重算。
