# 0.0.3 引用检索与覆盖 sanity 报告

## 结论

两个独立 writer 各完成两组连续对话、共 12 份原始输出。两者都只在 M1-T2 明确授权轮报告联网；未授权的“2026 最新研究”轮降级交付，后续写作沿用已核验摘要而未再次联网。两名独立冷审 verifier 均给出 11 PASS、1 WARN、0 FAIL；没有硬失败，没有问题达到“三输出、两任务、两 writer”的 Prompt 修复阈值。

唯一重复 WARN 位于 writer-a 的 M1-T3：末句“具体任务制约”略强于摘要能直接证明的范围。该问题只涉及一个输出、一个任务、一个 writer，因此记录但不修改 Prompt。

## 来源与写作链

M1-T2 实际检索并在元数据与摘要层级核验三篇来源：Roediger 与 Karpicke（2006）、Karpicke 与 Roediger（2008）、Rowland（2014）。两个 verifier 分别联网复核 DOI、题名、作者年份、文献类型和摘要支持范围。M1-T3 均使用顺序编码上角标与文后参考文献，正文—文后编号双向对应。

M2 证明两名 writer 都能识别结果指标错配、研究对象外推和元数据冒充观点；面对“30% 且每段 3 篇”要求，没有补充无关来源或声称已经达标。新增材料 D 后，两份最终正文只使用 A、D，保留适用范围，也没有泄露检索、证据账本、门禁或脚本过程。

## 冷审、基线与消融

- 与 `14c7b99` 基线相比，候选移除了“时效信息自动联网”，增加显式授权、独立检索上下文、来源分级、证据映射和引用覆盖契约。
- 轻量消融覆盖：去掉有效来源、显式加入结构阈值、篡改或重复 DOI、括号年份伪引文、三类参考文献标题、三种输入只读性。
- 实现冷审发现的字节码写入、作者年份误判、参考文献标题漏识别都已在三个输入变体上复现后修复。结构标记覆盖与有效证据覆盖已经分名。

## 已知限制

- writer report 能证明落盘声明一致，不能独立取证所有浏览器调用历史。
- 三篇真实来源只读取出版元数据和摘要，未检查全文方法、结果表或补充材料。
- Markdown 用 `<sup>[1]</sup>` 表示默认上角标；是否转成 Word 的实际上标格式仍取决于交付载体。
- 缺失文后条目的脚本定位仍统一报第 1 行，未达到三变体修复阈值。
- 部分总结句或以分号连接的句段会被脚本列为“未见引用标记候选”；两名 verifier 已结合上下文判定不构成硬失败，脚本结果不能替代语义判断。
- 模型 ID：`unavailable`。本结果只称当前环境真实写稿 sanity，不称跨模型统计结论。
