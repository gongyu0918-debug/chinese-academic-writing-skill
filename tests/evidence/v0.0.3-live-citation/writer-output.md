围绕高等教育学生同伴反馈与学术写作质量，现有证据显示出积极但有条件的关系。Huisman等对24项量化研究的元分析发现，与无反馈和自我评价相比，同伴反馈组写作改善更大，但与教师反馈未呈现稳定差异；无反馈比较所含研究很少，结论仍需审慎推广[1]。具体研究提示，反馈角色、内容和实施方式可能影响修订成效。在写作密集型心理学课程中，多名同伴提供的反馈更丰富，非指令性意见引发的复杂修订与质量提升相关；该研究仅纳入28名本科生，不能断定同伴反馈普遍优于教师反馈[2]。另一项83名本科生参与的真实写作任务显示，反馈提供者与接收者的成绩改善相近；解释性评论与反馈充分性感知及修改意愿正相关，却未直接对应更大的写作增幅[3]。针对50名语言学硕士生英文文献综述的研究发现，提供与接收反馈的特征联合预测修订质量，具体问题和解决建议较为关键；由于采用相关性设计，尚不能确认因果关系[4]。综合来看，同伴反馈可能改善学术写作质量，但其效果受任务设计、反馈内容和学习情境制约，现有证据不足以支持无条件的普遍结论。
