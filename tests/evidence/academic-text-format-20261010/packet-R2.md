## 栏目的组织主线

开题正文按一条对应链组织,前一栏要能被后一栏接着回答:中心问题 → 研究目标 → 子问题 → 研究内容 → 方法与材料来源 → 进度与已有条件 → 预期产出。

| 栏目 | 这一栏要回答的问题 | 状态归属与写作边界 |
| --- | --- | --- |
| 选题依据 | 问题的现实来路与学术来路 | 已完成且材料支持的写"已有基础",问题提出写"拟开展";不补行业趋势、价值影响、障碍类别与作用机制 |
| 国内外研究现状与述评 | 已有研究谈到哪一步、与本题的关系 | 只综合已提供或已核验来源;已读原文、已读摘要、仅有元数据三层分别处理,不从题名或元数据推测发现 |
| 研究对象与范围 | 研究什么、在哪里、不覆盖什么 | 只采用作者已定的口径 |
| 研究问题与研究目标 | 中心问题是什么、要达到什么 | 作者已提出的内容;目标和中心问题必须可回溯 |
| 研究内容 | 目标拆成哪几项具体工作 | 与子问题逐项对应,不平均铺排 |
| 方法、材料来源与分析思路 | 用什么取得材料、怎么处理 | 只写作者已给的方案;样本数量、提纲、招募、编码与分析步骤没有依据就不成文 |
| 已有基础与条件 | 已经做完什么、现在具备什么 | 有材料支持的已完成工作;只知道"已整理某类材料"时只记该项基础存在,不概括其内容 |
| 进度安排 | 什么时间做什么 | 只用作者明确给出的任务与时间 |
| 预期产出 | 计划希望得到什么 | 保持"预期"语气,不写成已证实的结论 |
| 参考文献 | 引了哪些、怎样著录 | 待核验来源不进入正文;著录格式待模板或用户指定 |
