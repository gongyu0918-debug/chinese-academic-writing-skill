# “生成式人工智能对大学写作的影响”独立文献综述写作方案

本轮只有综述题目，没有提供文献、摘要、检索记录或其他可核验材料，同时明确不允许联网。在这一材料条件下，无法可靠归纳已有研究的主要观点、共识、分歧、证据基础与局限，也不能生成引用和参考文献。因此，暂不撰写3000字综述正文，以免虚构文献、研究结论或领域趋势。可先按以下方案界定范围并准备材料。

## 一、需要先确认的综述范围

1. “大学写作”的具体范围：本科生课程论文、学位论文、通识写作、专业写作，还是教师的教学与评价活动。
2. “影响”的考察对象：学生、教师、课程教学、写作评价或学术规范；如需同时讨论多个对象，应明确主次关系。
3. 时间、地域与学科边界：是否限定研究年份、国家或地区，以及是否聚焦某一学科。
4. 生成式人工智能的概念边界：纳入哪些类型的工具与使用情境，是否区分构思、起草、修改、反馈等环节。
5. 综述用途与格式：课程作业、独立作业或其他用途；引用体例、标题层级和参考文献格式由学校或教师要求确定。

## 二、建议聚焦的综述问题

在材料到位后，可围绕以下问题进行筛选和综合：

1. 现有研究如何界定生成式人工智能介入大学写作的方式与边界？
2. 不同研究关注了哪些写作主体、写作场景和评价指标？
3. 各项研究得出了哪些结论，这些结论分别建立在何种研究对象、方法和证据之上？
4. 不同研究的结论是否一致；如不一致，差异是否与研究情境、样本、任务或方法有关？
5. 现有材料能够支持哪些审慎结论，又有哪些问题因证据不足而只能保留为待研究事项？

## 三、3000字正文的暂定结构

### 1. 引言

说明综述问题、核心概念、讨论对象和范围，交代选题意义。涉及背景事实和研究现状的表述均须有来源支持。

### 2. 文献范围与组织方式

说明实际使用的文献来源、覆盖时段、材料层级以及分类依据。若没有完整检索协议和筛选记录，只按叙述性综述撰写，不使用“系统综述”表述，也不编写检索数量、排除数量或纳入数量。

### 3. 主要研究主题

根据文献实际内容归纳主题，不预先设定结论。每个主题以多篇文献的比较为基本单位，分别呈现研究对象、方法、主要结论及适用范围，避免逐篇摘要。主题名称和数量应在阅读材料后确定。

### 4. 研究共识、差异与争议

比较来源之间能够被证据支持的一致之处与差异，区分单篇文献结论和综述者的综合判断。只有在材料覆盖充分时，才能判断某一观点是否构成研究共识、争议或发展趋势。

### 5. 证据局限与待研究问题

依据已读文献讨论研究对象、方法、情境和证据范围的限制。当前材料没有覆盖的问题只能写为“本综述所收集材料尚不足以判断”，不能直接表述为整个领域的研究空白。

### 6. 结语

回应综述问题，概括当前材料能够支持的有限结论，并说明结论的适用范围。不得将相关关系、研究者解释或个别情境中的发现改写为普遍因果结论。

## 四、需要补充的材料

请提供能够相互比较的多篇真实文献，优先提供全文；如暂时无法提供全文，可提供题名、作者、年份、出处、摘要及可回查链接或 DOI。仅有书目信息的文献只能用于确认元数据，不能用于概括观点；仅有摘要的文献只能支持摘要明确陈述的有限结论。还需一并提供课程或学校的字数、结构、引用体例和参考文献格式要求。

收到材料后，可建立“来源—研究对象—方法—主要结论—限制—正文位置”的对应表，再据此完成约3000字的叙述性独立文献综述，并确保正文中的每项观点均可回到相应来源。
