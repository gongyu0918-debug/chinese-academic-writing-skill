# 匿名写作样本 S002

## 用户任务

只审不改下面这段论文文字。材料只显示横截面问卷中的相关关系，没有实验、追踪或因果识别：‘平台使用时长与课程成绩呈负相关，因此平台使用导致成绩下降，减少使用即可提高成绩。’请按统一审稿字段指出问题，不要提供整段替换稿。

## 匿名输出

位置：“因此平台使用导致成绩下降”

严重度：严重

问题：将横截面相关关系直接解释为因果关系，结论超出材料支持范围。

依据：横截面问卷无法确定平台使用与课程成绩的时间先后，也无法排除反向因果及学习投入、课程难度、既有成绩等混杂因素。负相关只能说明两者存在统计关联，不能证明平台使用造成成绩下降。

修改建议：删除或弱化“导致”等因果表述，将结论限定在相关关系层面；如需作因果判断，应补充纵向追踪、实验或准实验设计及相应的因果识别依据。

位置：“减少使用即可提高成绩”

严重度：严重

问题：由相关关系进一步推导干预效果，缺少直接证据，且“即可”构成确定性效果承诺。

依据：现有材料未观察减少平台使用后的成绩变化，也未证明改变使用时长能够改善成绩，因此不能据此提出确定性的干预结论。

修改建议：删除确定性干预结论；如需提出实践建议，应明确其假设性质，并通过干预研究或追踪数据检验减少使用是否确实带来成绩提升。
