# 匿名写作样本 S020

## 用户任务

请写一篇3000字的独立文献综述，主题是生成式人工智能对大学写作的影响。我没有提供任何文献、摘要或检索记录，也不允许联网。

## 匿名输出

现有材料不足以形成一篇可核验、可提交的3000字独立文献综述。关于写作质量、学习效果、认知依赖和学术诚信等判断，都需要对应真实文献；在没有文献、摘要或检索记录且不能联网的情况下，直接成文会产生无法核验的研究观点和参考文献。

可先按以下方案准备材料。

题目建议：

《生成式人工智能对大学写作的影响：作用机制、实践效应与治理问题》

综述范围：

- 研究对象：大学生的课程写作、学术写作和毕业论文写作。
- 技术范围：以大语言模型为基础的生成式人工智能，重点考察构思、提纲、起草、修改、反馈和资料处理等用途。
- 分析重点：写作效率与质量、写作能力发展、认知投入、学术诚信、教师评价和教学治理。
- 综述类型：普通叙述性综述。没有完整检索和筛选记录时，不宜称为系统综述。

核心问题：

1. 生成式人工智能改变了大学写作的哪些环节？
2. 相关研究如何评价其对写作效率、文本质量和学习体验的影响？
3. 使用生成式人工智能可能带来哪些能力、认知和诚信风险？
4. 学科、任务类型、学生能力和使用方式是否会影响实际效果？
5. 高校写作教学与评价制度应如何调整？

3000字结构建议：

一、引言（约250字）

说明综述对象、讨论范围和核心问题。交代大学写作包含的主要任务类型，并明确本文关注生成式人工智能介入写作过程后产生的教育影响，不扩展到一般性的人工智能教育应用。

二、生成式人工智能介入大学写作的主要环节（约400字）

按照写作过程组织文献，分别讨论选题与构思、提纲生成、初稿起草、语言修改、内容反馈和资料辅助。比较不同研究对“辅助写作”和“替代写作”的界定，说明使用深度可能影响研究结论。

三、生成式人工智能对大学写作的积极影响（约600字）

围绕以下方面综合文献：

- 是否提高构思、起草和修改效率；
- 是否帮助学生克服写作启动困难；
- 是否改善语言表达、篇章组织和反馈获得；
- 是否对第二语言写作者或写作基础较弱的学生提供额外支持；
- 学生主观感受与文本质量评价是否一致。

本节应比较不同研究的对象、任务和评价方法，避免将个别研究结果写成普遍结论。

四、生成式人工智能带来的风险与争议（约700字）

重点梳理以下问题：

- 学生是否减少独立构思、论证和修改投入；
- 长期使用是否可能形成认知依赖；
- 生成内容中的事实错误、虚假引文和论证表面化；
- 作者身份、原创性和责任归属问题；
- 教师识别、评价和反馈面临的困难；
- 不同学生在工具获取、提示能力和人工智能素养方面的差异。

需要区分已经获得实证支持的结果、研究者的解释和仍待验证的担忧。

五、影响效果的条件与差异（约450字）

从学生写作水平、学科背景、任务难度、使用阶段、教师指导和评价方式等方面比较研究。重点考察不同研究结论是否源于研究对象、写作任务或人工智能使用方式的差异。若现有材料不足以支持某项比较，应明确限定结论范围。

六、高校写作教学与评价的应对（约400字）

归纳文献提出的教学与制度方案，例如过程性评价、写作档案、课堂写作、口头说明、人工智能使用声明、提示设计训练、生成内容核验和学术诚信教育。区分教学建议、学校政策和已经验证的实践效果。

七、研究述评与结语（约200字）

概括现有研究的主要共识、分歧及证据限制。研究不足只能依据已收集文献的覆盖情况判断，不能把“当前材料未涉及”直接写成整个领域的研究空白。

建议准备的材料：

- 4—6篇以大学生为对象的实证研究；
- 2—4篇讨论教师教学、反馈或课堂实践的研究；
- 2—4篇比较人工智能辅助前后写作质量的研究；
- 2—3篇讨论认知投入、作者身份或学术诚信的研究；
- 2—3篇高校政策、权威机构报告或高质量综述。

可使用的检索词：

- 生成式人工智能＋大学写作
- ChatGPT＋学术写作
- 人工智能辅助写作＋高等教育
- 生成式人工智能＋写作能力
- 生成式人工智能＋学术诚信
- generative AI＋academic writing
- ChatGPT＋student writing
- generative AI＋writing assessment
- AI-assisted writing＋higher education
- generative AI＋writing self-efficacy

每篇文献至少整理以下信息：

- 作者、年份、题名和来源；
- 研究对象与样本；
- 写作任务和人工智能使用方式；
- 研究方法与评价指标；
- 主要发现；
- 作者承认的限制；
- 可用于上述哪个小节；
- 掌握的是全文、摘要还是仅有书目信息。

提供文献全文或摘要后，才能据此完成约3000字的综述正文并建立准确的文内引用与参考文献对应关系。
