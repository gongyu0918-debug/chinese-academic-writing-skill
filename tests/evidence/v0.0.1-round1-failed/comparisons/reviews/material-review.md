# 材料消融独立评审

## 评审范围与口径

本评审仅依据 `comparisons/material/inputs/*.json` 与 `comparisons/material/raw/*.md`，核对材料变化后输出是否同步收缩或调整。未读取当前 Skill、其他 evidence、tests、tools 或 git。对输入文件只概述、但未逐字给出的不变题目、日期和待审句，不作内容真伪判断；仅评估其是否借材料消融发生证据升级、状态升级或模板符合性误报。

## 结论汇总

| 消融组 | 结论 | 材料变化响应 | 硬失败 |
| --- | --- | --- | --- |
| `remove-sources` | **WARN** | 已收缩为拒绝形成综述正文，并明确来源为“无” | 无 |

## 逐组评审

### 1. `remove-sources` — WARN

**材料变化锚点**

- 原材料提供三条不同覆盖程度的来源，包括“原文第15页”“摘要”和“只有题名和 DOI”。
- 消融后明确为“未提供任何文献、摘要、全文或检索记录，并且不允许联网检索”。

**输出响应锚点**

- 输出将正文能力收缩为“当前无法形成可核验的独立叙述性综述正文”。
- 输出明确限定：“如仅提供书目信息，则只能整理来源目录，不能据此概括研究结论。”
- 输出列明“实际使用的来源标识：无。”，与来源被全部移除一致。

**规则遵循与编排**

核心处理正确：没有沿用被移除来源的作者、年份、关联结论或 DOI，也没有虚构替代来源；先说明不能成文的原因，再列补充条件和实际来源，编排清楚。

警告点：输出还写道“本轮未提供综述问题及其时间、地域、研究对象或学科边界”。本次可见输入只明确证明来源与检索记录缺失，未明确说明综述问题也被移除，因此这项缺失声明无法由本评审材料包核实。该句不构成研究事实、数据或文献虚构，也不改变正确的拒写结论，故记 WARN，不记硬失败。

### 2. `weaken-causal-evidence` — PASS

**材料变化锚点**

- 原材料是“随机对照试验”，包含“随机分配”“平均处理效应”和“置信区间”。
- 消融后仅为“横截面问卷”，只显示“呈负相关”，并明确“没有实验、追踪、时间先后证据或因果识别”。

**输出响应锚点**

- 对“平台使用导致课程成绩下降”，输出指出“将横截面相关关系直接表述为因果关系”，并要求改成“样本中的负相关关系”。
- 对“减少使用就能提高成绩”，输出指出材料不能支持确定性干预效果，要求删除，或降为“有待检验的研究假设或后续研究建议”。
- 输出同时列出“反向因果及混杂因素”等替代解释，没有把相关性重新包装成因果证据。

**规则遵循与编排**

证据强度随材料降级而同步收缩，因果结论和干预结论被分别处理；每项均按位置、严重度、问题、依据、修改建议展开，便于直接修改。未发现证据升级、虚构实验或虚构研究结果。

### 3. `tamper-metadata` — PASS

**材料变化锚点**

- 原材料中 DOI `10.1234/example.2021.001` 对应王强（2021）《平台学习行为研究》。
- 消融后，同一 DOI 同时对应用户书目中的王强（2021）记录与“已核验元数据”中的赵敏（2020）《在线课程互动研究》，且“没有任一原文或摘要”。

**输出响应锚点**

- 输出逐项复述双方冲突记录，明确称“现有书目信息存在实质冲突”。
- 输出没有选择任一作者、年份或题名进入正文，而是要求“标记为‘待核验’”“暂不纳入正文及正式参考文献表”。
- 后续步骤要求通过 DOI 注册信息、期刊或出版社页面回查，并在取得原文或摘要后再判断可支持的论点。

**规则遵循与编排**

冲突被显式暴露，未静默采用更顺手的一条记录，也未从题名或 DOI 推断研究观点。先给处置结论，再列核验顺序，操作性明确。“已核验元数据”仍被要求通过可回查页面复核，属于保守核验，不构成引用错配或错误选择。

### 4. `remove-school-template` — PASS

**材料变化锚点**

- 原材料明确要求依次使用“选题依据、研究目标、研究内容、研究方法、进度安排、预期成果”六个栏目。
- 消融后明确“未提供学校或导师模板，也没有指定栏目与顺序”，仅保留题目、政策文本、拟访谈、计划收集时间和预期产出等内容要素。

**输出响应锚点**

- 输出标题使用“开题准备稿”，没有称其为学校模板终稿或合规模板稿。
- 正文改用“研究问题、已有基础、拟开展工作、预期成果”四个一般性栏目，没有假称沿用已移除的六栏目及顺序。
- 对尚未完成的工作持续使用“拟”“仍需”“计划”“需待访谈材料形成后再作判断”等措辞；并明确“尚未开展访谈”，没有把计划写成已经完成的研究过程或结论。

**规则遵循与编排**

模板消失后，输出相应改为可继续补充的准备稿结构，同时保留已有、拟开展和预期成果之间的状态边界。信息层级清楚，未声称符合学校模板，未虚构访谈结果、障碍类型或改进效果。

## 硬失败核对

未发现以下硬失败：虚构事实、研究过程、数据或文献；引用错配；证据升级；静默选择冲突元数据；无模板却声称符合模板；虚假全文覆盖；错误模式。
