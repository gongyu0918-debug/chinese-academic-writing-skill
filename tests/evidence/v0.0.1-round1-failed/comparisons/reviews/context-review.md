# 上下文消融独立评审

## 评审口径

- 仅依据 `comparisons/context/inputs/*.md` 与 `comparisons/context/raw/*.md` 逐份对照，不参考 Skill、其他测试或其他证据。
- PASS：交付物类型、任务结构和证据边界均符合输入要求。
- WARN：没有硬性事实错误，但编排中存在可能诱导预设结论、弱化边界或降低稳定性的内容。
- FAIL：出现虚构事实、研究过程或数据，文献发现越权推断，引用或来源标识错配，证据强度升级，交付物类型错误或输出模式错误。
- 篇幅、措辞和单次风格差异不单独作为硬失败依据。

## 配置间比较

### 正确叶是否带来更稳定的任务结构

- A01 中，correct-leaf 把材料范围、现象限度、访谈限度和两类材料关系分层展开，较 entry-only 的结构更集中，边界提示也更连续。
- P01 中，correct-leaf 对“已有基础—拟开展工作—预期成果”的显式标记更稳定；entry-only 虽未越过事实边界，但提前给出了较具体的障碍维度，因此为 WARN。
- L01 中，correct-leaf 没有保持来源清单与正文的一致，反而产生唯一硬失败；entry-only 对 [3] 的“仅用于说明证据不足”标记最完整。
- 因此，正确叶在 A01、P01 的任务结构上有局部增益，但本组样本不能支持“正确叶整体更稳定”的结论：它在 L01 的来源编排上出现了实质退化。

### 全叶是否造成串叶污染

- A01 的 all-leaves 仍只输出三级提纲与补充建议；P01 仍只输出六栏开题报告；L01 仍只输出独立叙述性综述与实际来源标识。
- 三份 all-leaves 输出均未出现其他叶特有的交付物结构、研究阶段话术或无关模块，也未因加载更多叶而扩张事实、研究过程、数据或文献结论。
- 本组可观测结果不支持“全叶造成串叶污染”。all-leaves 三项均为 PASS，但样本量仅为三个任务，不宜据此外推到其他任务类型。
