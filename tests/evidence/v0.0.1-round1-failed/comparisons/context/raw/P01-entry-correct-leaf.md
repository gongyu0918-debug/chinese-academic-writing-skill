# 社区老年人数字政务使用障碍研究开题报告

## 一、选题依据

随着政务服务数字化推进，社区老年人在使用数字政务服务过程中的实际体验及可能遇到的障碍值得关注。本研究拟以社区老年人为研究对象，了解其数字政务使用过程，并为相关服务改进提供参考。

已有基础：目前仅完成了相关政策文本的整理，尚未开展访谈，也未形成关于障碍类型的研究结论。

## 二、研究目标

本研究拟通过后续材料收集，了解社区老年人使用数字政务服务时遇到的具体困难，分析不同障碍的表现及其形成环节，并在此基础上提出有针对性的改进建议。

## 三、研究内容

1. 梳理已有政策文本中与老年人数字政务服务相关的内容，明确研究背景。
2. 根据后续访谈材料，整理社区老年人在数字政务使用过程中的具体经历和困难。
3. 对访谈反映的问题进行归纳，形成障碍类型分析。
4. 结合障碍类型及其具体表现，提出改进建议。

以上内容均为拟开展工作，其中访谈材料收集、障碍归纳和建议形成尚未完成。

## 四、研究方法

前期已采用政策文本整理方式汇集研究背景材料。后续拟采用半结构式访谈法收集材料，围绕社区老年人的数字政务使用经历、具体困难和服务需求开展访谈，并对访谈材料进行整理和归纳。访谈尚未开始，访谈对象范围和具体提纲仍需结合研究条件进一步确定。

## 五、进度安排

- 前期：已完成相关政策文本整理。
- 2026年9月至10月：开展半结构式访谈，收集并整理访谈材料。
- 材料收集完成后：归纳障碍类型，形成改进建议并完成报告撰写。

## 六、预期成果

本研究预期形成两项成果：一是社区老年人数字政务使用障碍的类型分析；二是针对相关障碍提出改进建议。上述内容均为预期成果，不代表已经取得的研究发现或结论。
