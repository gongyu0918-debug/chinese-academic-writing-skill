# 社区老年人数字政务使用障碍研究开题报告

## 一、选题依据

数字政务服务逐步成为居民办理公共事务的重要渠道，但社区老年人在实际使用过程中可能面临操作、理解和服务衔接等方面的困难。研究社区老年人使用数字政务服务时遇到的具体障碍，有助于从其实际体验出发认识数字政务服务的适老化需求，并为改进相关服务提供参考。

目前已完成的基础工作仅为相关政策文本的初步整理，尚未开展访谈，也未形成经验材料和研究结论。后续研究将在现有政策文本整理的基础上，通过访谈收集一手材料。

## 二、研究目标

本研究拟了解社区老年人使用数字政务服务的实际经历，识别其在接触、理解和操作相关服务过程中遇到的主要障碍，分析不同障碍的具体表现，并据此提出具有针对性的改进建议。

## 三、研究内容

一是梳理已收集的政策文本，明确数字政务适老化服务的相关要求；二是围绕社区老年人的数字政务使用经历设计访谈提纲并开展访谈；三是整理访谈材料，归纳使用障碍的主要类型及其表现；四是结合政策要求与访谈发现，提出改进数字政务服务的建议。上述访谈、材料分析和建议提炼均属于拟开展工作，尚未完成。

## 四、研究方法

本研究拟采用政策文本分析与半结构式访谈相结合的方法。政策文本分析主要用于梳理相关制度要求和服务导向；半结构式访谈拟以社区老年人为主要访谈对象，围绕数字政务服务的接触方式、使用过程、困难表现和求助经历等内容收集材料。访谈尚未开始，具体分析将以实际取得并整理的访谈材料为依据，不预设研究结论。

## 五、进度安排

2026年9月：进一步整理政策文本，明确研究问题，拟定并完善半结构式访谈提纲，开展访谈和材料收集。

2026年10月：继续完成材料收集，对访谈材料进行整理和归纳，形成障碍类型的初步分析，并据此撰写改进建议和研究文本。

## 六、预期成果

本研究预期形成两项成果：一是社区老年人数字政务使用障碍的类型分析，二是针对相关障碍提出的改进建议。上述内容均为预期成果，最终表述和结论将以实际访谈材料及其分析结果为准。
