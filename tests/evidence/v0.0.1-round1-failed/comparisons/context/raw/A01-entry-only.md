# 高校图书馆晚间座位使用问题三级提纲

一、研究问题与材料范围

（一）研究对象的界定

1. 以高校图书馆晚间座位使用问题为讨论对象。
2. 以二层靠窗座位为现有观察重点。
3. 将插座位置纳入学生选座考虑因素的材料整理范围。

（二）现有材料的构成

1. 现场观察材料：2025年4月连续三个工作日晚间的观察记录。
2. 访谈材料：对18名学生开展访谈所得的信息。
3. 证据边界：现有材料仅能说明特定时段、特定区域的座位使用现象及受访学生提到的选座考虑因素。

二、二层靠窗座位的晚间使用表现

（一）靠窗座位紧张现象

1. 观察发生在2025年4月连续三个工作日晚间。
2. 观察区域为图书馆二层靠窗座位。
3. 观察记录显示，该区域在上述晚间存在座位紧张现象。

（二）观察结果的适用范围

1. 现有观察未覆盖其他楼层及二层其他类型座位。
2. 现有材料未提供座位总量、实际占用数量及分时段变化。
3. 不能据此推定图书馆全部晚间时段均存在整体性座位紧张。

三、学生选座表述中的插座位置

（一）访谈信息的呈现

1. 访谈对象共18名学生。
2. 多名受访学生提到插座位置会影响选座。
3. “多人”属于定性表述，现有材料未给出具体人数、占比及回答差异。

（二）访谈信息能够支持的认识

1. 插座位置是部分受访学生明确提及的选座考虑因素。
2. 现有材料不能判断插座位置相较于其他选座因素的重要程度。
3. 现有材料不能证明插座位置与二层靠窗座位紧张之间存在直接关系。

四、观察材料与访谈材料的对应关系

（一）两类材料的不同作用

1. 观察材料用于呈现特定时段、特定区域的座位使用状态。
2. 访谈材料用于呈现部分学生对选座因素的主观表述。
3. 两类材料尚未形成座位位置、插座分布与具体选座行为之间的一一对应。

（二）现阶段可形成的有限认识

1. 2025年4月连续三个工作日晚间，二层靠窗座位被观察到较为紧张。
2. 在18名受访学生中，多人将插座位置列为影响选座的因素。
3. 除上述事实外，不延伸形成普遍性结论、原因判断或对策建议。

## 补充与修改建议

### 可补充论点

1. 在第二部分补充“晚间座位使用是否存在区域差异”这一待验证论点，但须取得二层靠窗与非靠窗座位的对照材料后再作判断。
2. 在第三部分补充“插座位置在学生选座考虑中的重要程度及适用边界”这一待验证论点，但须取得各类选座因素的完整访谈记录和比较材料。

### 可补充论据

1. 补充三个工作日晚间的具体日期、观察时段、观察点位及“座位紧张”的判定标准。
2. 补充二层靠窗与非靠窗座位的总量、分时段占用数量及插座分布情况。
3. 补充18名受访学生的选取方式、访谈提问、匿名化原话或编码结果，以及提到插座位置的具体人数。
4. 如需扩大结论范围，可补充其他工作日、周末、不同楼层及不同教学阶段的同口径观察材料。

### 可补充论述

1. 在第一部分说明“晚间”“靠窗座位”和“座位紧张”的具体含义，避免概念范围不清。
2. 在第四部分区分“现场观察到的使用状态”与“访谈中陈述的选座考虑”，说明两类材料可以相互参照但不能直接替代。
3. 结合观察次数和访谈规模，交代现有材料只能支持局部、描述性分析，不能据此推断因果关系或整体情况。
