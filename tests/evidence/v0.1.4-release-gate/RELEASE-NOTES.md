# 中文论文写作 v0.1.4

本版修复三项只读检查脚本中的五类问题，使合法格式少被误报、异常引用不再静默通过。

- 合并引用中的中英文分号不再切断句子，引用覆盖计数保持完整。
- 倒序或超过安全展开范围的数字引用给出明确问题提示，严格检查会报告失败。
- LaTeX 的 document、abstract、enumerate 等普通正文环境可以正常检查，公式与代码环境继续保护。
- Markdown 代码围栏允许更长的同类结束标记，未闭合围栏保护到文件末尾，示例引用不再被当作正文中的缺失标签。
- 消除异常长数字引用触发的重复回溯，保持合法引用编号及检测语义。

写作入口、专项规则与默认文风保持 v0.1.3；本轮写稿未验证出稳定收益的三条候选提示均未进入本版。脚本仍只报告问题，不改写文件，不判断 AI 生成概率。

发布前验证覆盖每类问题的三个修复前复现变体、合法格式与保护区反例、真实稿件扫描回放、全量单元测试、结构校验和可复现打包。具体计数与结果见同目录 RESULT.md。
