## Task A

主题为“同伴反馈的作用路径与反馈角色”，要求仅依据两项材料写 180—260 字叙述性综述。

- Cho 与 MacArthur：28 名本科生；多同伴组收到更多各类反馈；非指令性反馈预测复杂修订；复杂修订与质量提升相关。
- Huisman 等：83 名本科生分别提供或接收匿名反馈；两组改善相近；更多解释性反馈与反馈充分性感知、修改意愿有关；后两者均未与写作成绩增幅显著相关。

### 匿名稿 A（原真实联网写稿中的对应段落）

在写作密集型心理学课程中，多名同伴提供的反馈更丰富，非指令性意见引发的复杂修订与质量提升相关；该研究仅纳入28名本科生，不能断定同伴反馈普遍优于教师反馈[2]。另一项83名本科生参与的真实写作任务显示，反馈提供者与接收者的成绩改善相近；解释性评论与反馈充分性感知及修改意愿正相关，却未直接对应更大的写作增幅[3]。

### 匿名稿 B（writer 2）

同伴反馈的作用取决于反馈形式、修订过程与学习者角色的衔接。Cho和MacArthur将28名本科生分为单一专家、单一同伴和多同伴反馈组，发现多同伴组获得的各类反馈更多；非指令性反馈可预测复杂修订，复杂修订与文本质量提升相关[1]。Huisman等对83名本科生的研究显示，提供或接收匿名反馈的学生从草稿到终稿改善相近。接收较多解释性反馈者认为反馈更充分，修改意愿更强，但二者均未与写作成绩增幅显著相关[2]。这表明同伴兼具反馈提供者和接收者角色，反馈作用可表现为修订方式变化或主观感知差异，其数量不必然转化为成绩增长。

## Task B

主题为“反馈特征、修订来源与写作表现”，要求仅依据两项材料写 180—260 字叙述性综述。

- Lu 等：114 名香港本科生；认知性与情感性反馈均与同伴发起修订正相关；情感性反馈与自我发起修订负相关；反馈接受度只中介认知性反馈与两类修订的关系；两类修订均正向预测写作表现。
- Gao 等：50 名语言学硕士生、1356 个可实施反馈单元；提供与接收反馈特征联合预测修订质量；解决建议较稳定；问题识别只在部分模型显著或边缘显著；不同英语水平组模式不同。

### 匿名稿 C（writer 3，控制性通过样本）

反馈特征、修订来源与接受过程共同关联写作表现。对114名香港本科生的路径分析显示，认知性和情感性反馈均与同伴发起修订正相关，情感性反馈则与自我发起修订负相关；反馈接受度正向中介认知性反馈与同伴发起修订的关系，并负向中介其与自我发起修订的关系，两类修订均正向预测写作表现[1]。另一项对50名语言学硕士生和1356个可实施单元的分析发现，提供与接收反馈特征联合预测修订质量；解决建议较稳定，问题识别仅在部分模型中显著或边缘显著，且预测模式因英语水平而异[2]。两项研究表明，反馈内容、接受度、修订来源和学习者水平共同关联修订成效。

### 匿名稿 D（writer 2）

反馈特征经由反馈接受和修订来源关联写作表现。Lu等对114名本科生的路径分析表明，认知性与情感性反馈均与同伴发起修订正相关，情感性反馈与自我发起修订负相关；反馈接受度分别正向和负向中介认知性反馈与这两类修订的关系，两类修订均正向预测写作表现[1]。Gao等分析50名语言学硕士生两轮双盲多同伴反馈中的1356个可实施单元，发现提供与接收反馈的特征联合预测修订质量；解决建议是较稳定的预测项，问题识别仅在部分模型显著或边缘显著，且不同英语水平组的模式不同[2]。反馈成效受反馈特征、接受过程、修订来源及学习者水平共同影响。

- 匿名稿 C：PASS。保留了关系类型、主客体和范围。
- 匿名稿 D：FAIL。把局部中介拼成完整路径，并用“共同影响”升级关系强度。
