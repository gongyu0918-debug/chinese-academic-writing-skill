# v0.0.3 引用语义修复报告

## 结论

引用模块已从“来源存在、元数据和格式”扩展为“文献身份、原文证据、原子论断语义、出版状态、格式对应”分层门禁。修复有真实效果，但未消除所有模型波动：最终 4 份盲写回归中 2 份通过；2 份失败集中在同一个材料组，未达到再次修改的 3 稿、2 任务阈值。

## 修复依据

修复前，同类“把局部关系串成未检验结论”的问题在 3 份稿件、2 个任务、2 个 writer 中复现。第一轮软修复后仍在 3 份稿件、2 个任务中复现，因此第二轮只强化段首、过渡和段末综合句门禁。第二轮后，同类失败降为 2 份稿件、1 个任务，按约定停止修复。

## 新增规则

- DOI 解析后仍回读题名、第一作者、年份或版本族；身份错配即阻断。
- 证据账本记录主体、关系类型、对象、方向、否定、范围、允许措辞与禁止增强措辞。
- 描述、相关、预测、中介、因果和机制不可互换；不把相邻局部关系拼成未检验整体路径。
- 段首、过渡、段末综合句同样进入写后语义门禁；降调词不能补足证据。
- 出版状态记录渠道和日期；“本次未检出更新”不升级为“确认未撤稿”。

## 真实联网链

联网 agent 检索并核对 3 篇同行评审论文，记录 DOI、题名、第一作者、年份、访问层级、原子论断及 Crossmark 状态，生成顺序编码正文和文后参考文献。来源 [3] 全文受限，正文仅使用出版方摘要可见结论。确定性引用审计只能确认编号覆盖和正文—文后对应，不能替代语义冷审。

## 剩余风险

- Task A 的两份回归仍出现整体路径拼接，说明 Prompt 约束不能保证每次采样都通过。
- 联网稿末句“课程设计宜重视……”属于从研究证据提出的建议，尚未由独立冷审确认其论断强度；保留为单例风险，不据此改规则。
- Crossmark 或数据库本轮未列更新，不等于永久确认未撤稿；发布状态应按任务日期重新核验。
