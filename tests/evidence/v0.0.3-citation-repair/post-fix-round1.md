# 第一轮软修复后的真实写稿冷审

第一轮在 citation reference 中加入原子论断、关系类型、主客体、否定范围及写后语义门禁。两个新鲜 writer 分别处理 Task A、Task B，并各自继续处理另一任务，共 4 份输出。

## 稿 1（Task A）

同伴反馈的作用既取决于反馈内容，也与学习者所处的反馈角色有关。Cho和MacArthur将28名本科生分入单一专家、单一同伴和多同伴反馈组，发现多同伴组获得的各类反馈更多；其中，非指令性反馈能够预测复杂修改，而复杂修改与质量提升相关[1]。Huisman等对83名本科生的研究则显示，提供与接收匿名反馈者从草稿到终稿的改善程度相近；收到较多解释性反馈者更认可反馈的充分性，也更愿意修改，但这两项感知均未与写作成绩增幅显著相关[2]。由此看，反馈作用可能沿着“反馈特征—修改行为—文本质量”展开，提供者与接收者均可受益；主观认可和修改意愿却未必直接转化为成绩增长。

## 稿 2（Task B）

反馈特征与写作表现的联系，需结合修订来源及反馈角色考察。Lu等对114名香港本科生的路径分析显示，认知性和情感性反馈均与同伴发起修订正相关，情感性反馈与自我发起修订负相关；反馈接受度还分别正向、负向中介认知性反馈与两类修订的关系，而两类修订均正向预测写作表现[1]。Gao等分析50名语言学硕士生两轮双盲多同伴反馈中的1356个可实施反馈单元，发现提供与接收反馈的特征可联合预测修订质量，解决建议较稳定，问题识别仅在部分模型显著或边缘显著，且预测模式随英语水平而异[2]。这表明，反馈作用与接受程度、修订主体及语言水平共同相关。

## 稿 3（Task B）

反馈特征可通过修订来源关联写作表现。114名香港本科生的路径分析显示，认知性、情感性反馈均与同伴发起修订正相关，后者与自我发起修订负相关；反馈接受度正向中介认知性反馈与同伴发起修订的关系，负向中介其与自我发起修订的关系，两类修订均正向预测写作表现[1]。对50名语言学硕士生1356个可实施反馈单元的分析显示，提供与接收反馈的特征联合预测修订质量。解决建议是较稳定的预测项，问题识别仅在部分模型显著或边缘显著，不同英语水平组的预测模式有别[2]。这说明反馈作用与反馈特征、接受过程、修订来源及语言水平相关[1-2]。

## 稿 4（Task A）

同伴反馈通过反馈形式和参与角色影响修订。Cho和MacArthur将28名本科生分为单一专家、单一同伴和多同伴组，发现多同伴组收到的各类反馈更多；非指令性反馈可预测复杂修订，复杂修订与写作质量提升相关[1]。Huisman等对83名本科生的研究显示，提供与接收匿名反馈者从草稿到终稿的改善相近。接收更多解释性反馈者认为反馈更充分，也更愿意修改，但两项指标均未与成绩增幅显著相关[2]。这表明，反馈数量与方式可能促进修订，反馈角色、感知与修改意愿却未必对应更高成绩[1-2]。
