# pilot-R1 独立只读审稿报告

## 总体结论

本轮不能判定候选规则具有可归因的稳定增益。A 两臂均完整保留取舍，差异主要是表述清晰度、重复和长度负担，属于审稿偏好而非规则直接作用；C 的干净输出也未必与本次“比较/压缩规则”DIFF有关，只能算偏好胜负。B 在 qwen3.8-flash 上出现目标相关的状态遗漏：候选仍写“部署候选”，却删去“尚未进行现场部署测试”。该遗漏与候选规则的因果归因和可复现性仍待复测确认，不在单稿中判定为严重或可复现退步。

执行结果本身不足以证明质量：12 个子运行的 `returncode` 均为 0、`invalid` 均为空、`commands` 均为空，且 12 个 final 文件 SHA-256 均与 result JSON 记录一致；但这些只说明运行与落盘完整，不说明内容合格。

## 归因核对

设置层面的差异可归因：

- `binding.json` 中 `main_commit` 与 `candidate_head` 同为 `07f8a0ad405083ab1fc98d80cd1dd40ce4e3645e`，但两臂快照指纹不同。
- 快照对比显示，候选与基线唯一实质差异是 `references/academic-writing.md` 中新增两行规则，内容与 `../candidate-rule.txt` 完全一致。
  - 候选新增规则要求：比较或压缩时保留会影响取舍的代价、负向变化或相反结果；不把总量改善写成各项改善；不把单项领先写成全面最优；尊重作者已定侧重。
- 同一任务、同一模型、同一 effort 下，main/candidate 的 `prompt_sha256` 不同；不同模型使用同一 case 的对应 prompt hash 一致。这符合“只改变候选规则”的绑定设计。
- 执行面未见工具调用：12 个 result 的 `commands` 均为空。trace 中未见 command item；这与任务“不联网、不读取文件、不委派”的要求一致。
- 非致命运行噪声：stderr 中有 PowerShell shell snapshot、WebSocket 426 后回退 HTTP 等警告；其中一个运行还有 state DB migration 警告。所有相关 result 仍为 returncode 0、final 非空。这些噪声不作为质量证据，也不改变内容判定。
- 绑定明确为“full frozen entry plus one routed leaf, supplied inline”，不是端到端文件加载验证，也不能证明生产 Hook 或完整路由链路无回退。

## A 任务逐项复核

### 必须保留的原始事实与状态

- 原布局总搬运距离 931.5m；方案Ⅰ 833.1m，下降 10.56%；方案Ⅱ 867.9m，下降 6.83%。
- 包装区到成品区的一条路线：原 20m，方案Ⅰ 35.5m，方案Ⅱ 43.5m；原表标记为负向变化。
- 方案Ⅱ有 3 个包装区，布局柔性优于只有 2 个的方案Ⅰ。
- 两方案改动成本大致相近。
- 作者已确定以总搬运距离为优先依据并选用方案Ⅰ；不得重选、增加权重、推断已投产或新增成本和生产效率实测。

### m0-A：qwen3.8-flash

基线保留了全部给定事实，尤其正确写出该路线的负向变化和方案Ⅱ的柔性优势，并把选择Ⅰ表述为以较少包装区和路线延长为代价。主要不足是“作者在其余差异中……”表述略显含混，但未改变事实关系。

候选同样保留全部关键事实，并更明确地区分总量改善与局部路线变化：先给出两方案相差 34.8m，再说明该路线 20m→35.5m/43.5m，且Ⅰ的延长 15.5m 小于Ⅱ的 23.5m。它还把方案Ⅱ柔性优势与方案Ⅰ选择代价放在同一取舍中。相比基线，候选更符合新增规则的意图。34.8m、15.5m、23.5m 是给定数字的直接差值，属于入口允许的简单算术；风险只在于后续不得把这些派生差值升格为独立实测证据。

结论：持平，评价分歧。基线更简洁，候选更明确但不必要地更长、重复增加；两臂都已完整完成目标取舍。此差异是偏好胜负，不能归因于候选规则。

### m1-A：ollama glm-5.3-flash

基线保留全部关键事实，并明确“并非所有路线都缩短”，随后给出该路线的负向变化、柔性差异和成本相近。轻微风险是“并非所有路线都缩短”从一条已给路线推广为对所有路线的判断；逻辑上可由该路线推知“并非全部”，但材料只给了一条路线，表述应更贴材料。

候选保留全部关键事实，直接以总搬运距离切入，随后给出同一路线的反向变化、方案Ⅱ的包装区数量与柔性优势、成本相近，并以“接受路线增加和柔性不足，换取总搬运距离更大幅度的下降”收束取舍。未新增机制、未重选、未推断投产。相比基线，候选对材料边界的贴合度更高。

结论：持平，偏好候选表述。两臂均完整；候选更收束，但仅“写得更清楚”不足以归因于规则。A 不构成可归因稳定增益证据。

## B 任务逐项复核

### 必须保留的原始事实与状态

- 同一设备、相同输入尺寸、同一测试集。
- 模型甲：准确率 92%，推理速度 40 帧/秒；模型乙：准确率 90%，推理速度 60 帧/秒。
- 任务要求至少 50 帧/秒；作者因此选择模型乙作为部署候选。
- 连续遮挡样本上：乙降至 81%，甲为 86%；这些样本属于同一测试集。
- 乙满足速度要求，但总体准确率和遮挡表现逊于甲。
- 该取舍支持当前候选选择；尚未进行现场部署测试。

### m0-B：qwen3.8-flash

基线完整保留设备、输入、测试集、两个模型的总体指标、速度阈值、连续遮挡结果和“尚未进行现场部署测试”。它将甲的速度不达标、乙的速度达标与乙的准确率劣势放在同一比较中，没有新增结果或后续计划。

候选保留了主要指标和选择理由，也保留了连续遮挡结果，但删去了“尚未进行现场部署测试”。候选仍使用“部署候选”一词，该词本身没有断言已经部署；缺失的是明确研究状态。压缩可以删冗余，但此句承担部署状态边界，删去后读者需要从“候选”一词自行推断未完成部署。该遗漏在本稿中成立，但是否由候选规则引起、是否会在重复运行中出现，仍需另行确认。候选也没有明确保留“这一取舍支持当前候选选择”，不过这可由“作者因此选择”部分承担，损失小于部署状态边界。

结论：基线更好。候选的问题不是字数或词频，而是部署状态遗漏；本轮不把它升格为严重或可复现退步。

### m1-B：ollama glm-5.3-flash

基线完整保留全部关键信息，包括速度阈值、选择理由、连续遮挡结果和“候选尚未经现场部署测试”。表述略长，但内容闭合。

候选同样完整保留设备、输入、测试集、总体指标、速度阈值、选择理由、连续遮挡结果和“现场部署测试尚未进行”。它把“作者因此选择模型乙作为部署候选”作为取舍核心，没有添加现场成效或后续计划。相比基线，候选更简洁且未丢失必要边界。

结论：持平，偏好候选表述。两稿均保留关键边界；候选更简洁，但差异不足以归因于规则。B 任务在本轮内结果不一致，m1 的偏好优势不能抵消 m0 的状态遗漏。

## C 任务逐项复核

### 必须遵守的审稿边界

- 只审不改，不重写正文。
- 检查论断范围与材料关系。
- 底稿中的“可能更适合……”是有限强度条件性分析，不能只因该情境未被直接测量而否决或强索次级材料。
- 没有实质问题应明确无需改动，不为凑意见要求测量所有候选解释。

### m0-C：qwen3.8-flash

基线逐句核对三处论断，均给出位置、问题、依据和修改建议，并明确“无需改动”。它正确说明“多品种同时下线”是有限强度的条件性推测，未把包装区数量改写为已验证机制，也未要求补测。主要不足是末尾“核查说明”包含工具、委派和复核范围等过程性内容，超出用户要求的审稿意见本体。

候选同样逐句核对，明确“无需改动”，并以表格承载位置、严重度、问题、依据和必要修改建议。它特别说明不能只因柔性或候选情境未被直接测量而判为事实错误，符合任务要求。轻微风险是“非本轮修改要求：该句若将来用作选型理由……需补实际依据”带出未来条件，虽然标明非本轮要求，但仍略扩大审稿输出；这不构成重写或凑意见。

结论：持平，偏好候选输出。差异主要是交付形态更贴近“只审不改”的要求，但与比较规则DIFF未必有因果对应，不能计为规则增益。

### m1-C：ollama glm-5.3-flash

基线用表格核对首句、第二句前半和后半，明确未发现实质问题、无需改动。它正确承认“多品种同时下线”是标注了“可能”和“条件性分析”的作者推测，未因未测量而否决，也未改写正文。

候选用分项条目核对同样的位置，结论为“无需改动”，并明确该分析以“可能”限定强度、未把包装区数量差异写成已验证需求、机制或投产结果。没有重写正文，也没有要求补测。相对基线，候选更直接，过程残留更少。

结论：持平，偏好候选输出。C 任务在本轮两个模型上均未回退，但干净输出不能归因于本次比较规则。

## 共同问题与限制

- B 任务的候选压缩在 m0 上漏掉部署状态说明，是本轮最重要的实质风险；这正是“返回成功、更短、词频更少”不能等同于合格的反例。该遗漏不能单凭一稿判定为严重或可复现。
- A 的“更清楚”和 C 的“更干净”是偏好胜负，不等于可归因目标动作；本次比较规则DIFF没有在这两类差异上形成可确认因果链。
- A 中候选加入的派生差值均为简单算术，允许使用；但不得被后续升格为独立证据或统计结论。
- C 中两臂都能守住“有限条件性分析不被否决”的边界；候选的主要优势是审稿输出更干净，而非内容覆盖面突然扩大。
- 每对只有一次运行，未做重复采样、外部盲审或统计检验；不能把本轮 6 对结果推广为长期稳定性，也不能把 m0-B 的单稿遗漏判成可复现回退。
- 后续新鲜复测由主线程针对压缩边界与数字口径另行执行；本报告只校准本轮证据，不扩实验。
- 本轮只测 inline frozen entry + 单专项叶，不覆盖完整文件加载、Hook、生产安装或多轮长稿场景。
- 基线在 B 与 C 上已经能完成多数要求，候选输出有若干偏好优势；m0-B 的状态遗漏和单轮设计共同限制稳定增益结论。
