# 从公开论文与开题范例提炼规则（2026-10-09）

## 结论与变更边界

本轮从2篇已发表论文、2份高校公开填充开题范例和1篇作者署名指导中提炼可迁移的判断。论文读取范围各不相同，见下表；不是5份均已全文审查，更不是5个真实项目经过验证。新增的模板内容隔离提示经过两轮实写后取消。运行规则、版本及安装包保持0.1.7；本轮合并研究记录、原始稿件、模型绑定和审稿纠偏，不发布新版本。

## 提炼后的审稿判据与当前规则对应

以下为维护与评估依据，不是额外默认加载的Prompt叶，也不是新强制模板。

| 判据 | 何时实际使用 | 现版对应与本轮处理 |
| --- | --- | --- |
| 主次按对研究问题的解释作用判断 | 关键证据、会改变结论的反证或限定应展开；背景与重复信息按理解需要压缩。作者要求逐项呈现时照办。 | SKILL.md“执行与交付”第2项已明确；不引入等长、固定句位或按资料数量分配篇幅。 |
| 方法要能回答具体问题 | 在作者已有方案和材料内解释方法作用；不能因为只有方法名就替作者补招募、编码、试验或进度。 | 开题叶“状态与任务链”与据材料起草第4、6项已覆盖。 |
| 缺口是已有解释在当前对象上的不足 | 用已读来源建立视角差异和适用边界；不从关键词少或题名未检出断言研究空白。 | 来源服务、综述叶及开题叶伪研究空白复核已覆盖；不新增强制综述结构。 |
| 创新归属与比较范围必须具体 | 区分已有工具、组件与作者给出的改动；比较结论对应对象、条件和指标，承认材料中的取舍。 | 入口不可改变事实、引用与贡献；普通叶保留主体、对象、情境、变量及强度已覆盖。表中取舍用于今后审稿材料，未单独验证新Prompt。 |
| 限定放在影响判断的位置 | 同一主张的证据、解释、限定尽量一起处理；结论只汇总已论证内容。 | 普通叶“规划、成段与文体”已覆盖；不强制每段、每节追加局限或理论对话。 |
| 带内容模板先识别内容归属 | 区分栏目与作者当前材料、示例数据、指导批注；作者明确采纳的安排仍是当前方案。 | 通用事实与模板优先级已覆盖。更细提示作为唯一候选进行实写，结果未支持准入，取消。 |

## 未吸收为运行规则的内容

不把单校模板变成通用章数、段长或句位；不把开题预期改成已经发现；不根据发表身份认定方法有效；不为凑完整新增预算、实验、进度或核心贡献。多证据分工、创新归属和指标取舍可用作后续真实材料的审稿情境，但本轮没有声称新Prompt已提高这些情境的质量。
