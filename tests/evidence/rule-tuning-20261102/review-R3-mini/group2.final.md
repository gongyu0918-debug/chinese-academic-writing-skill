## 核对基准

被评目标为"原稿"（乙本、丙本眉批 → 异文不能证明改定 → "犹疑"仅为可讨论的局部读法 → 不能认定思乡之情、不能提升为主旨）。判定依据只用给定材料：仅两处眉批与相邻诗句；无作者定稿记录、传记材料及全诗对读；段落目的为界定局部文本解释的可达范围。四组共 8 篇稿件中，X 全部等于原稿原样；Y 在 r1 两组中亦等于原稿原样，在 r2 作者模型 0 中为"原稿 + 追加的材料段"。

## 任务 D3_delete_control_r1

### 作者模型 0（X 与 Y 逐字相同）

两稿无任何差异，六项均无差别可指。

- 事实：均以"只据现存乙本与丙本的眉批"为唯一依据，"作者已改定原稿""作者确有思乡之情""全诗主旨"三项均只被否证，未被肯定，与材料设定不冲突。
- 状态：全部命题为"不能证明／只说明可能／可讨论／不能认定"的边界陈述，无未经核验却写成已定的项；"抄手可能见过另一种措辞"保留可能性状态，未升级。
- 对象：限制对象为"这处异文"与"'犹疑'这一局部读法"，未越及全诗或其他诗句。
- 推断强度：与材料上限一致——局部读法可讨论、作者意图不可判定；"更不能把这种犹疑提升为全诗主旨"正是"无全诗对读"所要求的范围界定，非可删的冗语。
- 交付范围：仅正文，未夹带材料说明或作者提示，符合"只输出正文"。
- 过审：X 通过；Y 通过。

### 作者模型 1（X 与 Y 逐字相同）

同模型 0：两稿逐字一致，事实、状态、对象、推断强度、交付范围五项均无差别，正文内容与原稿完全一致。

- 交付范围与过审：X 通过；Y 通过。

## 任务 D3_delete_control_r2

### 作者模型 0

- 差异定位：仅 Y 有差异，位置在末句"全诗主旨。"之后，追加了"材料：只有这两处眉批和相邻诗句；无作者定稿记录、传记材料及全诗对读。当前段旨在界定局部文本解释能达到的范围。"一段；正文主体部分与 X 逐字相同。
- 事实：Y 追加段复述的正是材料本身（同样的两处眉批与相邻诗句、同样的三项缺失），未引入任何新事实，与稿内主张也未冲突。这一点上 Y 与 X 无事实性矛盾。
- 状态：Y 追加的是材料说明而非论断，故未新增任何确定性主张；稿内原有的可能性、可能性限定（"可能见过""可讨论"）与 X 完全相同。
- 对象：论断对象未变，仍限于"这处异文"与"'犹疑'这一局部读法"；追加段不扩展主张对象，但把元信息并入了正文载体。
- 推断强度：正文推断强度与 X 一致，未因追加而增强或削弱。材料中"无作者定稿记录、传记材料及全诗对读"并未被转写为稿内的肯定性证据，Y 也未据此下任何新结论。
- 交付范围：此处构成实质越界。原任务为"只删不改，保持全部原词及顺序""只输出正文"，Y 的行为是整体追加新句，既非删除，也不属于被删的原词；而材料与"当前段旨在……"属写给审阅者的说明（作者模型说明、段落任务说明），不属于论文正文，放进输出即违反正文-only 要求。材料已写过"未测"项并不要求每稿在正文里复述一遍，稿内已有的三处负向限定已承担该信息。
- 过审：X 通过；Y 不通过，退回到与 X 同形的正文-only 形态。

### 作者模型 1（X 与 Y 逐字相同）

两稿均等于原稿原样，无差异位置可指。

- 事实、状态、对象、推断强度、交付范围：与 r1 各稿一致，无差别。
- 过审：X 通过；Y 通过。

## 结论

可用稿为全部 X，以及 r1 作者模型 0/1 与 r2 作者模型 1 的 Y。唯一不可用的是 r2 作者模型 0 的 Y，其问题仅在交付范围（追加非正文、且非删除操作），其事实、状态、对象与推断强度均无问题。

两点说明：以上仅针对给定材料与本次任务的可核对项，未作全稿定性；此外，单一稿件出现一次交付越界，属于本次实例的具体事实，不足以推断某项规则的必然因果，也不构成可复现的一般结论。
