## 多模型结果意味着什么

| 关注点 | 可以确认的观察 | 尚不能确认的结论 |
| --- | --- | --- |
| 多层否定与外围免责 | v1/v2在MiniMax的D2重复保留绕句；v3该题较直接，但E1四份候选都保留外围尾部，基线四份中一份保留 | 简短或正向规则整体优于/劣于现版；C2已稳定去掉免责 |
| 必要限定 | D3大多保住人文来源、局部读法和两层推断边界；N3/E2方法、人工归属和排除条件大多保住 | 所有场景下均不会误删；保留全部限制就是更好 |
| 研究状态与有限分析 | 大多数混合进展正确，仍有待讨论补成暂不安排、增加后续步骤、有限解释写成已发生变化等具体问题 | 这些问题全由改词造成，或全是可忽略的模型噪声 |
| 任务与交付 | 两臂都见正文外说明、背景混入、只审字段外扩；原题背景混入分别出现在v2候选和后轮基线 | 单次目标误读证明某条规则有害；静态规则存在即可证明执行稳定 |
| 独立复核 | 能找出一些问题，也漏掉正文外说明，误读人数、方法缺失和引号来源，有时以“可用”掩盖未完成润色 | 多数评审票可取代材料核验；增加复核数量必然提高质量 |

同一题重复用于观察该题波动，不能当作多个独立任务或全局故障率。R1/R3/R4基线字节相同而表现变化，仍不能单独排除规则与任务、上下文显著性、宿主和采样的交互。对称标准同样约束正向收益与负向风险：该修正的稿件明确记录，工程暂缓不改写成因果否证。

## 验证边界与下一诊断点

本轮比较的是自足片段中的规则文本作用，没有验证自主加载、宿主自动委派闭环、整篇学位论文、真实来源认证、外部规范、Word排版或平台安装。服务端权重版本、temperature、seed和实际收到的请求字节未开放核验；本地模型标识/effort一致只证明记录一致。各批最多4个writer并行，R2/R3短时重叠，独立评审也可能与写稿重叠，上游负载未受控。

下一次有针对性的诊断应比较“同一规则下写稿—真实独立复核—按意见修订”的完整交付与单次内联写稿，保留未修复原稿；同时单独测试明确正文分界与自然混合输入。它们是本轮暴露的未决路径，不是已证明的原因，本轮未继续新增普遍写作禁令来替代诊断。
