结论先给：八份审稿文本里六份可用，两份不可用。不可用的是 K 任务的作者模型 0 稿 X 和 M 任务的作者模型 0 稿 X；其余各稿对任务禁止事项（未显著不写成无关系或中介被否定、较新不当作已确认、未校读不推定完成）全部守住，给定的数字与原句都未改动。以下逐对说明。

## 任务 K：版本数量冲突

### 作者模型 0

| 维度 | 稿 X | 稿 Y |
| --- | --- | --- |
| 事实 | 断言"这次请求里没有附上要审的文本”，给定两句均未出现 | 两句原句完整保留在意见中 |
| 状态 | 无法建立任何状态判断，因为材料被当作不存在；要点6只描述这类冲突的一般特征，未落到给定句 | 两处均按"拟"处理；冲突登记为未决；"尚未校读"列为一致项并明确无需修改（显式的"无问题"表述） |
| 对象 | 一份设想的完整开题报告（"收到正文后按……出意见"） | 就是两句状态表述及其相互关系 |
| 推断强度 | 对"是否有材料"作出与任务给定相反的断言；对数量冲突本身没有形成意见 | 停在"向作者索取出处与取舍依据"，不选定数目，不宣布哪个口径正确 |
| 交付范围 | 8条通用检查要点并请求提交开题全文，超出"仅限这两项材料" | 限定在两句之内；下游推测部分已自注无法核对 |
| 过审 | 不可用 | 可用 |

稿 X 不过审的定位：第一，开头句与给定材料相悖，两项材料恰恰是“拟比较两个版本，尚未校读正文”与“拟比较四个版本，尚未校读正文”这两句；第二，任务核心动作“指出数量冲突”未完成，“两个/四个”冲突全稿未出现，连带“较新不当作已确认”与“不推定已校读”两项约束都落空；第三，8条要点无一条挂在给定两句的具体位置上，与“只报能指出位置与依据的问题”不符。

稿 Y 可用，两处限度其稿内已自注：第2行“若下游栏目按四个版本铺开”是对未给内容的条件性推测（已明注“现有两项材料不含其他栏目，无法核对”）；第3行把“版本”指代是否同一口径列为待补说明。两处都不选定数目、不新增事实，不构成实质问题。

### 作者模型 1

| 维度 | 稿 X | 稿 Y |
| --- | --- | --- |
| 事实 | 两句原句准确引用，无材料外内容 | 同稿X；另自注"未读取比较对象的正文" |
| 状态 | 冲突定级"阻断"独立成行；“草稿较新这一点不构成确认依据”明写；“尚未校读”列为一致项并禁止后续推定 | 冲突定级"高，阻断确认”；结尾说明"不因此视为已确认安排”、校读不推定完成 |
| 对象 | 两句状态表述，另附待作者确认清单（数目及来源材料） | 仅两句状态表述 |
| 推断强度 | 不选定数目；要求确认后再写入具体数目 | 不选定数目；只要求先列"版本数量待确认" |
| 交付范围 | 意见表加总评、一致项、待确认项，仍以两句为界 | 单行意见加两条结尾说明，范围最窄 |
| 过审 | 可用 | 可用 |

两稿都可用，差别在粒度：稿 X 把“易被读成已确认的研究安排”单独成行，并在建议里给出示例性计划写法（"如‘版本数目待讨论’"），这是给作者的建议选项而非正文改写；稿 Y 把同一要求并入一行和结尾说明，也未追问出处。两者都把具体写入推迟到作者确认之后。

## 任务 M：目标句"这提示X可能经由Y改善Z。"

### 作者模型 0

| 维度 | 稿 X | 稿 Y |
| --- | --- | --- |
| 事实 | 依据栏引用给定材料中不存在的"组间差异"“期末成绩"“自我效能感与成绩关联"“8周" | 三项给定结果（X-Y相关、Y-Z未发现显著相关、无整体路径检验）全部映射，无添加 |
| 状态 | 给定三项结果在意见中未被使用 | 非显著保持为状态陈述；可支撑的说法收窄为"路径未被检验"与"Y–Z环节未观察到显著关联"两条 |
| 对象 | 四处未给段落句；目标句全篇未出现 | 三处位置全在目标句内，自注"未审查前后文" |
| 推断强度 | 给未给句配"高"级问题与三选一改法；对目标句没有推断意见 | "经由Y""改善Z"均定阻断；"这提示……可能"单独说明弱化词不能补足缺证；参照句自注"不要求照用" |
| 交付范围 | 违反"只对这个目标句""不审查未给的前后文"两条 | 限定在目标句内 |
| 过审 | 不可用 | 可用 |

稿 X 不过审的定位：第一，被审的四句（"干预后学生的学业成绩有改善"等）都不在给定材料中；第二，依据栏的“已给材料记载的是干预后实验组与对照组的组间差异”等内容无材料位置，给定材料只有三项结果；第三，目标句本身未被审到。

稿 Y 可用：明确“未发现显著相关”不代表无关系或中介被否定，参照句“现有数据不足以判断”的强度与材料一致，且交付形态是意见而非改稿。

### 作者模型 1

| 维度 | 稿 X | 稿 Y |
| --- | --- | --- |
| 事实 | 三项给定结果映射正确 | 同稿X，无新增事实 |
| 状态 | 明写"不得把Y-Z未显著改成无关系或中介被否定" | 同左；另写"只是这些结果不能为这句提供支持" |
| 对象 | 仅目标句 | 仅目标句；另注句首"这"的指代不外推 |
| 推断强度 | "经由Y＋改善Z"合并为一个"高”；保留出路为补检验，或标待检验假说并依赖明确文献依据 | "经由Y"高、"改善"中；单独指出「提示」「可能」不能补证；若保留路径须补整体检验或交代Y-Z未达显著的边界 |
| 交付范围 | 单条意见 | 两条意见加范围说明 |
| 过审 | 可用 | 可用 |

两稿都可用。可指出的差别有三点，属归档与范围差别而非事实差别：其一，“改善”定级一高一中，实质判断一致，我不做定级裁判；其二，稿 X 的保留分支提到文献依据，本轮材料不含文献，这是保留路径才触发的条件门槛，不等于新增文献事实，但该分支在本轮不成立，须等依据实在场；其三，稿 Y 对限定词的不足和“这”的指代各有一条显式说明，稿 X 缺这两项说明但不因此失守任务禁区。

## 收尾说明

两处不可用是这一轮各自的独立失误：K 的错在事实前提（断言无文本），M 的错在范围与事实来源（审了未给段落）。失败形式不同，不能从中推出对任一模型的一般规律或可复现结论，也不影响其余六稿逐项过审的判定；本意见只对这两轮给定文本成立。
