## 被证伪或未获支持的假设

### 两行候选能稳定减少强行综合

未获支持。`FALSE_CROSS_SOURCE_LINK` 自动计分为无方向信号；人工纠正两处 Baseline 漏标后为 `baseline_only=2`，仍未达到预注册 3:0 收益门槛，只能记 `AMBIGUOUS`。

### 两行候选能减少“稳定、可重复”式放大

被本轮重复结果否定为无方向信号：四次分别为 Candidate-only 1、Baseline-only 1、双方出现 1、双方未出现 1。

### 两行候选可能让模型拒绝合法综合

该回退假设未出现。H2 中两臂均 4/4 明确联合归纳 S1/S2 的共同参与提升；原第三整轮 Candidate 的 H2 阳性控制经语义复核为 3/3。候选没有普遍压制合法综合，但也没有带来新增收益。

### 两行候选能稳定改善来源就近标注

未获支持。自动计分无方向信号；人工补回两处漏标后为 Candidate-only 1、Baseline-only 1、双方出现 1、双方未出现 1，仍无方向信号。

### Candidate 更短即可视为减负

被证伪。24 稿总量只减少 272 个可见字符（2.4%）；Ollama -563、Alibaba -338、MiniMax +629。机械合规为 Baseline 9/12、Candidate 5/12，缩短中混有截断、超长和来源 ID 缺失，不能把字数下降直接解释为减负。

### 原始 Candidate 失分都代表 DIFF 回退

被证伪。原始严格分数为 Candidate 7、Baseline 5，但决定局胜率 58.3%、Candidate-only hard fail 和 MiniMax 净负使旧门 FAIL。逐稿复核显示多数 Candidate 失分来自标题、长度、来源标记、事实或文献类型误写，与两行 DIFF 没有机制关系；这些仍是绝对质量问题，但不能直接计规则回退。

## 确认的真实写稿问题

跨 provider 反复出现的高负担问题是：先补未检验的任务、样本、语言或情境解释，再用“材料不足”收回；把访谈共现升级为机制；擅加研究趋势和背景；把摘要可见状态写成综述纳入范围；把“每周两句”移成“每周两次”；把元数据来源写成“一书”；擅加题目；字数失控；来源 ID 缺失或格式错误；以及“效果层面—体验层面—综合来看”的模板链。

下一候选如继续，应只检验“猜原因后再收回”这一原子，并同时设置来源明确报告调节效应的阳性控制。本轮不根据已见答案追加规则或改门槛。
