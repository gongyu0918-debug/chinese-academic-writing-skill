# D3 独立文献综述据材料起草

根据下列来源卡起草 700—1000 个可见字符的独立叙述性文献综述片段（去除空白后计数，标点和来源 ID 均计入），只输出正文。围绕“社区老年人获取数字健康信息的障碍与支持条件”组织比较，不连续逐篇摘要。每项实质观点后保留正确的来源 ID；不得把元数据写成研究发现，不得把相关关系改成因果，也不得把当前四项材料的缺口写成整个领域的研究空白。

来源卡：

- `[S1]` 已读全文。周宁、李凡（2022）对两个城市社区 186 名 60 岁以上居民开展横断面问卷。文中报告，较低的数字技能自评分与较少使用线上健康信息服务相关；作者明确说明横断面设计不能支持因果推断。
- `[S2]` 仅有摘要。陈静（2023）摘要称，界面步骤较多与老年受访者较低的继续使用意愿相关；摘要没有给出样本量、地区、量表或效应值。
- `[S3]` 仅有元数据。王明（2021），《社区数字健康服务中的代际差异》，期刊和 DOI 已记录，正文与摘要均未读取。
- `[S4]` 已读全文。赵琳等（2024）比较三个社区个案，发现线下志愿者协助可以帮助部分受访者完成信息检索；研究同时指出个案数量有限，且没有测量长期使用变化。

成稿应体现来源层级和可支持强度。可以作审慎综合，但不要虚构共同结论、争议、趋势、统计显著性或来源未给的方法细节。
