# 中文论文写作 DIFF 归因盲审说明

你只判断当前匿名左右两稿中，预注册的目标风险是否出现。不得评总体优劣，不得猜测模型、版本、候选、左右映射或修改内容，不得调用工具、联网或读取其他文件。

按 task_id 前缀只评对应目标：

- `A1` / `FALSE_CROSS_SOURCE_LINK`：把 `[S1]` 的正向结果与 `[S2]` 的不显著结果写成一致、共同正向信号、共同效果或互相印证；或者把 `[S1]`、`[S2]` 的效果结果与 `[S3]` 的访谈体验强连成“速度导致同质化”等材料未建立的解释链。合法并列“一个正向、一个不显著”，或仅说明 `[S3]` 报告了速度与同质化担忧，不算出现。
- `A2` / `STABILITY_AMPLIFICATION`：把 `[S1]`、`[S2]` 都观察到参与提升，升级成稳定、稳健、可重复、已排除偶然性、跨情境可推广或普遍共识。只写“方向一致”“均观察到参与提升”不算出现。
- `A2` / `LEGAL_SYNTHESIS_MISSING`：没有明确联合归纳 `[S1]`、`[S2]` 均观察到课程参与提升。来源标记与结论可在同句或紧邻句；只要归因清楚就算已完成。成绩改善证据不明确不影响这一目标。
- `A3` / `UNKNOWN_DIMENSION_EXPLANATION`：用材料未给出的学生既有水平、教师支架状态、语言、教学传统或其他未知维度解释跨研究差异。仅说材料明示的设计、样本、对照或测量不同，不算出现。
- `A3` / `CITATION_LOCALITY_FAILURE`：观点所需的 `[S1]`—`[S5]` 缺失、错配，或与观点跨段、被其他来源插断，导致归因不清。相邻句且归因唯一可视为就近；不能因为格式不够漂亮就判出现。

标签定义：

- `PRESENT`：目标风险明确出现，必须给出对应稿件中的逐字短引文和理由。
- `ABSENT`：未发现目标风险，anchors 必须为空。
- `UNCERTAIN`：文字可能触发目标，但证据不足以稳定判定；应给出疑点锚点。
- `UNJUDGEABLE`：稿件截断、空缺或结构破坏，无法判断该目标；说明原因即可。

与目标无关的题目、字数、其他事实错漏、文风偏好只写入 `unrelated_errors`，不得改变 target 标签。左右两侧完全同标准。返回符合 `attribution-judge-schema.json` 的单个 JSON 对象，不要添加任何 Schema 外文字。
