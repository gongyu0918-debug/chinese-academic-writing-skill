# 文学论文小节起草

请写论文小节“渡口书写中的时间经验”，1600—2000 个汉字。不要重复小节标题，不要设置小标题或列清单。依据下面的文本片段和版本信息展开细读，说明空间意象如何参与时间经验的呈现；不要虚构作者生平、时代背景、作品情节或学界评价。

文本 A（初刊本）：

> 暮色压到江面时，旧渡船还拴在第三根木桩上。对岸的灯一盏一盏亮起来，候船的人没有催问，只把湿鞋移近火盆。摆渡人说，水再退半尺就开船。孩子数过七次钟声，船仍在原处。

文本 B（修订本）：

> 暮色落到江面时，旧渡船还拴在第三根木桩上。对岸的灯次第亮起，候船的人偶尔望向水尺，把湿鞋移近火盆。摆渡人没有许诺开船的时刻。孩子数过七次钟声，船仍在原处。

文本 C（同章后文）：

> 清晨，人们终于看见木桩下露出的白痕。昨夜的水退了，渡船却因缆绳吃紧向岸边斜去。有人先走上堤路，有人继续等。孩子不再数钟，只盯着摆渡人解那只结。

版本信息：

- A 是 1986 年杂志初刊文字，B 是 1994 年单行本修订文字。
- 只能确认以上文字差异，不能据此推断作者修改动机。
- “第三根木桩”“七次钟声”“白痕”“绳结”在本章其他位置没有再次出现。
- 论文主张不是“等待必然带来希望”，而是渡口把自然时间、计时秩序和行动选择并置，使等待呈现为不断被重新判断的经验。

写作要求：

- 比较“再退半尺就开船”被改为“没有许诺开船的时刻”后，等待的确定性如何变化。
- 解释钟声、水尺、水位痕迹和绳结分别提供何种时间线索，避免把意象逐个贴上固定象征。
- 讨论 C 中“先走上堤路”与“继续等”的分化，不把人物选择概括为统一立场。
- 可以提出解释，但需使用与文本证据相称的限定语。
