# 单节论文起草

请根据材料写论文小节“地方档案数字展览的叙事取舍”，900—1200 个汉字。不要重复小节标题，不设小标题，不列清单，只输出正文。

材料：

- 研究对象是甲市档案馆 2024 年上线的“河港记忆”数字展览。
- 展览共 67 个页面，其中 28 页以历史照片为主，19 页以档案文书节选为主，12 页以口述史音频为主，8 页为导航和说明页面。
- 展览按“河道、码头、行业、生活”四个主题组织，不按严格年代顺序排列。
- 研究者核对了页面标题、材料类型、说明文字和页面之间的链接，没有访问量、停留时长、用户评论或线下参观数据。
- 照片页面多使用地点和大致年代作为说明；档案文书页面保留形成机关和年份；口述史页面标明讲述者身份类别，但未公开完整访谈时间和删节原则。
- 可以讨论不同材料如何共同构成展览叙事，以及主题组织带来的呈现取舍。
- 不能判断用户是否更喜欢某类页面，不能评价传播效果，也不能推断策展团队的主观动机。
- 结尾需要说明：现有分析针对公开页面的材料组织，不等同于对档案完整性或城市历史全貌的判断。
