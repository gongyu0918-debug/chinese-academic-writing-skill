# 独立文献综述

请根据四项来源写一篇 1200—1500 个汉字的独立叙述性文献综述，题目为“大学生在线讨论沉默的研究进展”。保留来源 ID `[S1]`—`[S4]`，论断后就近标注。使用“问题与范围、主要解释路径、证据差异与研究限制、述评”四个标题。只输出综述正文。

来源：

- `[S1]` 已读全文。对两所高校 684 名学生进行一次问卷调查，发现感知评价压力与发帖频率呈负相关。作者明确不作因果解释，也没有平台阅读日志。
- `[S2]` 已读摘要。研究使用某门在线课程 12 周的平台日志，区分浏览与发帖；摘要称部分低发帖学生保持较高阅读频率，但没有报告学习成绩，也没有说明沉默者的动机。
- `[S3]` 仅有题名和期刊元数据，题名为《在线协作中的社会临场感与学习投入》。没有摘要或全文，不能用于说明研究发现。
- `[S4]` 已读全文。对 24 名学生进行访谈，受访者提到担心回答错误、重复他人观点、时间不足等原因。样本来自一个专业，作者没有比较这些原因的普遍程度。

写作边界：

- 不把相关关系写成因果关系。
- 不把“少发帖”等同于“不阅读”或“没有学习”。
- 不用 `[S3]` 支持具体观点。
- 不把 24 人访谈结果概括为大学生普遍动机。
- 当前材料不能支持系统综述、领域空白或历年趋势结论。
