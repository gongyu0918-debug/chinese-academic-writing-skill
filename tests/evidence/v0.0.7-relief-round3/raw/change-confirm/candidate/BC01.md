# 夜间自习空间选择的观察结果

本研究对同一学院A、B两间自习室进行了连续4个工作日的观察，观察时段均为19:00—21:00。A室共形成160次座位观察记录，其中124次处于使用状态，观察使用率为77.5%；B室共形成144次座位观察记录，其中86次处于使用状态，观察使用率约为59.7%。在本次观察覆盖的时段内，A室的观察使用率比B室高约17.8个百分点，处于使用状态的记录也多38次。这一结果表明，两个自习空间在工作日晚间的座位使用情况存在较为明显的描述性差异，A室在所观察时段内呈现出更高的座位占用水平。

需要说明的是，304次座位观察记录是按照不同时点累计形成的座位状态记录，并不对应304名不同学生。同一座位或同一学生可能在多个观察时点被重复记录，因此，上述数据只能用于比较两间自习室在特定时段内的座位使用状态，不能据此推算实际到访人数、人员流动频率或学生个体的选座次数。同时，现有材料未提供各日数据及不同时点的变化情况，因而不能进一步判断两室差异是否在每日或整个观察时段内持续保持一致。

对16名学生的便利访谈为理解空间选择提供了有限的补充线索。其中，9人提到插座位置，6人提到照明，4人提到与同伴相邻。由于访谈回答允许重叠，这些数字反映的是不同因素被提及的次数，不能相加后理解为彼此排斥的选择类型。从访谈内容看，插座、照明和同伴邻近性可能是部分受访学生关注的空间条件，尤其是插座位置被提及较多，说明设备使用的便利程度在其自习空间体验中具有一定可见性。然而，便利访谈的样本数量较少，且材料没有建立具体回答、实际座位与所在自习室之间的对应关系，因此只能将这些内容作为解释观察差异的背景线索，不能认定上述因素造成了A室较高的观察使用率，也不能据此确定各因素的相对重要性。

本次观察未覆盖周末和考试周，也未跟踪学生的停留时长，研究结果因而仅适用于所观察学院、工作日晚间19:00—21:00及连续4日这一具体范围。两室座位使用差异可能与空间条件有关，但现有材料尚不足以检验其因果关系，更不能将这一局部观察推广为学生夜间自习空间选择的普遍规律。
