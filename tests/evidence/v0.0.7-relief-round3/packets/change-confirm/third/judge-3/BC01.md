# 夜间自习空间选择的观察结果

研究者在同一学院的A、B两间自习室连续观察4个工作日，观察时段均为19:00—21:00。从累计座位状态看，A室共形成160次座位观察记录，其中124次处于使用状态，使用比例为77.5%；B室共形成144次记录，其中86次处于使用状态，使用比例约为59.7%。在本次观察覆盖的日期和时段内，A室的座位使用比例比B室高约17.8个百分点，说明A室在所观察的夜间时段呈现出更高的座位占用水平。两室观察记录总量不同，因此，与单纯比较使用记录次数相比，使用比例更能反映其在各自观察记录中的差异。

需要说明的是，上述304次记录是按观察时点累计的座位状态，并不对应304名不同学生。同一座位或同一名学生可能在不同观察时点被重复计入，因而这些数据只能用于描述两间自习室在特定时段内的座位使用状况，不能据此推算实际到访人数、学生流动频率或个体选座偏好。A室较高的使用比例表明其在此次观察中更常处于被使用状态，但仅凭这一差异，尚不能判断学生是否稳定偏好A室，也不能排除座位总量、到达时间及其他未记录因素的影响。

对16名学生的便利访谈为理解空间选择提供了补充线索。其中，9人提到插座位置，6人提到照明，4人提到与同伴相邻。由于回答允许重叠，这些人数不能相加后理解为彼此独立的选择类型，也不表示受访者只关注某一项条件。访谈结果能够支持的判断是，在受访学生的表达中，插座位置、照明条件和同伴邻近性均属于被主动提及的考虑因素，且插座位置被提及得较多。这些材料有助于说明学生观察和评价自习空间时可能关注的具体方面，却不足以证明这些因素造成了A、B两室使用比例的差异。现有材料也未分别呈现两室的插座、照明状况及受访者实际选座过程，因而不能建立空间条件与座位选择之间的对应关系。

本次观察未覆盖周末和考试周，结果可能无法反映学习需求集中或日程结构变化时的情况；研究也未跟踪学生的停留时长，无法区分短暂停留与持续使用。加之便利访谈人数有限，相关表述不宜推广至学院全体学生。由此，本节只能确认两间自习室在4个工作日夜间观察时段内存在座位使用比例差异，并将访谈中出现的空间因素视为解释这一现象的可能线索，而不能据此作出因果判断或普遍结论。
