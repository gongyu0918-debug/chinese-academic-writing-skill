# 《短视频使用与大学生睡眠质量》开题准备提纲

## 一、最小研究范围

暂定题目为《短视频使用与大学生睡眠质量》。现阶段可确定的研究主题仅包括“短视频使用”“大学生”和“睡眠质量”三个基本要素，拟围绕短视频使用与大学生睡眠质量之间的关系展开。研究对象的院校、地区、年级等范围，本轮未提供，需作者确认；两个核心概念的具体含义和测量口径也需结合文献、学校要求及拟采用的材料进一步界定。

在现有材料条件下，不能预先认定短视频使用会导致大学生睡眠质量发生变化，也不能写入特定影响方向、作用机制、群体差异或研究空白。后续论证应以作者提供或授权核验的文献、数据和研究记录为依据。

## 二、中心问题与目标骨架

### （一）中心问题

短视频使用与大学生睡眠质量之间呈现何种关系？

该问题目前只作为上位问题。是否需要拆分子问题，以及子问题涉及哪些具体方面，需在研究对象范围、概念界定、文献基础和研究方法明确后确定。

### （二）研究目标

在明确研究范围和证据来源的基础上，描述并分析短视频使用与大学生睡眠质量之间的关系。目标的具体层级、论断强度和最终成果形式，本轮未提供，需作者确认。
