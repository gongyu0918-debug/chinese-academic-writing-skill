# 生成式人工智能对大学写作的影响：独立文献综述写作框架

当前材料不足以形成符合学术规范的3000字文献综述正文。独立文献综述需要以可核验的文献为依据，比较不同研究的对象、方法、结论与限制。本轮未提供文献、摘要或检索记录，也不允许联网，因此不能将未经来源支持的判断写成研究共识、争议、趋势或结论。以下内容可用于界定综述范围、收集材料并组织后续正文。

## 一、综述范围

本综述拟讨论生成式人工智能介入大学写作后可能涉及的学习过程、文本产出、评价方式与学术规范问题。研究对象可限定为普通高等学校学生；如需纳入教师、研究生或特定专业学生，应分别标明，避免把不同群体的研究结论直接合并。写作类型可覆盖课程作业、学术论文、反思性写作、外语写作等，但应记录每项研究对应的具体任务，因为不同体裁的写作目标和评价标准并不相同。

“生成式人工智能”“大学写作”“写作质量”“写作能力”等核心概念应依据所收集文献界定。需要特别区分工具使用与能力变化、文本表现与学习成效、短期任务结果与长期写作发展。时间、地域和学科边界由课程要求或实际材料决定；若同时使用中文与外文研究，应说明教育情境、语言环境和评价制度的差异，避免简单类推。

## 二、核心综述问题

1. 现有研究考察了生成式人工智能参与大学写作的哪些环节，如构思、提纲、起草、改写、反馈或语言校订？
2. 不同研究如何界定和测量写作质量、写作能力、写作投入及学习成效？
3. 生成式人工智能的使用与文本质量、写作效率、认知投入或自主学习之间呈现何种关系？这些结论建立在何种研究设计之上？
4. 不同学生群体、学科、课程、语言背景和使用方式是否对应不同结果？
5. 现有研究如何讨论作者身份、引用责任、事实核验、学术诚信和评价公平？
6. 教师指导、课程规则、任务设计和人工智能素养在工具使用中发挥何种作用？
7. 各项研究在样本、测量、研究周期、工具版本和情境适用性方面存在哪些限制？

上述问题均是后续检索和比较的方向，不能在缺少来源时预设答案。

## 三、3000字正文结构

### （一）引言：约300字

说明综述主题、研究对象和写作场景，提出需要回答的核心问题。引言中的背景判断应有来源支持，不使用“广泛应用”“深刻改变”“引发巨大争议”等无法由当前材料证明的概括。结尾交代综述的范围、组织方式及不纳入的内容。

### （二）概念与来源范围：约300字

依据实际文献界定生成式人工智能、大学写作、写作质量与学习成效，说明综述覆盖的时间、地域、语言、学生层次和写作体裁。若最终采用普通叙述性综述，应如实说明材料来源与选择原则，不写成系统综述，也不虚构数据库、检索式、筛选数量或纳入数量。

### （三）生成式人工智能与大学写作过程：约600字

按照构思、起草、修订和反馈等写作环节归纳研究。比较不同研究中的工具使用方式、任务要求、教师介入程度和学生自主程度，分析研究所报告的便利、困难或变化是否来自访谈、自陈问卷、过程数据、文本比较或其他证据。需要把学生主观感受与实际写作表现分开，把一次任务中的表现与持续能力发展分开。只有采用适当对照和追踪设计的研究，才可能为较强的效果判断提供依据。

### （四）文本产出、学习成效与能力发展：约550字

围绕文本质量、写作效率、语言表现、论证质量、知识理解和迁移能力等指标比较研究结果。首先说明各研究的测量标准，再讨论结论是否一致。若评价指标、写作体裁或学生群体不同，不宜直接合并为单一结论。对于相关性、自我报告或短期实验结果，应采用与证据相称的表达，不将“同时出现”“受访者认为”或“单次任务得分变化”写成稳定的因果影响。

### （五）学术规范、作者责任与评价问题：约550字

归纳文献对署名、引用、事实核验、文本原创性、过程透明度和评价公平的讨论。区分规范性文件提出的要求、教师或学生的态度调查，以及实际行为研究所得的发现。不同学校、课程和学科的规则可能并不相同，正文应注明来源适用范围。对风险与治理措施的讨论应建立在材料之上，不把个别案例扩展为普遍现象，也不在缺少比较证据时断言某种制度措施有效。

### （六）群体差异与教育条件：约400字

比较不同学科、年级、语言水平、数字能力和任务类型下的研究结果，并考察教师指导、课程设计、使用规则和技术条件。只有文献实际提供分组或情境证据时，才能讨论差异。若现有材料只覆盖某一群体，应将结论限定在该群体，不把材料未涉及的对象写成研究空白。

### （七）综合评述：约300字

概括来源之间能够确认的共识、差异和争议，并把每项综合判断对应到具体文献。评述研究设计、测量方法和适用范围对结论强度的影响，指出当前材料能够回答与尚不能回答的问题。所谓“研究不足”或“未来方向”须来自充分的来源覆盖，不能仅凭未检索到材料作出判断。

## 四、文献收集清单

后续材料应尽量覆盖以下类型：

- 直接观察或比较大学生使用生成式人工智能完成写作任务的实证研究；
- 关注构思、起草、修订、反馈等写作过程的研究；
- 采用明确标准评价文本质量或学习成效的研究；
- 讨论学生体验、教师判断与课堂实施的调查或质性研究；
- 涉及作者身份、引用、学术诚信和评价规则的研究或正式规范；
- 能够比较不同学科、语言背景、学生层次或使用方式的研究；
- 与研究问题直接相关、能够说明理论概念或分析框架的综述和理论文献。

新闻、评论和产品宣传可以帮助了解讨论背景，但不能代替学术研究支持效果、机制或因果结论。正式规范可以说明制度要求，也不能直接证明学生行为或教学效果。

每份材料至少记录以下信息：

| 项目 | 需记录内容 |
| --- | --- |
| 来源信息 | 作者、题名、年份、载体、链接或 DOI |
| 可用层级 | 全文、摘要或仅有书目信息 |
| 研究对象 | 学生层次、专业、语言背景、样本范围 |
| 写作情境 | 课程、体裁、任务要求、使用环节 |
| 工具与方式 | 工具类型、使用规则、教师是否介入 |
| 研究方法 | 实验、调查、访谈、文本分析、过程记录等 |
| 测量指标 | 文本质量、效率、投入、能力或其他指标 |
| 主要结论 | 仅记录来源明确陈述的结论 |
| 研究限制 | 样本、周期、测量、情境与可推广范围 |
| 正文用途 | 拟支持的章节、观点及引用位置 |

## 五、形成正文前需要补充的材料

要完成可提交的3000字独立文献综述，需提供与上述问题相关的文献全文或摘要，并附可核对的书目信息。若只提供摘要，正文只能使用摘要明确陈述的有限结论；若只提供题名、作者和年份等元数据，则只能确认文献身份，不能据此概括其观点。还需明确课程或学校对文献数量、时间范围、引用格式、中文与外文来源比例等要求。

材料齐备后，应以多篇文献之间的比较为基本单位，按主题综合研究对象、方法、发现和限制，避免逐篇摘要。每项事实判断和研究结论均应就近标注来源，参考文献表与正文引用逐一对应；无法回到原文的共识、趋势、因果关系和领域空白不写入最终正文。
