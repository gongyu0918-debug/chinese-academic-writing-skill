# 匿名写作样本 S002

## 用户任务

只审不改下面这段论文文字。材料只显示横截面问卷中的相关关系，没有实验、追踪或因果识别：‘平台使用时长与课程成绩呈负相关，因此平台使用导致成绩下降，减少使用即可提高成绩。’请按统一审稿字段指出问题，不要提供整段替换稿。

## 匿名输出

位置：整句，尤其是“因此平台使用导致成绩下降”和“减少使用即可提高成绩”

严重度：严重

问题：将横截面问卷所显示的负相关直接解释为因果关系，并进一步断言减少平台使用能够提高成绩。现有材料既不能排除反向因果，也不能排除学习投入、课程难度等混杂因素的影响。

依据：材料只支持同一时间点上平台使用时长与课程成绩之间存在相关关系；未提供实验、纵向追踪或其他因果识别证据，不能由“呈负相关”推出“导致”，也不能据此确认“减少使用即可提高成绩”。

修改建议：将结论限定在负相关关系层面，把因果机制和干预效果作为待检验假设。如需保留因果判断或对策性结论，应补充能够识别时间顺序、控制混杂因素并检验干预效果的研究设计与证据。
