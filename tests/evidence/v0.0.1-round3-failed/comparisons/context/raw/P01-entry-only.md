# 社区老年人数字政务使用障碍研究开题报告

## 一、选题依据

本研究聚焦社区老年人使用数字政务服务过程中面临的障碍。前期已完成相关政策文本整理，可作为界定研究背景和政策要求的基础。由于现有材料尚未包含访谈资料，且本轮未提供政策文本的具体内容，目前不能对障碍表现、形成原因及影响作出判断，仍需通过后续调查取得研究材料。

## 二、研究目标

本研究拟通过半结构式访谈了解社区老年人使用数字政务服务的实际情况，梳理其使用障碍，形成障碍类型分析，并据此提出改进建议。

## 三、研究内容

一是以已整理的政策文本作为前期基础，明确研究所涉及的数字政务服务范围；二是围绕社区老年人的数字政务使用经历收集访谈材料；三是根据访谈材料归纳使用障碍的主要类型；四是在障碍分析基础上提出相应的改进建议。具体障碍类型将在材料收集和分析完成后确定，不作预设。

## 四、研究方法

本研究拟采用半结构式访谈法收集材料。访谈尚未开始，访谈对象范围、样本数量、遴选条件及访谈提纲等事项本轮未提供，需在正式访谈前进一步明确。

## 五、进度安排

前期已完成政策文本整理。计划于2026年9月至10月开展半结构式访谈并收集研究材料。访谈材料整理、分析及报告撰写的具体时间安排本轮未提供，需结合学校要求和研究进展另行确定。

## 六、预期成果

预期形成社区老年人数字政务使用障碍的类型分析，并在此基础上提出改进建议。以上内容属于预期成果，不代表已经取得研究结论。
