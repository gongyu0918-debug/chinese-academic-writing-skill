# 高校图书馆晚间座位使用问题：三级提纲

一、研究范围与材料说明

（一）观察材料的时空范围

1. 观察时间：2025年4月连续三个工作日晚间
2. 观察地点与对象：高校图书馆二层靠窗座位

（二）访谈材料的范围

1. 访谈对象：18名学生
2. 已知访谈信息：多人提到插座位置会影响选座

（三）现有材料的使用边界

1. 观察材料用于描述特定时段、特定楼层和特定座位区域的使用情况
2. 访谈材料用于呈现受访学生对选座影响因素的表述

二、二层靠窗座位的晚间使用现象

（一）连续观察所见

1. 连续三个工作日晚间均观察到二层靠窗座位紧张
2. 该现象限定于本次观察的时间与空间范围

（二）观察材料可支持的判断

1. 在已观察的三个工作日晚间，二层靠窗座位存在使用紧张现象
2. 现有材料不能据此判断其他楼层、其他座位区域或其他日期的使用情况

（三）观察结论的表述限度

1. 不将三次局部观察扩展为全馆晚间座位使用的普遍结论
2. 不由座位紧张现象推断其形成原因、持续程度或变化趋势

三、学生选座中插座位置的访谈信息

（一）受访学生的相关表述

1. 本次访谈共涉及18名学生
2. 多名受访学生提到插座位置会影响其选座

（二）访谈材料可支持的判断

1. 插座位置是部分受访学生明确提及的选座考虑因素
2. 现有材料尚不能确定提及人数、影响程度及其在各类选座考虑中的相对位置

（三）观察材料与访谈材料的关系

1. 观察材料呈现二层靠窗座位在限定时段内的使用状态
2. 访谈材料呈现受访学生提及的一项选座考虑，不能据此认定插座位置造成了靠窗座位紧张

## 补充与修改建议

### 可补充论点

- 如需扩大讨论，可在取得更多观察材料后分析二层靠窗座位紧张现象是否具有跨日期、跨时段的稳定性。
- 如需深化访谈部分，可在取得分类材料后讨论不同座位区域中插座位置被提及的情况是否存在差异。

### 可补充论据

- 补充更多工作日及非工作日晚间的分时段观察记录，并记录各区域座位总数与实际使用数量。
- 补充18名学生的访谈原始记录、提及插座位置的确切人数及经匿名处理的代表性表述。
- 补充二层座位与插座的位置资料，用于准确说明观察区域和访谈所指对象。

### 可补充论述

- 进一步说明“连续三个工作日晚间的局部观察”与“全馆长期使用情况”之间的证据边界。
- 区分“受访学生提到插座位置影响选座”与“插座位置能够解释靠窗座位紧张”两种不同强度的判断。
- 分别交代观察材料和访谈材料能够回答的问题，避免将两类材料直接合并为因果结论。
