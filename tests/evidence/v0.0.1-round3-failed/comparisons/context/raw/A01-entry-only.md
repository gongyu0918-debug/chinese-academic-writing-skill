# 高校图书馆晚间座位使用问题

## 三级提纲

一、研究对象与材料范围

（一）研究对象的界定

1. 讨论对象为高校图书馆晚间座位使用问题
2. 现有观察区域为图书馆二层靠窗座位
3. 现有观察时段为2025年4月连续三个工作日晚间

（二）现有材料的构成

1. 连续三个工作日晚间的现场观察材料
2. 对18名学生开展访谈形成的材料
3. 观察材料用于描述座位使用现象，访谈材料用于呈现学生提到的选座考虑

二、现有材料呈现的晚间座位使用情况

（一）二层靠窗座位的使用现象

1. 连续三个工作日晚间均观察到该区域座位紧张
2. 这一现象的时间范围限于2025年4月已观察的三个工作日晚间
3. 这一现象的空间范围限于二层靠窗座位

（二）插座位置与学生选座

1. 访谈对象共18名学生
2. 多名受访学生提到插座位置会影响选座
3. 现有材料未提供具体人数及影响程度，暂不作比例或程度判断

三、现有材料的论述边界

（一）观察材料的适用范围

1. 可确认特定日期、特定区域出现座位紧张
2. 暂不能将该现象推广到其他日期、其他时段或图书馆其他区域
3. 暂不能据此判断座位紧张的形成原因

（二）访谈材料的表达范围

1. 可表述插座位置是部分受访学生提到的选座考虑
2. 暂不能判断该因素在全部学生中的普遍程度
3. 暂不能认定插座位置与二层靠窗座位紧张之间存在因果关系

（三）两类材料的组织方式

1. 先以观察材料说明二层靠窗座位在限定时段内的使用现象
2. 再以访谈材料呈现学生选座时提到的插座位置因素
3. 将两类材料分别陈述，不在证据不足时建立因果链条或引出对策

## 补充与修改建议

### 可补充论点

- 如需进一步讨论座位紧张是否具有持续性、是否存在区域差异，以及插座位置对选座的影响程度，应在补充相应证据后再形成论点。

### 可补充论据

- 可补充更多日期、更多晚间时段及其他楼层或座位区域的观察记录，并明确座位总数、已使用座位数及“紧张”的判定标准。
- 可补充18名受访学生中提到插座位置的具体人数、访谈原话及访谈问题，以便判断现有表述的证据强度。

### 可补充论述

- 可进一步说明现场观察与学生访谈分别回答什么问题，并区分“插座位置影响选座”与“插座位置导致座位紧张”这两种不同论断。
- 可在相关段落交代现有观察的时间、空间和样本边界，避免把局部现象表述为全馆或长期情况。
