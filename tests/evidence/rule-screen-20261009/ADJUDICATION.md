# 最终取舍：取消R1/R2，只合并筛查与证据

本轮没有准入新的运行规则。SKILL与全部运行文件已恢复a6e9cab基线；v0.1.6中已准入的主次规格和独立综述Q2原子仍保留。没有版本号变化、发布、推送或桌面更新。

## 改动范围和归因

R1只把既有独立证据原子从独立综述叶移到共用证据账本；R2保留迁移，并补充同样本访谈按所支持内容使用、独立性不改变用户必列范围。潜在路由覆盖缺口确实存在，但合理的规则意图不等于这次实现已经可靠。

两轮32份完整返回、16完整配对中，GLM多份稿件能正确区分同方法新样本、准确转述和访谈；Qwen候选却出现漏必列、误认缺材料及错数。基线也有缺陷，不能把候选侧独有的稿件错误一律宣称为DIFF导致的回退；尤其访谈人数改错与迁移文字之间未证明机制因果。本轮结论是未证明新增稳定收益，最小修订后的成稿比较仍净负，不把这个未验证的共用实现准入。没有要求每题胜出，也没有以字数更长、来源更多或持平为优势/回退。
