# 本轮真实来源补读及边界

继续读取吳佳鴻2016年国立台湾大学中国文学系硕论《從見聞到敘事──晚清小說文體革新》，学校[记录](https://tdr.lib.ntu.edu.tw/handle/123456789/3784?mode=full)与[原PDF](https://tdr.lib.ntu.edu.tw/bitstream/123456789/3784/1/ntu-105-1.pdf)。原件沿用上轮已取得版本，SHA256为6db5b4d7e1e1188dbe51d3679f5c7b899d488dc0aae47383c2d3000353d68a6f；本轮重新打开学校记录核对身份。

新增实际阅读PDF42—52（印刷页33—43），共11页，未与上轮50页重复；累计该硕论61/236页，仍是部分阅读。视觉核读PDF46、50，印刷页分别37、41；论文正文、脚注及页码位置分清，未把原PDF页数冒充印刷页。没有因此声称读完第二章、全部正文或逐条核验文后文献。

新页段实际讨论了小说论者如何想象教化者与读者，以及从将小说作工具到将教化者形象转移给小说创作者的具体转折。历史论者的社会功用主张、硕论作者的文本解释、读者真实接受效果不是同一证据对象。脚注保留对西方政治小说影响的夸大说法的质疑，不因为它处于背景章就可以把这类限定压掉。
