# 0.0.5 长稿稳定与全文一致性验证报告

## 修改范围

本轮保持普通论文段落生成规则不变，只新增按需长稿层：

- `paper-state.md` 结构保存经最新版稿件或材料确认的耐久事实、论点—证据—章节关系、术语、文体基线、章节摘要和未决事项；
- `section-briefs/` 记录章节职责、可用证据、结论上限、相邻依赖和重复边界，不规定句序、句数、首句、段长或统一节奏；
- 合稿后按硬边界、研究闭合、稿内一致、章节关系、文体漂移、语言整理的顺序复核；来源核验和 ANTI-AI 另开轮次；
- 新增只读 `manuscript_audit.py`，只报告完全重复段落、显式术语组、指定缩写和 LaTeX 交叉引用候选，不自动改稿。

## 剩余风险

- 只覆盖一组社会科学风格的四章材料，尚未覆盖法学、文学历史、理论研究、理工公式长稿和真实导师模板。
- `paper-state.md` 的跨会话持久化仍是 Prompt 契约，尚未用多个真实会话验证状态更新、冲突合并和旧状态淘汰。
- 机械脚本不判断数字是否属于同一口径、论点是否语义矛盾或文体是否合适；高等级 LaTeX 结果也以用户实际提供的扫描文件范围为边界。
- 本轮不发布，不声称优于旧基线，也不把单个前向样本外推为跨模型结论。
