# 作者确认材料

- 论文题目：高校图书馆学习分析系统使用情况研究。
- 研究对象：某高校自愿参加观察与访谈的学生48人；不得改称本科生或研究生。
- 观察时间：2025年3月连续三个工作日晚间；不含周末、考试周和白天。
- 系统正式名称：学习分析系统；首次出现后可简称“系统”。作者不采用“LA”缩写，也不将其称为“学习分析平台”。
- 二层靠窗区域共有31个座位，中部区域共有24个座位。现有记录只包含区域座位数量，不包含逐座使用率或显著性检验。
- 访谈记录中，18人提到插座位置，11人提到照明，8人提到安静程度；回答可以重叠，不能换算为互斥比例。
- 研究只能描述观察期内的使用情况及受访者提及的关注因素，不能识别系统、插座或其他因素对学习效果、选座行为的因果影响。
- 作者认可的表达采用第三人称“本研究”，语气克制；方法章节可使用“记录了”，讨论章节多用“可能”“提示”“尚不能说明”。

## 章节职责

- 第一章：界定问题、材料范围与研究边界，不提前写结果。
- 第二章：说明观察与访谈材料怎样取得，不写政策建议。
- 第三章：呈现材料中的数量和关注因素，并说明回答可以重叠。
- 第四章：讨论材料能够支持的有限认识、局限和后续材料需求，不新增调查结果。
